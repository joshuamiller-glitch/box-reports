# Spec for the LIVE-definition profit-line series (W-JV to W-CF2), from DS7.cs v2.0 (ManageProfitState, StateTick, L2ThSnapshot, Delta60Window)
Per UTC day npz in /mnt/l2/l2vast/_confl/cf2_profit_live/<YYYYMMDD>_<iid>.npz, dense float32, index i = second - sec0, keys: sec0 (int64), mid, delta, med, totrel.
- mid: 0.5 x (best bid + best ask) at the end of the second (DS7 stateTick; fall back to last print if book not live), in points.
- delta: signed aggressor volume of the second, the Delta60Window sample sum: buy-aggressor contracts minus sell-aggressor contracts (the live sign uses the print vs lastAsk/lastBid and gives no sample inside the spread; MBO uses the exchange aggressor flag: parity not asserted). The hook computes delta_mult = -side x sum_{win seconds}(delta) / med.
- med = stMedLevel: per closed second, avg = (sum of top-5 bid level sizes + sum of top-5 ask level sizes) / 10; stMedLevel = avg at the first second, then 0.999 x stMedLevel + 0.001 x avg (EWMA per second, continuous across days while the strategy runs; seed from the first second of the file or carry over from the previous day file).
- totrel = curDepthRel: at each depth snapshot, curDepthTot8 = bid depth within 7.5 ticks of the best bid + ask depth within 7.5 ticks of the best ask; baseline per 30-minute slot of the ET clock (48 slots): depthBase[slot] = first value, then += a x (cur - depthBase) with a = 0.02 while depthBaseN[slot] < 300 else 0.002 (depthBaseN counts snapshots); curDepthRel = curDepthTot8 / depthBase[slot] once depthBaseN[slot] >= 300 (ThL2WarmupSnapshots), else NaN. Take the value at the end of each second (last snapshot of the second). Baseline continuous across days (kept while the strategy runs).
Lines: K7 pct>=0.3 delta_mult>=5 win=10 persist=10 lock 0; U7 pct>=0.4 delta_mult>=20 win=15 persist=5 tighten 30; M7 pct>=0.3 tot_rel>=2 persist=2 step 10 (wall_ticks=8 unused). Window needed: 202511..202610 first (about 250 days).
