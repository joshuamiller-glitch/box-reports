### (1) Tue 11-03 00:58 short, 4 lots, thl2_cut +7,716 on a 28,128.50 exit (18.75 pt adverse): ENGINE BUG, resolved
Mechanism (traced in the engine arrays, row 45155): the split kernel's base outcome for this row is a TARGET (+64.03 pt, kernel exit second 46,753,614; the kernel enters at a dip price 28,109.75 and its target level is 28,042.08), but the stored TH-L2 cut stream is relative to the library TABLE exit of the signal (stop 28,158, -60 pt from E 28,098, cut delta dN +30.015 pt). d7lib._compose_d7 adds `o[r,0] += dN * l` to the kernel outcome, so the row books +64.03 + 30.0 x 1.073 = +96.2 pt per lot for an exit that is 18.75 pt adverse. The correction exists in the code as 'kfix' (V13T2: re-base each cut delta to the kernel exit) but is OFF in the truth base and sealed run, and with kfix=True alone it does nothing for the blind rows because d7_v13t._lib() takes the table exit price from a tid-indexed table that has NaN for the blind-week rows (variant N1: week list identical). Variant N2 (kfix=True with the table exit prices taken from the blind trades_arm, finite for 74.8% of rows): this trade becomes -2,322 (swing -10,037); 25 other cut trades move by +34 to +360 (net +3,058); week total 34,879 -> 27,899 (-6,979), P7 (P6) +2,404 -> -5,791 (-8,195), K6 +489, M6 +339, H6 +290, U6 +97.
