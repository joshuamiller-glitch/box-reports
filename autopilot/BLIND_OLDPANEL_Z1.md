## 2. The four signal-state slots (code slots.py)
SkipBot3 K7 St1Dist / SkipTop3 P7 St1Dist / SizeHi P7 St1Dist (x1.5 top third, x0.5 bottom third) / SkipBot3 H7 St1Dist; rank = fraction of the book's earlier signals with a strictly smaller value (bisect_left/n), min history 100, value inserted after ranking (also for skipped signals), B3 rank < 1/3, T3 >= 2/3, NaN -> multiplier 1. Feature sig_st1_dist_atr = side*(E - Supertrend(ATR10 Wilder, x3) line)/ATR14 Wilder, 1-min bars, state never reset. Verified: stored EINT1 feature on 3,000 trades max abs diff 2.4e-7; recomputing the line from the last 40,000 library bars reproduces the stored line exactly (0.0) over the last 5,000 bars. The engine calls `SL.apply_slots(signals, S, rk)` with ALL K7/P7/H7 signals of the span in time order (the Shadow period keeps the rank history causal) and applies slot_mult only inside the old-panel window.
