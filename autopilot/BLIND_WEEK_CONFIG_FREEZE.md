## 2. Engine and fill model
d7_v13t / lots_ts2 truth base: V13Y -> V13X chain with U7 blackout EXACT (30 min, same side, after a TH-L2 cut of U7), per-book locks in the engine (12R week floor, day give-back arm 2R keep 50%, daily +5R/-2R entry caps), lockfix 'legs' (resting 30% add cancelled on EVERY exit), Native stops, 70/30 split dip 3, OTE-62 B73 D30, PE 45-s confirmation, ER(20) running-max sizer, live lot order session -> A06 slot -> B02 -> ER -> zone (lots_ts2). Fill model (measured, from the directive): market entries ~1 s after the 1-min close (engine grid '1sh'), targets resting at nominal, stops 2.45 pt worse than nominal (stopcost 2.45), market exits 0.80 pt (xcost 0.80), flatten 16:55 ET. Slicing 1 lot per 2 s is not modelled by the engine's P&L (DS3_TH_COST.md: within about +-$90/week); nothing is added for it.
Books: K7=KB, P7=PE, U7=SM, H7=HM, M7=MV, A7=PB (PB7), X1-X5. NY-AM lots K7/H7/M7 = 1 (engine lot table live11 checked equal to the directive strings: K7 2,2,0,1,2,0; H7 4,0,0,1,0,0; M7 0,2,0,1,0,0; P7 7,7,0,7,0,0; U7 4,4,0,0,0,0; A7 1,0,0,0,0,0).

P0 Sun 18:00 -> Mon 08:50 ET "old panel": X1-X5 LIVE 2 lots; signal-state rules LIVE (engine sig_hm/sig_kb/sig_pe + Z1's 4-slot rank code as a documented difference, see 5); zone action SKIP D20; th_profit ON (APPROX of "TH-L2 profit tighten, thick-book 2.0x for 10 s, trail 30 ticks": engine th_profit = open profit >= 30 pts held 30 s then trail 30 pts; the thick-book condition has no engine switch); ER ladder x0.5/x1.5 at 0.30; th_loss panel cut.

The week is composed from three engine runs on the full span: each trade is taken from the run whose period contains its ENTRY second; exits keep the entry-period configuration (a trade entered in P0 and open after 08:50 keeps the P0 exit logic). Day/week lock states (give-backs, week floor, daily caps) accumulate inside each run from that run's own earlier trades; they are therefore not the mixed-config sequence on Monday. This is an APPROXIMATION and is stated in the uncertainty paragraph.
## 4. Rules common to all periods (assumptions marked A)
* Entry blocks (ET, applied as extra_skip on the entry second): NY open 09:00-09:59, Globex 18:00-18:04, Asia guard 15:00-17:59. A: applied in ALL periods including P0 (they are code/defaults already live before the week per the 10-31 user text; the directive lists them under v1.3 defaults, so P0 is uncertain; the number of P0 Sunday-night entries the 18:00-18:04 block removes is reported).
* Restart Tue 19:52-19:55 ET: A: no entry in the window; no state loss (v1.4 counters restored); WaitUntilFlat not modelled as a forced exit.
* P7 DAY-HALTED by give-back Wed 01:44 and K7 Thu ~04:35 (from the directive): NOT used as inputs; the engine's lock rules either produce halts or not; the predicted halt times are printed.
* Loss-line policy (pct <= -0.50, pulled_mult >= 30, secs_ext <= 5 -> cut) alongside the panel cut, in force from Mon 08:20 ET: A: pct is the unrealised loss as a fraction of the trade's stop distance; implemented as a second cut set from the L2SL K-rows (upnl <= -0.5 x stop_d, p5 >= 30 x median level, new extreme within 5 s), earliest of the two cuts wins, gated to cut seconds >= Mon 08:20 ET. Shifted-entry (PE 45-s / OTE) rows keep the panel cut only.
* Policy file timeline: none until Mon 08:05; 5-rule take file 08:05-08:15; empty 08:15-08:20: A: the content of the 5 rules is not recorded; this 10-minute take-file window is NOT modelled; I report how many predicted trades are open in it as a bound.
* Signal-state slots: engine has 3 rules (H6 skipBot3 sig_slope, K6 skipTop3 sig_st1_dist_atr, P6 sizeHi); the directive has 4 (K7 SkipBot3 St1Dist, P7 SkipTop3+SizeHi x1.5/x0.5 St1Dist, H7 SkipBot3 St1Dist). A: P0 uses the engine's three rules; Z1's 4-slot rank code (blind_z1/slots.py, causal expanding rank, min history 100) is run as a sensitivity and its differences reported, not substituted, unless it can be wired before the engine run (then this line is amended BEFORE the run).
* X1-X5 in P0 (2 lots each): X1/X2 (NY-AM) cannot trade before 08:50 ET; X3 (pre-open Range-8), X4 and X5 (London) as in Z1's candidate list; brackets are the library cells' (no brackets in the directive): X3 75/50, X4 75/40, X5 60/60 (X5 = EMA90/150 on 2-min as the directive says, not the scored library cell L02783).
