Mechanism per family (one sentence) and predicted effect:
* HA colour flip / strong body / 2-3 in a row / doji-then-flip: HA smoothing removes noise, so the flip is a lagged trend filter; waiting for it after the book signal costs the first part of the move -> predicted effect <= 0 per contract vs the 70/30 floor except where it avoids adverse runs (filter d).
* Renko/UniRenko reversal & continuation bricks: bricks only print on a net move of B so a reversal brick is a fixed-size momentum confirmation; predicted <= 0 market, ~0 for the limit at the brick base (structure not information).
* Range/tick/volume/dollar/delta bars (close in favour, two in a row, beyond the prior bar's extreme): activity time makes the confirmation arrive faster in fast markets; predicted ~0 vs floor, MDE ~0.3-0.5 pts.
* Imbalance/run bars (close in favour, imbalance sign): the bar closes when one-sided aggression exceeds expectation, so the sign is flow information; predicted small positive only if flow persists beyond the fee/spread (INFO cycle found a 30-s IC of 0.015-0.026 on mbp-10), otherwise ~0.
* Kagi/P&F/line break/zig-zag/LinReg/Hull/momentum-Kase: reversal/flip of a price-only trend filter; predicted <= 0.
* Footprint (delta, divergence, stacked imbalance, unfinished auction, POC migration, absorption, exhaustion): order flow at the price where it happened; predicted >= 0 only for absorption/stacked limit entries at the zone (limit gets price improvement), market ~0.
* Candle anatomy: pin/engulf/inside-break/marubozu/three-bar on 15/30/45 s are price-only patterns; predicted ~0.
Selection: per book and per (book, session), cells ranked on the N basis, 70/30 base, by the n-weighted PRE u X' mean of (cell - 70/30 plain 3-pt dip floor) per planned lot; only PRE and X' statistics are computed before the selection file is hashed. Selected = top 12 per book (ALL sessions) + top 4 per (book, session), n >= 150. ONE look at Y26/L6M/HOLD per stage, for the selected cells only. Placebos for selected cells: random-level placebo (same placement times, shuffled distances), shuffled-day events (+7 days), time-matched random events (same count per ET day). Tiers per CONFIRM/UF gates: PASS needs >= 0 per contract on N in L6M AND HOLD, PRE and X' > 0, placebo beaten, and the cumulative multiplicity-adjusted RC p <= 0.05 (cumulative starting count 143,584 + this program); otherwise CANDIDATE-RECENT or BEST-AVAILABLE-NEGATIVE.
