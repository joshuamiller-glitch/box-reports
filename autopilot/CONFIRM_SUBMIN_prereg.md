## Events (all at bar CLOSE = bar ek, or at the print/second that completes them; direction +1 supports long)
Series: 1s (print-second grid, no volume), 5s/15s/30s/45s/1m/2m/3m time bars from bars_store/tc (volume, prints, buy/sell). Periods 5 8 9 13 20 21 33 34 50 55 89 100 200. MA valid only after `n` bars since the last >2h data gap.
MA family (87 type x tf tasks): cross (every fast<slow pair, 78; hold 0 in the screen, hold 1/2/3 added for the carried pairs), reclaim (first / second consecutive close back across), slopesign (1/3/5-bar slope sign change; HMA colour flip == HMA slope-1), slopeatr (3-bar slope/bar > 0.02/0.05/0.10 ATR14), ribbon 8/13/21/34/55 (restack, exit in favour, re-enter on a pullback with stack intact), distpull (|close-MA|/ATR falls back to <= 0.5/1/2 from beyond = pullback reached the MA), distres (crosses out beyond th = move resumed). Distance in ticks: NOT run (monotone relabel of ATR within a session; stated).
VWAP family (5s..3m): anchors session(CME day), RTH 09:30, running-session-high bar, running-session-low bar, last confirmed fractal-5 swing low, swing high, last high-volume bar; events cross, reclaim2, band re-entry 1/2/3 sigma. Needs >= 20 bars since the anchor.
Movement (15s/30s/45s/1m/2m/3m): N consecutive closes 2-5; fractal-3/5 higher-low/lower-high; micro BOS and CHoCH (fractal 3); break of previous bar extreme; inside-bar break; NR4/NR7 then first close beyond within 3 bars. 1s grid: velocity (W 5/10/15/30 s change > k=2/3/4 x EWMA normal), acceleration turn (W 5/10), stall (range of last 10/15 s < 4/8/12 ticks then first close beyond). Tick speed: print-count z>1 vs prior 1h with delta+close in favour (5s/15s/30s) and burst >= 30/60/120 prints in 5s. Oscillators (5s..3m): RSI(2) 10/20, CCI(5) +-100, ROC 5/10 zero cross, in favour.
Event levels: near = reference line facing price (MA, VWAP/band, swing, NR extreme, 38.2% retrace of burst), far = event bar's extreme against, mid = average. maxage 1800 s (12 bars if longer). Mechanic d uses the STATE version (exp = next opposite event).

## Mechanisms and predicted effects (all structure unless stated)
Waiting for a sub-minute MA/VWAP event after a held signal buys a pullback-then-resume entry. Predicted: most per-contract effect is the STRUCTURE already in the plain-dip split (waiting lowers the average entry on mean-reverting signals); events add information only if micro-trend resumption predicts the next 60 pts, which prior CONFIRM stages found ~0 for bar structures. Prediction: median |delta vs floor| < 0.3 pts per contract, most cells <= 0; a few positive by chance (23k cells).
