## 7. ITEMS 5b / 5c / 5d

**5b. L92a90948, vsig minimum periods and edge (SPEC, th_grid/trig_momentum_er.py `_vsig`, `ind.edge`).** vsig[i] = sample std (ddof 1) of the last W = 60 values dq[i-59..i] (dq = dclose / sg, the diffs of q, current bar included); it is NaN until bar index 60 (needs 61 bars; the first dq, index 0, is a forced 0 and is not part of the window); a NaN vsig makes the z-gate false, so no signal. Engine signals are additionally suppressed before bar index 2000 (series start only; live code needs just 61 completed bars plus the EMA200 warm-up of section 4).
**5b (edge).** Event = state flip, not "first valid bar": up_state[i] = (ER > 0.5 and move > 0 and |move| >= vsig x sqrt(2)); event on bar i iff up_state[i] and NOT up_state[i-1] (a NaN or invalid previous bar counts as false, so a state that is already true on the first valid bar DOES fire once there; irrelevant live after warm-up). Down mirrored with its own state; a swing from an up state straight to a down state on consecutive bars gives a down event (the down state was false on the previous bar). One position per book then drops events while in a trade.
**5c. L578701ed, book snapshots with bid == ask, crossed or empty levels (SPEC, th_grid/triggers_c/featc.py grid_feats / day_features).** A snapshot is VALID only if best bid > 0, best ask > best bid (strictly: bid == ask and crossed books are INVALID), and the top bid size > 0 and top ask size > 0; deeper empty levels are allowed (size 0 contributes nothing to the size-weighted averages). The feature x at a bar uses the LAST VALID snapshot with receive time <= the bar known time (an invalid snapshot is skipped, not zero-filled); the average prices bw/aw use all 10 levels.
