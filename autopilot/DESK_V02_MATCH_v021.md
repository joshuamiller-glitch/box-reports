## 0. READ THIS FIRST: what the replay is and four defects found while writing this page
- WHAT THE REPLAY IS: a SCREEN replay of the real class on real entries (books' own signal times and brackets from the exact trade tables), second by second on the feeds files, NOT the exact engine. The class's decisions are exactly what the manager returned; the fills are a screen model (a stop crossed on the per-second NQ mid exits at that second's mid; an 'all' decision exits at the next second's mid; a part removes floor(frac x lots + 0.5) lots, at least 1, only with >= 2 lots and no earlier part; session end = flat at the last mid). The engine's own fills, lags and print-level stops are W-DYNH's and are not reproduced here. All prices below are NQ MID prices from the book quotes (feeds/age_*.parquet column NQ_mid), not trade prices.
- DEFECT 1 (units drift, affects behaviour): best open profit and the 1-minute bar list are stored in s5 UNITS AT THE TIME they are recorded; s5 (NQ typical 5-min move) is re-estimated every 10 minutes and the stored values are NOT rescaled. When s5 changes, the stage (PROBATION / CONFIRMED / FREE), the swing levels and the half-peak floor compare old-unit values with a new-unit threshold (T4 below: s5 falls from 34.64 to 27.73 points at the 10-minute bucket 15:40:02, the unit in s5 units rises from 0.65 to 0.81 while the stored best stays 0.783, so the stage falls back from CONFIRMED to PROBATION although the best was 27.1 points >= the 22.5-point unit; the same stale values feed the swing levels and the half-peak floor). The v0.2 rows ran with this. It is an implementation defect, not a design choice; fixing it changes behaviour (v0.2.2). I did NOT fix it; the relay decides. A Mono program matching v0.2.1 must reproduce it; a Mono program matching the DESIGN must store points.
- DEFECT 2 (1-lot objective): the order says the first objective takes half; with ONE lot the class only sets an internal flag (pend_struct) that is never used: NO structure tightening happens (my page's earlier statement 'becomes a structure-trail tightening only' is wrong for the first objective; for the DEFEND third it is right: the nearest-swing mode is switched on). The first objective is still counted, so the second objective takes all.
- DEFECT 3 (staleness): for the age feeds the 'stale_s' limit is compared with the second of the feed row, not with the feed's own age column, so a quote that was set long ago but carried forward on the 1-s grid is accepted; the age column is only recorded in health counters. Seconds outside the feed's grid (outside Asia and NY AM for the age feed) are missing -> NaN -> abstain / no decision.
- DEFECT 4 (FALLBACK scope, an interpretation to confirm): the order says fewer than three voting seats -> 'S1 + the never-bend rules only'. The class, in FALLBACK, disables the seat-driven actions (ABORT, DEFEND half/third, divergence, posture) but still runs objectives (stall, levels, round number, wall flag, pool, range), the clock, N3 and the never-bend floors. T5 shows it. If the relay means that objectives and the clock must also stop in FALLBACK, that is a change.
- Also: the calendar tightening (cal true) is OFF in v0.2/v0.2.1 rows; the entry gate and the stand-down are outside the manager (section 4).

## 2. EXACT DEFINITIONS (item 2) as implemented
All times are epoch seconds; 'now' = the engine second of the call. Feeds are per-second as-of series from /mnt/l2/l2vast/_dynexit/feeds/ (lag baked in; the class adds none).
### 2.1 When the class decides
decide() is called once per engine second per open trade. It returns hold at once unless mins >= 1 (mins = elapsed minutes since the fill) AND now - (last decision second) >= 15. So the first decision is at the first call >= 60 s after the fill, then every >= 15 s (in the replay: fill + 60, +75, +90, ...; in the live hook: the first call at least 15 s after the previous one). Trade start second t0 = now - trunc(elapsed seconds since the fill); the 'entry price' ent = NQ mid at t0.
### 2.2 NQ price, s5, unit, open profit
- NQ price v(s) = NQ_mid (book quote mid (bid+ask)/2) at the latest feed row with row second <= s; valid when s - row second <= 5; otherwise missing. cur = v(now), ent = v(t0). A missing cur/ent/s5 = no decision that second (counted blind).
- sigma60 ('typical 1-minute move' of NQ, points): population standard deviation (ddof 0) of the changes v(x) - v(x-60) for x = X-7200, X-7170, ..., X-30 (240 sample points; points with a missing value dropped; fewer than 31 valid -> missing), where X = the second of the FIRST call in the current 10-minute bucket (bucket = floor(now/600)); the result is cached and used for every decision in that bucket. s5 = sigma60 x sqrt(5) (NQ's typical 5-minute move, points).
- R0 = the book's own stop (points) = hook risk0 / 1.5. unit = 0.25 x R0 (points); unit in s5 units = unit / s5 at that decision.
- open o = side x (cur - ent) / s5. best = running maximum of o over the decisions (stored in s5 units AT THAT TIME: DEFECT 1). stage: PROBATION if best < unit_s5, CONFIRMED if best < 2 x unit_s5, else FREE (label RUNNER only on the log line of a structure-trail action).
### 2.3 'Typical move' and the 2-hour own-move unit of every instrument
For instrument i (ES, RTY, YM, NKD, ZN, ZB, 6J, 6E, CL, GC; same estimator as NQ): sigma60_i = the population std of 60-s changes of that instrument's own series over the previous 2 hours (240 points, 30-s spacing, 10-minute bucket cache keyed by instrument); series: ES_mid, RTY_mid (book quote mids, stale_s 5); YM_c, NKD_c, 6J_c, 6E_c, ZB_c (1-minute bar closes, as-of per second, stale_s 150); ZN_last, CL_last, GC_last (last trade price, stale_s 60). Own-move unit over horizon h seconds = sigma60_i x sqrt(max(h, 60)/60). The since-entry move z_i = side x (v_i(now) - v_i(t0)) / (sigma60_i x sqrt(max(now - t0, 60)/60)); the 5-minute pace of NQ = side x (v(now) - v(now-300)) / (sigma60 x sqrt(5)) = ... / s5. A value is dropped (member abstains) when either price or sigma is missing.
- Macro signs (S5 member z = sign x z_i): ZN -1, ZB -1, 6J -1, 6E +1, CL +1, GC -1; S3: ES, RTY, YM +1, NKD +1 (Asia only).
### 2.4 Level z-scores (TICK, stocks, ETFs, UW)
x = the value at the latest feed row with row second <= now and now - row second <= 180; z = side x (x - mean)/std where mean and std (population) are over the finite values of the same column in the rows with second in [now-7200, now]; at least 30 values required. TICK: column tick_ma5 (5-minute mean of NYSE TICK, from 09:31 ET); stocks and ETFs: the column <TICKER>_r5 (5-minute return, +120 s lag baked in) of the stocks_ feed for NVDA MSFT AAPL AMZN META GOOGL TSLA QQQ SPY (AVGO and ^NDX are not in the feed); UW: etf_tide_QQQ column diff (net call minus put premium, +120 s lag). Note these are z-scores of the level against its own 2-hour distribution, not moves divided by a typical move.
### 2.5 S2 tape: the five adverse-flow components (feeds _grid/flow1s/<YYYYMM>.npz, W-GRIDC code/th_grid/triggers_c/flow1s.py; 1 = adverse for the trade's side, per second; first 60 s of every trading day = 0):
- delta: long adverse if the 5-s delta d5 <= -max(15, 1.5 x mean|d5| of the prior 30 min) AND the prior delta (t-34..t-5) > 0 (flip from buying to selling); short mirrored.
- absorb: long adverse if the buy volume of the last 10 s >= max(40, 2 x the trailing-30-min mean of 10-s buy volume) AND the last 10 s made no new high versus the prior 30 s; short: heavy selling, no new low.
- book: long adverse if the 5-s order-flow imbalance (L1, 1-ms grid) <= -2 x the trailing-30-min std of 5-s OFI; short mirrored.
- wall (THE ADVERSE-WALL FLAG): long adverse if an ASK wall (level size >= 4 x the median of the 10 levels, within 8 ticks of the ask) APPEARED in the last 5 s (its size 5 s ago < 50% of now) or a BID wall was PULLED (>= 4 x median 5 s ago, now < 30%); short mirrored.
- speed: long adverse if the prints in the last 3 s >= max(20, 3 x the trailing-5-min mean per 3 s) AND the last price fell >= 3 ticks over those 3 s; short mirrored.
The class reads the five flags ONLY AT ITS DECISION SECONDS (>= 15 s apart); a component counts if it was 1 at the current decision second (the '10-second window' never reaches the previous decision). S2 = AGAINST if 3 or more components are on, else NOTHING (no WITH vote).
### 2.6 Seat aggregation, conviction, postures
Member vote: z <= -1.0 AGAINST, z >= +1.0 WITH, else NOTHING (1.0 = 'moved'). Seat vote = AGAINST if more than half of the VALID members are AGAINST, WITH if more than half are WITH, else NOTHING (majority, strictly more than half; ties = NOTHING); a seat with no valid member ABSTAINS. S1 members (each +2, -2 or 0, then the same majority): (a) structure, (b) pace = 2 x pace if |pace| >= 1.0 else 0, (c) VWAP side: d = side x (cur - vwap)/s5 with vwap the feeds/levels_ column 'vwap' (Globex VWAP, raw NQ, not roll adjusted): +2 if d >= 1, -2 if d <= -1, else 0. (a) structure: bars = the list of o (s5 units at the time) appended at the first decision of each new clock minute (floor(now/60) changes); a swing is bars[i] < min(bars[i-2], bars[i-1], bars[i+1], bars[i+2]) for i = 2..len-3 (confirmed once bar i+2 exists); with >= 5 bars and at least one swing: last = the last swing value, f = o now: f < last - 0.1 -> -2; else if >= 2 swings and last > the previous swing and f > last -> +2; else 0; no swing -> no structure member. S3 members: ES, RTY, YM (+ NKD in Asia; + TICK in NY), S4: the nine stocks/ETFs (NY only), S5: the six macro series, S6: UW tide (NY only).
Posture: voting seats = those not abstaining; if fewer than 3: FALLBACK (posture NORMAL, seat-driven actions off, see DEFECT 4). nA, nW = seats AGAINST, WITH. ABORT if nA = all voting seats, or (S1 AGAINST and S2 AGAINST and nW = 0); else conviction c = nW - nA: PRESS if c >= 2, DEFEND if c <= -2, else NORMAL. (S2 abstaining makes the second ABORT test false.)
### 2.7 Objectives, clock, never-bend, trail (all in s5 units from the entry unless said)
- Objectives run in profit once best >= 1 unit; each distinct trigger kind is counted once. Triggers: stall = now - (second of the last new best) > 3 x lastunit, lastunit = max(second the best first reached unit index bu - second it first reached bu-1 (t0 if none), 30 s), bu = floor(best/unit_s5); prior high/low = any of pdh, pdl, onh, onl, rth_hi, rth_lo (levels feed, raw NQ) with 0 < side x (L - cur) < 0.5 x s5 (first in that order); round number = the next multiple of 100 NQ points ahead (long: (floor(cur/100)+1) x 100; short: ceil(cur/100) x 100 - 100) with 0 < side x (nr - cur) < 0.5 x s5; wall = the S2 adverse-wall flag was 1 at this decision second; pool = W-DYNL pool_state pa_dist < 0.5 x s5 (NOT reproducible from this page: it needs W-DYNL's pool tables; in the build log it as abstain); range used = the session range rank >= 0.8 (2.8). First new trigger: take half (part, 0.5); the second distinct trigger: all; posture DEFEND (voting >= 3): all at once. With one lot the first trigger does nothing (DEFECT 2).
- DEFEND: before best >= 2 units: part 0.5 once; from best >= 2 units: part 0.34 once and the structure trail switches to the nearest swing.
- Divergence (best >= 2 units, not FALLBACK): NQ makes a new best at this decision (best > previous best) and the voting seats among S3 and S4 exist and none is WITH -> all.
- Clock (v0.2.1): in profit, T0p = tgt_ratio x R0 (tgt_ratio.json: the book's median T0/S0), N = minutes to the session bell (the strategy's flat time; v0.2.1: N <= 30 only): if max(T0p - o x s5, 0) > (s5/sqrt(5)) x sqrt(N) -> all (once). N3: in profit and N <= 1 -> all. N is session_left_s/60 from the hook (cal true would use 13:00 ET on early-close days).
- Never bend / stop levels (s5 units above entry): lvl = 0 if best x s5 >= 0.9 x T0p; if best >= 2 units: lvl = max(lvl, 0, 0.5 x best); with best >= 2 units and a confirmed swing: lvl = max(lvl, swing - 0.1) where swing = the last swing value, or the one before it when posture PRESS and the nearest-swing mode is off (and >= 2 swings), label RT; the stop is moved only if lvl > current managed stop + 0.05: stop price = ent + side x lvl x s5 (hook 'tighten' to_R = lvl x s5 / risk0, ratchet only). Broker safety stop = ent - side x 1.5 x R0, never widened.
### 2.8 Session range used
range_table.json: for each session type (Asia: Globex start 18:00 ET of the previous day, 480 minutes; NY AM: 08:30 ET, 210 minutes) and each session day key (Asia keyed by the END day), the range-to-date (max - min of the 1-s NQ closes of instr_1s from the session start) at the last second of each elapsed minute. rank = the fraction of the previous 20 table days (keys before today's key, at the same elapsed minute) whose range-to-date is <= today's; needs >= 10 previous days else missing. Built on NQ_SC closes (continuous contract, roll jumps not removed: a roll gap inflates the range on about 4 days a year). The hook uses the table value of today's day, which is the causal prefix.
### 2.9 Top-tier calendar events (entry gate blackout, and cal true)
feeds/calendar_<YYYY-MM>.parquet per second: nxt_hi_min = minutes to the next IMPORTANCE-3 scheduled event, prv_hi_min = minutes since the last. Importance 3 in events_all.parquet = five kinds: CPI (47 events), NFP (47), FOMC_DECISION (32), FOMC_PRESSER (32) and EARN_AMC (62; megacap earnings after the close). Blackout for new entries = nxt_hi_min <= 5 or prv_hi_min <= 5. The calendar is NOT used inside the manager unless cal true (not in v0.2 / v0.2.1).
