## 8. Method, placebo hierarchy and limits (read before using any number)

* **Placebo hierarchy.** (1) engine-level: random skips (or size permutations) with the same count per book x session through the same engine, 60 draws, stopped after 3 draws at or above the rule's L6M cut (rank then cannot reach 0.05), for every re-simulable cell that passes the user L6M definition (NT-3 C D L R T U, TG-1, NTE-1, NTZ; risk-off random-tighten through ro_stack with 2 exceedances); (2) trade-level paper-track random skips with the same per-book count (HALT), the stricter of paper-track and engine-cut rank is used; (3) day-level random placement of the same number of cuts with the same retained fractions (QW-2, RHQ, RO-2, risk-off cells without an engine placebo) - this is MORE lenient than (1) in L6M (29 NT-3 target cells: day rank <= 0.05 in 5, engine rank in 0), so a day-level "L6M only" label is an upper bound. Rank = (1 + #draws with a cut >= the rule's) / (1 + n draws); beating = rank <= 0.05; with 60 draws the resolution is 0.016.
* **Selection / looks.** Selection = maxDD cut >= 20% in BOTH PRE and X'; one recent look per prereg group (the recent windows are columns, not selectors). Sorting the table by in-sample drawdown, or listing "the best 10 of the 74", is post-hoc and is labelled so. Family-wise: the "expected under the volume null" column is the number of cells in the family that a same-volume random skip would pass the selection screen; where the observed count is not above it the family has no skill beyond volume. HALT is above its null (760 vs 654) because performance halts remove the right trades in PRE/X' (the 74), and that skill does not reach L6M.
* **One-week base.** The L6M base maxDD is one episode (the 2026-01-19 week), so L6M cuts of 20-70% by single rules are a statement about that week; HOLD (one month longer) contradicts many of them (maxDD deeper).
* **Equal-risk mean** = the change in mean after scaling the with-rule stack's lots linearly by c = (base worst-20 over ALL 149 weeks) / (rule worst-20), i.e. delta = c x mean_rule - mean_base. The engine lot-table rescaling (integer rounding, governors scaling) was not re-run per cell here; c is within 0.8-1.2 for the rows shown, so the engine value will differ by the rounding only. Flag: linear scaling.
* **Bases differ by family** (HALT: D6-faithful + 12R lock; QW / NT-3 / TG / NTE-1 / NTZ: D6 composite at live lots, no combined lock; risk-off: the ro_stack composite) and none is the one-convention engine with parity stop; the vs-as-is comparison (cutA_*, dA_*) in a2_master uses the QW as-is series from the same family of engines. DD-1 on the one-convention engine gives the composite L6M maxDD 23k / PRE 241k, consistent in sign with the bases used here.
* **Not scorable** (only per-trade / per-contract gains stored): see Coverage. The random samples (TG-1 400, NTE-1 400, risk-off 200) are the base rate for those unscored remainders, not a result for them. Two NT-3 cells use a nested state absent from the stored state files and keep the day-level placebo.
* **No promotion.** Every row is Shadow only. D6 vocabulary: K6 KB, P6 PE, U6 SM, H6 HM, M6 MV, A6 PB, S6 ST, W6 WT, MA6 MA; D7 = alt-bar / filter slot. A4 merges; the composite from non-overlapping RISK-KEEPs is A4's (this part supplies one sampled H6 stop-move cell and no other).
