### 9. Tie-out and method
- Null engine run (no injection), both frames: max daily difference vs the one-convention frames 0.0 / 0.0. Zero-delta, exit-unchanged injection on 5,000 random rows: 0.0 / 0.0 (`tieout_null.json`). Run before any cell.
- Every one of the 8,995 new cells: rebuilt per-trade delta equals the stored delta (max abs 3.7e-06 pt), total-gain error <= 0.4942% (gate 1%); the A6 cells are unchanged (0.0016% max).
- Engine injection, exit seconds, half-cut simplifications: exactly A6 (delta-only for half cuts and scale-out remainders that never exit early; L2SP half/lock: last kernel exit row with the summed delta).
- Placebos: (a) A1 volume-matched random skip (200 draws, 36-point grid); (b) NEW size-cut placebo (200 draws, seed 20261103): each live engine trade gets a random cut fraction g_i ~ U(0,1) scaled by a water-filled c (cut_i = min(1, c g_i)) so that the cut volume sum cut_i |net_i| equals the cell's volume share of the frame's gross trade P&L; the rule's maxDD cut is ranked against it with the same thresholds. 'Volume' = sum |delta| x engine size x PV over the cell's fired trades.
- Family-wise p: WY max-T over the full ledger of the program with the A1 volume-matched skip null (smallest attainable 0.005); the size-cut null is not used in the max-T.
- Equal-risk mean: engine lot-table secant (ALL worst-20 = baseline) for the rows of the tables and the top 80 per frame; the linear scale for every other cell (`*_ALL_er_dmean`).
- Windows: L3M 14 / L6M 28 / HOLD 32 / PRE 75 / X' 44 / ALL 149 weeks; worst-20 in L3M/L6M/HOLD is the sum of the worst min(20, weeks) weeks and is not a tail measure there. The as-is L6M maxDD (88k) is the single week of 2026-01-19, the composite's is 23k.
- Not covered (as A6): UF-LOSS C4 (48), C9 (432, engine file not located), 28 C1 extra and 42 C2 HM path-rule cells, C7/C8/C10 (stack-level files span the cap), the L2SL cut actions (exact in A1), L2SP unrun cells.
