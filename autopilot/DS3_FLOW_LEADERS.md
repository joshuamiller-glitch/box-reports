# DS3_FLOW_LEADERS - T-FLOW Part B leader columns for every D7 signal (W-AL2), FIRST PASS, data to 2026-10 signals / bars to 2026-11-13
VERDICT (data ends 2026-11-13; plain): the leader columns exist for all 193,628 universe signals (sig_id keyed, causal at the entry second) as one parquet of 93 columns; no scoring done here (W-FL1 scores). 10-second returns, VX and DX are NOT available from free history.
File: /mnt/l2/l2vast/_alpha_breadth/flow/leaders_signals.parquet (key sig_id = signals_all.parquet sig_id). Code: code/th_alpha_breadth/flow_leaders.py. Coverage 93-100 percent non-missing per column (missing = no bar within 3 minutes, e.g. halts and thin sessions).
Causality: bar i = last COMPLETE 1-minute bar (bar start <= sig_ts - 60); price = close of bar i (known at sig_ts); returns back-adjusted at rolls (roll-bar increment = 0). Every *_s column is signed with the trade side: positive = the market moved WITH the trade. No information after sig_ts is used.
Columns:
- lead_<M>_r<L>_bps_s : signed return in bp over the last L minutes, M in NQ ES RTY YM ZN ZB 6E GC CL, L in 1, 5, 15, 60. Live: ES RTY YM ZN ZB 6E: feeds D7 already has in NT8 (class B series per DS3_CONFLUENCE_LIVE_CLASS_CF2.md); NQ itself yes; GC and CL: NOT in D7's current feeds, need new instrument subscriptions (COMEX / NYMEX data on the NT8 data connection; not verified with the data vendor).
- lead_<M>_z<L>_s : the same divided by the market's trailing 390-minute 1-minute volatility x sqrt(L) (signed). Same live status.
- nqes_gap{5,15,60}_bps_s : (NQ return - ES return) x side over L minutes; positive = NQ ahead of ES in the trade direction. Live: yes (NQ and ES both in NT8).
- nqes_open{5,15,60} : 1 if the NQ-ES log-spread, measured from its trailing 1-day mean, is wider now than L minutes ago (gap opening), 0 if closing. Live: yes (needs a rolling 1-day mean of the spread inside D7).
- nqes_nq_leads{L} / nqes_nq_lags{L} : NQ moved with the trade more than ES (and positively) / ES moved with the trade more than NQ. Live: yes.
- agree_eq{1,5,15} : how many of ES RTY YM moved in the trade direction over the last 1/5/15 min (0-3). agree_all7_{L}: count out of 7 (ES RTY YM 6E CL up = with a long; ZN ZB DOWN = risk-on = with a long; signs flipped for shorts), a convention fixed before scoring. agree_gc{L}: GC alone (haven, not counted in the 7). Live: agree_eq yes; agree_all7 needs CL (new subscription) otherwise a 6-market version works with feeds D7 has; agree_gc needs GC.
