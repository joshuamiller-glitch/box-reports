## Method and assumptions (read first)
- Expected $ to date = WF weekly mean x lots/10 x f_book; SD = weekly SD x lots/10 x sqrt(f_book); z = (realised - expected)/SD. f_book = trading-hour fraction of the 115-h week since the book's first W44 entry (DS3: Mon 13:03 -> f 0.235; DS4: Tue 13:18 -> f 0.033; DS5: Tue 18:05 -> f ~0). Wall-clock fractions ignore intraday trade-density, so early-week counts are only a rough yardstick.
- Trades/wk band: there is NO 4 complete-week live history for any book (W43 is info-only, DS3/DS4/DS5 started this week), so the "4-week band" is the backtest expectation band: expected count mu = backtest trades/wk x f, 95% band mu +- 1.96 sqrt(2 mu) (Poisson with overdispersion 2; lower bound clamps at 0 for small mu so a LOW flag cannot fire yet). Assumption, chosen by D3FW; the lead can swap it.
- Expectation sources: ST/HM = Set A $24,975/wk, SD $104,500, ~35 tr/wk (register); KB / SM = WF at 10 lots, KB 16,838 (SD 59,572, 26.8 tr/wk), SM 9,130 (SD 35,530, 12.2 tr/wk) (D3L / DS3_LIVE_CONFIG); PE = library PE series WF 15,062 / SD 50,017 at 10 lots, 24.4 tr/wk (pre-lock, so an upper bound on count); MV = WF 20,608 / SD 61,129 at 10 lots, 25.2 tr/wk (HYBRID basis); DN = mapped (no direct replay), see the mix row.
- "Identity score" cannot be the replay-vs-live trade match for W44: the mbp-10 tape ends 2026-10-23, so no replay exists for W44 trades. Substitute = STRUCTURAL identity: share of scoreable exits whose points match the registered bracket (Target +59..+61 pts; TH LossExit -13..-30 pts; StopJoin -57..-63) and whose $ equals pts x qty x $20 within 5% (or $150). Real identity (exact entry/exit vs L2 replay) is PENDING_TAPE; it becomes computable only after the weekly tape extension.
