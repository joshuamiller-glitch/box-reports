* Data: in-trade states use the dp1m/ldp1m decision rows of the 11 library books (profit 1,121,215 rows thinned 1-in-3; under water 667,083 thinned 1-in-5; 737 label days), features = full l2feat t1+t2+t3+t4+vpin (642 usable columns) + seq + lean; signal state = 35-42k unique (entry_ts, side) signals (ABR entry table), unconditional = 405,556 one-minute marks (20% random label days + signal-day RTH), both with features_at tranche-1 library + D6 gates + seq + lean (269 columns). Targets from the NQ 1-s mid (mid-to-mid, hi/lo for first passage, +-5/10/20 within 1800 s).
* Walk-forward: 10 quarterly re-fits (2023-10-01..2026-01-01), fit rows closed (ts + 1800 s <= refit). Models R, E, G, C (control), H, Q as preregistered; hyper-parameters fixed. Placebos: shuffled-book (within label day), time-shifted (60 s earlier; evaluated on rows that have a 60-s-earlier row, with the real model on the same rows).
* Sequence model Q: scikit-learn MLP (128-64) on the 7 x 15 window + lean + context, fit on PRE, early-stopped on X', evaluated once on HOLD (L6M, 2026 subsets); it is NOT a GRU/TCN (no torch on the box; installs not allowed). Result: IC <= 0.009, AUC 0.50.
* Statistics: Spearman IC on within-window ranks, day-clustered bootstrap (B=300), AUC by rank identity; n_eff = 1/se^2 (the independent-day count, ~25-75k for in-trade 30-s targets vs 200-400k rows); BH within state x window x session over features x 7 targets; cumulative tests reported in 1i. With ~4,500 tests per cell family about 225 false positives at 5% are expected; in-profit has 521 q<0.05 in L6M (almost all of them IMB/micro-price/FLOW variants of the same signal), under-water 83 (fewer than the 224 expected by chance at nominal 5%: no breadth of signal), signal 55, unconditional 279.
* Session slicing uses the within-window ranks (rank-transformed Pearson), not re-ranked inside the session.
* Rows beyond the horizon at the end of a UTC month / the cut are dropped (last 30 min). t2/t3/t4 are not built for signal/unconditional seconds (builders keyed to trade rows).
* Disclosure: during pipeline tests a one-month target sanity table and a 60-resample univariate run on the signal state printed window max|IC| counts including 2026/L6M/HOLD; no choice depended on them. The headline models were chosen on PRE+X' (selection sha256 ec7ffedde736e617df19f37bce2148a16fe340245c3b104469b8f375f357e82d logged in DECISIONS.md before the final evaluation). Recent windows were evaluated once.
* Mid-to-mid moves exclude the bid-ask cost, so the IC of micro-price features is partly the known micro-price-to-mid relation; per-contract translation applies the live cost model.

## 4. Limits and what this does not cover
* Gains are vs hold-to-bracket on the library path: rem_pts from the decision row; unfilled rests are cancelled and re-rested at the next qualifying minute row (rows thinned 1-in-3 / 1-in-5, so the first fill can be up to 2-4 minutes late).

* Entry-side resting limit and size/skip rules with the book were scored in L2EA/L2EB/DIPENTRY and UF-ENTRY C1-C6 (limit-join, split dips); not repeated here.
