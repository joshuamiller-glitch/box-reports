# DS3_L2_INFO PREREG - cycle 1 (INFO agent, 2026-10-30). Written BEFORE any outcome statistic was read (only row counts and one-month sanity checks of target distributions, no IC/AUC of any feature or model).

## Question
Does the order book predict the next move, per contract, out of sample, recent first? Information map (no rule is scored). Rules are written only if OOS IC > placebo AND per-contract expectation > measured cost in L6M and HOLD.

## Cells (exact lists)
STATES (4): sig = every signal second (unique entry_ts x side of the 11 library books' base trades = ABR entry table; T = entry_ts, direction = signal side); prof = every in-trade 1-min decision row in profit (dp1m, thinned 1-in-3 by ts//60 % 3); uw = every in-trade 1-min row under water (ldp1m, thinned 1-in-5); unc = 1-min marks of a random 20% of label days (seed 20261030) + RTH of the other signal days (side=+1, absolute direction).
TARGETS (7): m10, m30, m60, m300 = side-signed NQ mid move over the next 10/30/60/300 s; w5, w10, w20 = favourable +-x pts level reached first within 1800 s (1 fav / 0 adverse / NaN neither or both in one second).
FEATURE FAMILIES (11, assigned by name rule in info_eval.family()): IMB (imbalance, cumulative depth, depth_rel, d_imb, depth_press, rel_*), WALL (ahead_L*, behind_L*, maxlv*, wall_*, gap*, convex, slope, entropy, HHI, rnd*, cum_to_*), FLOW (delta*, ofi*, vol/intens, big/cnt/net prints, sweeps, last5, kyle, cvd, vpin, eff/real spread, cons/vwap), QUEUE (MBO-derived 1-s add/cancel/refill aggregates: cons_*, refill_*, can_*, iceberg*, nclr*, pulled_*, added_*, eobi*, cancel_*, otr60, int_ratio_*), FOOT (fp*, sess_*, vap*, vp_max*), XMKT (es_*, rty_*, esnq_*), TZ (t4 z_* and d60_*), LEAN (book 20 s before the last MFE/MAE/local extreme), SEQ (15 channels x 7 snapshots over the last 60 s at 10-s steps), GATE (D6-LIVE gate inputs g1..g8, rel_tot8; sig/unc only), MISC (spread, micro-price, exit-slip, ob_*, others).
MODELS (per state): R = ridge on all features (7 targets); E = elastic net (m30, w10); G = LightGBM (7 targets, num_threads=1); C = LightGBM on no-book context only (m30, w10; the control: information = G - C); H = discrete-time competing-risk hazard (LightGBM multiclass, intervals 0-60/60-300/300-1800 s) for +-10 first (scored vs w10); Q = sequence model on the 60-s window (see deviation) for m30, w10: ONE fit on PRE, validated on X', evaluated once on HOLD/L6M/2026. = 4 x (7+2+7+2+1+2) = 84 model cells.
Walk-forward: refits at 2023-10-01, 2024-01-01, ... , 2026-01-01 (10 refits, 3-month steps, expanding window from 2023-04); a row is in a fit only if ts + 1800 s <= refit time (outcome window closed). Fixed hyper-parameters (no tuning): ridge alpha = 0.005 x n_train on standardised features (NaN -> 0, clip +-5 sd); enet alpha 0.01 l1_ratio 0.5 (<= 200k rows); LightGBM 150 trees, lr 0.05, 31 leaves, min_data_in_leaf 500, feature_fraction 0.3, bagging 0.5, max_bin 63, <= 400k training rows; regression targets winsorised at train 0.5/99.5 pct.
PLACEBOS (each model cell evaluated 3x): real; SHUFFLED-BOOK (book/seq/lean/gate feature rows permuted across seconds within the same label day and state; context columns kept); TIME-SHIFTED (all book features taken from 60 s earlier). Gap real - placebo = information.
WINDOWS (own masks): 2026 = 20260101..20260206, L6M = 20250801..20260206, HOLD = 20250701..20260206, PRE = 20240201..20250630, X' = 20230401..20240131 (OOS part: from 2023-10-01). SESSIONS: ASIA LONDON PRE NY-AM NY-PM CLOSE by ENTRY session (in-trade, sig) / by clock (unc).
STATISTICS: Spearman IC (rank-transformed within window, day-clustered bootstrap B=300 over label days), AUC for binary targets (rank identity, same bootstrap), BH-FDR within each state x window family over (features x 7 targets), cumulative test count reported, effective sample n_eff = 1/se_boot^2.
SELECTION DISCIPLINE: features/models are chosen on PRE and X' OOS predictions only (selection file written and hashed in DECISIONS.md before the recent windows are read); recent windows are read once.
PER-CONTRACT TRANSLATION: top-decile / top-quintile (and bottom for exits) of the OOS prediction, thresholds from earlier OOS quarters; expected favourable move minus cost: entry market +1 tick = 0.25 pt + fee 0.242 pt RT; market-class exit 1.0 pt; stop-class 2.45 pt worse than nominal (stress); limit targets 0.
## Predicted effects (before seeing data)
* FLOW (delta/ofi) and short-horizon IMB: IC +0.01..+0.04 at 10-60 s, fading by 300 s; the strongest single-feature families; shuffled placebo IC ~0 (|IC| < 0.005), time-shifted placebo retains roughly half to two thirds of the real IC at 10-30 s (book state persists).
* WALL/FOOT/XMKT/LEAN/QUEUE: |IC| < 0.015; ES book imbalance (XMKT) the only non-trivial one (earlier map: adj t +4.0 for losers).
* Models: OOS model IC at 30 s 0.02-0.05 in prof/uw/unc, lower in sig (few rows); sequence model <= LightGBM; hazard AUC for +-10 first 0.51-0.53.
* Per contract: top-decile expected 30-s move +0.3..+1.0 pt gross; after cost (0.5 entry, 1.0 exit) NOT enough to trade in every state; no rule candidates expected.
## Deviation declared in advance
* No torch/tensorflow on the box and no installs allowed: the sequence model is an MLP (scikit-learn, partial_fit, hidden 128-64) on the full 7 x 15 window (+ lean, context) = a fixed-window dense equivalent of a TCN, not a GRU.
* Raw MBO is NOT on disk (events_L13 holds levels 0-2, RTH only; no order ids): the MBO-derived data used are the 1-s add/cancel/refill/sweep aggregates per side and level bucket (QUEUE, SEQ channels). Order lifetimes, cancel bursts, fleeting share, queue position, hidden size cannot be measured.
* t2/t3/t4 tranches are keyed to in-trade rows; for sig/unc the feature set is the tranche-1 library via features_at (136 columns incl. ES book, pulled/added), the 54-column D6-LIVE gate table, seq and lean.
