# DS3_OPEN_B2_HARNESS - T-OPEN block (ii) shared harness: design, audits, control rows (D3O1, 2026-10-27/28)
Research only; no live/chart/execution-server change, no credentials, no purchases, no deletions. API and exact definitions: `l2vast/ds3/code/open2/README_OPEN2.md` (sha256 in DECISIONS.md). Code: `l2vast/ds3/code/open2/`; data/outputs `l2vast/ds3/out/topen_b2/`.

## 1. Design (one paragraph per piece)
- **Input**: an event list (ld, side, t_sig = ET second at which the signal is known; optional rule origin t0, height H, per-event stop/target prices, stop-entry level). Families (3.1-3.9) only build event lists; the harness does the rest. Coverage: label days 2023-02-10..2026-10-23 for the path/tape, 2026-10-16 for the stack calendar (953 days; later days are not scored). Quote/print arrays 09:00-12:00 ET (962 days), path to 16:00 from the DS2 1-s sample path (46.4 M samples).
- **Two bases, always stated** (the verdict is the lower tier of the two): **M** mapped conservative (entry = first print of the signal second = bar open; nominal 1-s exits at exact levels, firmlib gap rule; net = nominal + min(P9 exit-type correction by year, 0) - commission 4.84/lot - s113 sweep surcharge >14 lots; the +2.6..+4.2 stop-exit credit is NOT given); **T** tape-direct-style (signal second + 1 s; buy = max(ask at arrival, first print of the fill second), sell mirrored; stop exits give up 1 tick beyond the stop and use the previous close on a gap; targets need a print 1 tick through the level; time/flip exits give up 1 tick; no correction credit; stop-entry = first print through level+1 tick, fill max(level+1tick, first print)). Neither is a real-book replay: direct L2 replay (open_direct.py, orchestrator via corepool) is block (iii)+ for survivors.
- **12-cell bracket core** CORE12: F30, F45, F60, ORX (S=T=OR/drive height), VWAP, ONHL, T1030, T1200, HOLD (16:00), STRAIL (Supertrend(10,3)-1m ratchet), CHAND (2.5 x ATR22-1m), SCALE (50% at +45 pts, runner to breakeven then Supertrend trail; two engine rows). Fixed 10 lots (fixed-R $12k/$6k available). One kernel (numba) for all; stop beats target within a second.
- **Lock engine**: sl_lib semantics (per-book day entry test -2R/+5R realised, day give-back 2R/50% on the 1-s mark-to-market, week floor -12R), two rule rows: `stk` (the stack's per-book dollar thresholds, R = $12,000) and `own` (R = lots x median stop x $20). Engine identity reproduced: the D3SL baseline stack WF = $48,560/wk, SD 142,165, maxDD 731,292 exactly.
- **Stack lines**: the LIVE stack = D3SL stack (ST10+HM10+WT7 at 1.0, KB+SM+PB3B_R5_P1 with the frozen monthly inverse-SD weights, DS3 peak 23 lots) with entries 09:00-09:59 removed in every book. IMPORTANT FINDING: the D3SL baseline (books.pkl) DOES trade 09:00-09:59 (ST 1,041, HM 548, KB 838, SM 248, PB 857 entries), while the live stack is flat there. Three stacks are kept: live (blocked), live30 (only 09:30-09:59 un-blocked, 09:00-09:29 still blocked), unblocked (= D3SL as published). WF (142 wk): live $44,867/wk SD 134,246 maxDD 548,152 Sharpe 2.40; live30 $50,711 / 138,780 / 571,383 / 2.6; unblocked $48,560 / 142,165 / 731,292 / 2.5. A cell is added as `live + cell` and compared on mean, SD, maxDD, worst week, Sharpe with paired week bootstrap CIs and MDE; also against unblocked and live30 (the un-block question).
- **Placebos** per variant, 16 draws: (a) timing destroyed (random other days); (b) same rule at a random origin 11:00-11:30 (>=60 min from 09:30 and the 10:00/14:00 slots, NY session, durations relative); (c) random-in-regime (conditioned variants); (d) bracket-beta control (random direction, same days/times/brackets) - added because stop-clipped random-side trades have a convex payoff (table below). Cheap gates first: (a),(c),(d) only for cells that pass mean_up, 2x cost, stack_add_pre and year share (a failing cell is DEAD anyway); (b) for every cell (best-of-N null). Best-of-N null = per-draw maximum over cells, family-wise over the whole registered grid (inverse-transform scaling to N_total) plus a prereg-group line.
- **Gates (never softened)**: mean_up, beats_b (CI lower > 0 and rank >= .95), beats_beta, beats_c, stack_add_pre (d_Sharpe>0, CI of d_mean lower>0, d_maxDD<=0), cost2x, year_share<=60%, neighbours (>=75% adjacent-parameter cells with d_Sharpe>0), hold (HOLD mean>0, d_Sharpe>0, effect vs (b)>0), span2 (2023-04..2024-01), best_of_N. PASS all; CANDIDATE all but best_of_N; DEAD otherwise with the failed list. Holdout: one look per prereg group (pre text with WFPRE numbers only -> `s48score.log_holdout_look` -> final), trials appended per group.
- **Reporting columns per cell**: weekly mean/SD/Sharpe/maxDD/worst/L8W on WFPRE, WF, HOLD, X; trades/wk; win rate vs required; avg win/loss; PF; interaction tables (year, dow, VIX tercile, opening type at 09:35 and 10:00, gap class, 08:30/10:00 release flags, FOMC, opex, month end, long/short; pre-open features are joined as conditioning columns in the family reports); 2x cost; mirror rows; duplicate flags; executability flag; MDE and forward weeks to settle = (2.8 sd_diff/d_mean)^2.

## 2. Audits (all 0 mismatches unless stated)
1. **Identity vs the ST/HM row machine** (`o2_ident.py`): kernel M basis vs firmlib.sim_rrt on 60/60, 30/30, 45/45 brackets, 5,438 random 09:30-11:30 bar-open entries (stop/target exits): entry sample, entry price, exit sample, exit price: 0 mismatches.
2. **Truncation / poison / as-of** (`o2_audit.py`, `out/topen_b2/audit_open2.json`): (i) Supertrend/ATR22 at bars <= b identical when bar arrays are cut at b: 22,100,814 cells, 0; (ii) kernel: 1-s path after a random cut sample and the indicators of later bars replaced by random numbers, 727 legs (9 brackets x 2 bases, 120 events) with exit before the cut identical, 0 mismatches; positive control (poison starts 1,500 samples early): 107 of 107 legs exiting inside the leaked span change; (iii) entry fills with quote/print rows after the fill second set to NaN: 240 of 240 unchanged; (iv) developing VWAP as-of the last complete minute equals the VWAP recomputed from minute bars with start < t_sig: 60 of 60.
3. **Independent family replay** (`o2_xfam.py`; own pandas/numpy code on nq_min + the per-second tape parquet, no harness import): OR5 + first 1-min close outside + F60, basis M, 842 independent trades resolving before 12:00; 836 matched on day; side 0 mismatches; 821 of 836 identical in entry price, exit second and exit price; the 15 remaining are roll days where the DS2 path differs from the library space within the day (mode-offset correction leaves <= 1.25 pts).
4. **Bug found and fixed before any holdout look**: the DS2 sample path differs from the library-adjusted tape/levels space on 15 roll days (offset up to 8.5 pts); the first version of the ORbase run (35 of 81 variants, abandoned in `out/topen_b2/grp_ORbase`, never read) used unshifted levels/quote prices; fixed with `o2_core.off2`, block recomputed in `grp_ORbase_v2`. No prereg parameter changed.
5. Disclosures: the harness smoke test printed OR5m_c1 WFPRE numbers (four M cells); the control tables below printed WFPRE and HOLD columns (controls, not cells, no holdout look claimed); dry-run output of the report code over the first ORbase pickles was written (`*_dry*`, not read; file deletion is not permitted by the rules).

## 4. Power
Stack weekly-mean MDE of one cell (80% power, WFPRE 75 weeks) is about 8,000 $/wk (sd of the weekly difference ~25,000 $/wk), 13,800 for HOLD-bracket cells; per-trade effect vs a placebo about 8.5 pts (10-lot-equivalent, n~360 in PRE). Family-wise best-of-N over thousands of cells raises the bar further. A null here reads: 'could not have seen a stack gain below about 8k $/wk'.
