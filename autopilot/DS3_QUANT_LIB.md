# DS3_QUANT_LIB - shared quant-validity library (QL-1, 2026-10-30)

Importable now: `sys.path.insert(0, 'l2vast/ds3/code/quant'); import qv`. Files: l2vast/ds3/code/quant/{qv.py, README.md, tests/test_qv.py, validate_known_cells.py, validation_output.txt}.

## What it is
One module, no data access, capped at label day 20260206 (rows after are dropped / refused), own window masks. API follows the per-trade frame (date, week, book, session, pts_N/M/LIVE_CAL/LIVE_P9, lots, optional entry/exit ts) and a cells x trades matrix. Section map in README.md: (1) White RC + Romano-Wolf stepdown, DSR, PBO (CSCV), MinBTL, `program_validity` one-call wrapper with cumulative Sidak; (3) purged k-fold (1-day embargo), CPCV + path assignment, anchored/rolling 3/6/12-month walk-forward with fold dispersion; (4) day/week clustered SE, block bootstrap CI (days/weeks), Newey-West t, ACF, effective n; (5) placebo primitives + rank among >= 200 + `placebo_suite` that reports MISSING placebos; (6) +-25/50% scan, knife-edge flag, 8-neighbour mean, timeframe neighbours, bases side by side; (7) rolling 3-month drift series, quarter sign count, half splits, regime split with works_in; (8) cost columns (0.242 / 2.45 / 0.5), breakeven, capacity with <10-contract flag, trades/week, top-5% share, longest losing run, skipped-signal P&L, stack correlation, marginal Sharpe / worst-20-weeks; (9) IC + day-clustered t, decay 10 s..60 min, IC vs shuffled/shifted, hit rate vs base, calibration deciles, Brier skill, 1- and 2-feature distillation; (10) delay hook (1 s / 3 s), 2-s slice schedule, queue-position fill model STUB (uncalibrated until fit on live fills), live reconciliation; (11) `header()` with all 25 section-5 columns and `promote_ok` (False when any column is missing/NaN/empty), `write_recent_wins()` with the same columns.

Unified from: bars_cand/bc_rc.py (RC/RW, PBO, MinBTL), bars/bars_qv.py (DSR, NW, bootstrap CI, top-5%, quarters), decay/rc/rc_stats.py (studentised RC/RW), confirm/cf_b_qv.py (day/week SE, block bootstrap, scaled-level sensitivity), decay/sd_stats.py (day x session cluster SE, MDE = 2.8 SE), UF_TRIALS.json cumulative count (`trials_total`). The local copies are untouched; migration is optional.

## Known limits (stated, not hidden)
* `capacity` participation fraction (0.25 of median top-5 depth) is an assumption; depth vectors must come from the caller. `QueueFillModel` is a stub until fit on live calibration rows. Entry-slip / stop-hit vectors are caller-supplied; missing inputs stay NaN and block promotion.
* Shuffled-size-bar placebo remains bar-specific (bars_cand/bc_placebo.py). Strategy re-runs for delay/placebo/sensitivity are the caller's eval function.
* A cell with non-positive total gain has an undefined top-5% share, so it cannot pass `promote_ok` (intended: nothing to promote).
* PBO needs > 2 cells and enough periods (>= 10 slices).
Question: none.
