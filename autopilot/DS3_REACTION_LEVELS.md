## 5. Exact D7-ready definitions (all causal; inputs are bars and, for the profile, 1-s or tick volume)
**D7-RL1 fractal event.** Inputs: closed bars of TF in {5m, 15m, 1h} (epoch-aligned, ET-hour aligned). n in {1, 2, 3}. A bar j is a fractal high if high[j] > high[j-q] and high[j] > high[j+q] for q = 1..n (strict); low symmetric. Known at the close of bar j+n (never earlier). Size = |price_j - price of the latest opposite fractal of the same (TF, n) with pivot index < j| (bar range if none; floor 0.25 pt). NT8: computable (Swing-type indicator with Strength n; the opposite-pivot size is one extra array).
**D7-RL2 density.** G(p) = sum over events e with confirm time in [00:00 of the Globex day (18:00 ET) N trading days back, now) of size_e x 2^(-(now - t_e)/10 days) x max(0, 1 - |p - p_e| / 4.25 pts) on a 0.25-pt grid, N in {5, 20, 60}, recomputed at every 5-min bar open (now = that open). Range R = [lowest low, highest high] of the closed 5-min bars of the same window. Thresholds q80, q90, q95 = nearest-rank percentiles of G over every grid bin in R. Peaks = bins with G >= G(left) and G > G(right), suppressed at +-4 pts (higher survives). Band class 1 / 2 / 3 = peak G >= q80 / q90 / q95. A band is a LINE at the peak bin. NT8: computable (custom indicator; event arrays plus a 0.25-grid float array, sort of up to ~10k bins per bar close). Not computable differently: nothing; the cost is the percentile sort.
**D7-RL3 composite profile.** For each of the N (5, 20, 60) previous COMPLETE Globex days, the volume profile on 0.25-pt ticks with each 1-s bar's volume spread uniformly over [low, high] of that second (NT8 with tick data can use the exact traded price; the 1-s spread is the research approximation: values will differ slightly). Composite = plain sum; density = triangular kernel +-4.25 pts; HVN class k = local maximum (min distance 4 pts) at >= q80/q90/q95 of the range; LVN class k = local minimum at <= q20/q10/q5 of the inner range (price percentile 5%..95% of cumulative volume). Refreshed once per Globex day at 18:00 ET. NT8: computable (VolumeProfile on tick data or a custom tick accumulator).
**D7-RL4 rules scored (all DEAD; definitions for the registry only).** ahead(set, D): nearest band between entry and target within D pts -> skip | target band-0.5; behind(set, B): stop to band+0.5 (2 <= new < old, lots unchanged); at(set, R): take only if a band within R; chooser(set, cap): target = nearest band 30..cap ahead minus 0.5. D6 vocabulary (group 05): `entry book session poi_ahead(type=RL.<map>.<lb>.p<pct>, D) -> skip | target poi-2t`. None is proposed for D6/D7.

## 6. Validity, limits, questions
* QUANT header columns are filled for the carried rows where they exist (per-contract CI, windows, trades per week, placebo ranks, RC / RW / DSR / PBO of the program, neighbours not run because no cell passes NOW-ONLY): no cell is promoted (promote_ok False by design: NOW-ONLY fails, capacity not assessed - new re-target / stop fills have no depth measurement).
* Stack limitation: re-target / chooser / tight-stop rows re-simulate the fired rows on the 1-s path with the cf_run split kernel and add the DIFFERENCE to the engine row (identity test: a no-change re-target gives exactly 0 delta); PE NY-AM / NY-PM confirmation entries keep their original bracket. Equal-risk uses uniform scaling of the weekly series.
* Fade simulator: market entry at the close of the decision second + delay, measured cost lumps (target correction 1.4 / 1.5 / 4.2 / 4.3 pts applied to small 8-30 pt targets is pessimistic; the N basis, target correction 0, is also negative in every cell); gross edge is essentially zero (49.7% target vs 48.9% stop at 8/8); the only faint signal is the profile HVN set (edge +1.7 points of trades at 8/8, rank 0.99 against random-level bands) and it is far below the 0.6-0.7 pt cost wedge (N basis -0.60 pts per trade).
* Questions (structural, not blocking): none required. If a different reading is wanted for "a 95th-pct band": percentile over only the bins with density > 0, or over the price range within +-100 pts of the snapshot close, would raise the fire rate near price; the placebos suggest it would not create an edge.
