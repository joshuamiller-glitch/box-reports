# R8 PREREG (REDO-R8, 2026-11-09 ~21:30Z) - live books' own signal parameters, dressed. Post-hoc, Shadow only, no PASS claims.
Scope: KB (Keltner ema 10-30 x mult 1-3 x bar 1/3/5, + ATR 7/14/20), SM (ATR 7-21 x mult 2-4 x bar 5/10/15), HM (fast 9-34 x slow 34/55/75 x bar 1/5 x VWAP anchor fixed|session, + EMA 100/400/off), MV (thr 0.25-1.0 x votes 2-5, + lookback sets), PE (P7 Pb3: regime bar 5/10/15 x arm 15-60 x T1/T2 x EMA 10-40 + regime ST atr/mult), PB (A7 Pb7: regime bar x arm x depth 0.25-1.0 x T1/T2), OD (O7 arm 0.25-1.0 x last-entry minute 09:42-09:59). The live parameters are the REFERENCE row of each grid.
Method (first-order SCREEN, label PRE-PROOF): (1) signals regenerated on the 1-min NQ store with the live arithmetic (r8_sig.py); (2) naked 60/60 (O7 40/90, 16:00) 1-s bracket outcome with live time blocks, one position per book, 16:55 flatten, lots = DS7 session table x slot/B02 halves x ER Q1-A (r8_sim.py), ROLL-EXCL weight 0 for trades spanning a >20-pt roll gap; (3) DELTA METHOD: dressed book = S1b-COMB book + r_b x (naked cell - naked live) with r_b = clipped weekly regression slope of the COMB book on the naked live series (how much of a naked change survives the book's own state cut, sizer, zones, locks); stack = COMB stack with the book swapped (r8_score.py).
Ranking key (standing rule 2): key_eq = mean of the stack's equal-mean maxDD cut on L6M, L3M, L1M (drawdown first), key_lots = same at equal lots; then mean tie-break; PRE/X' tolerant via Z.prior_info (rule 2a); bi-weekly WF = Z.wf_biweekly on the stack (trailing 26 w -> next 2 w, purge 7 d, lowest trailing maxDD among the book's cells, live default); family null = shared random circular week shift of all cells' deltas (300 draws), statistic = L6M equal-mean cut, p_fam_best = P(max over cells >= observed max); held-out frozen live week = 2026-11-02..05 delta vs live.
Plateau: a cell is a plateau centre only if >= 75% of its +-1 grid neighbours have key_eq >= 80% of its own (>= its own - 0.5 pt when its key is <= 0). A change is RECOMMENDED only when: best cell is a plateau centre AND differs from live AND recents key_eq > 0 AND OK-PRIOR (rule 2a) AND bi-weekly WF beat% >= 50 with cut > 0 AND p_fam_best <= .10 AND live-week delta not worse than -1 weekly MDE. Everything else: live stays. EXACT only for the plateau centre (KB 3-min and SM 10-min via fd_hooks; others need new hooks, r8_hooks.py).
