## 1. Rule (NT8, OnBarClose on a 1-minute NQ series; 10-minute aggregates built from the 1-minute bars)
All inputs are back-adjusted NQ 1-minute bars (MergeBackAdjusted, volume roll). Time ET; NT8 stamps bars with their END time; "open time" = end time minus 1 minute.

**1.1 10-minute bars (as-of rule).** Bucket = floor(epoch minute / 10): clock-aligned on :00, :10, :20 ... ET (identical to the 18:00 ET session anchor; ET differs from UTC by whole hours). A bucket is the set of 1-minute bars present with that bucket number; its close = the close of the LAST PRESENT 1-minute bar in the bucket; only the close is used (no open/high/low/volume/hl2). The 10-minute series is continuous: it runs across the 17:00-18:00 break, weekends and holidays without reset (a bucket is never split by the break because 18:00 is on the grid). A bucket is "completed" when its :x9 1-minute bar has closed; the signal is evaluated on that bar (OnBarClose of the 1-minute series), never on an unfinished bucket. If the :x9 bar is missing no entry is possible for that bucket (rule 1.5), because the next bar is then not exactly one minute after the last bar of the bucket.

**1.2 Input and parameters.** p[j] = close of 10-minute bar j (j = 0, 1, 2, ... over the whole series). Ehlers MAMA/FAMA with FastLimit = 0.5, SlowLimit = 0.05.

**1.3 Recursion (exactly as scored, tr1_sig.mama). All state arrays are 0 for indices < 7. For j = 0..6: MAMA[j] = FAMA[j] = p[j] and nothing else is computed. For j >= 7:**
- Smooth[j] = (4 p[j] + 3 p[j-1] + 2 p[j-2] + p[j-3]) / 10
- adj = 0.075 * Period[j-1] + 0.54
- Detrender[j] = (0.0962 Smooth[j] + 0.5769 Smooth[j-2] - 0.5769 Smooth[j-4] - 0.0962 Smooth[j-6]) * adj
- Q1[j] = (0.0962 Detrender[j] + 0.5769 Detrender[j-2] - 0.5769 Detrender[j-4] - 0.0962 Detrender[j-6]) * adj
- I1[j] = Detrender[j-3]
- jI = (0.0962 I1[j] + 0.5769 I1[j-2] - 0.5769 I1[j-4] - 0.0962 I1[j-6]) * adj; jQ = (0.0962 Q1[j] + 0.5769 Q1[j-2] - 0.5769 Q1[j-4] - 0.0962 Q1[j-6]) * adj
- I2[j] = 0.2 (I1[j] - jQ) + 0.8 I2[j-1]; Q2[j] = 0.2 (Q1[j] + jI) + 0.8 Q2[j-1]
- Re[j] = 0.2 (I2[j] I2[j-1] + Q2[j] Q2[j-1]) + 0.8 Re[j-1]; Im[j] = 0.2 (I2[j] Q2[j-1] - Q2[j] I2[j-1]) + 0.8 Im[j-1]
- pr = Period[j-1]; if Im[j] != 0 and Re[j] != 0: pr = 2*pi / atan(Im[j]/Re[j]) (plain arctangent in radians, NOT atan2; it can be negative); then, in this order: if Period[j-1] > 0 and pr > 1.5 Period[j-1]: pr = 1.5 Period[j-1]; if pr < 0.67 Period[j-1]: pr = 0.67 Period[j-1]; if pr < 6: pr = 6; if pr > 50: pr = 50
- Period[j] = 0.2 pr + 0.8 Period[j-1]; (SmoothPeriod[j] = 0.33 Period[j] + 0.67 SmoothPeriod[j-1] is computed but not used)
- Phase[j] = atan(Q1[j]/I1[j]) * 180/pi if I1[j] != 0, else 0 (NOT the previous phase); DeltaPhase = max(Phase[j-1] - Phase[j], 1.0); alpha = max(FastLimit / DeltaPhase, SlowLimit) (no upper clamp; alpha <= 0.5 since DeltaPhase >= 1)
- MAMA[j] = alpha p[j] + (1 - alpha) MAMA[j-1]; FAMA[j] = 0.5 alpha MAMA[j] + (1 - 0.5 alpha) FAMA[j-1]
Reference implementation of exactly this text: l2vast/ds3/code/x_tr1.py mama_fama() (plain Python lists, ~35 lines); the NinjaScript port should be tested bar-by-bar against it.

**1.4 Signal (cross on the CLOSED 10-minute bar).** sg[j] = sign(MAMA[j] - FAMA[j]) in {-1, 0, +1}. Long signal on bucket j iff sg[j] = +1 and sg[j-1] = -1 (MAMA crosses above FAMA); short iff sg[j] = -1 and sg[j-1] = +1. A change through 0 (sg 0 between two non-zero values) is NOT a cross (equality essentially occurs only in the first 7 bars, where MAMA = FAMA = p). The state is evaluated on every bucket whether or not a trade is open or the clock is blocked; signals at an open trade are dropped (1.6), never queued. Library artefact: signals on bucket indices j < 300 of the library's own series are suppressed (the library series starts 2023-02-08 23:00 UTC, first allowed signal Sunday 2023-02-12 22:30 ET); in NT8 this mask has no counterpart and the first 300 buckets of the live chart should simply be skipped after a cold start (section 1.10). Long and short symmetric (49.5% / 50.5% of entries).

**1.5 Entry.** Market order at the OPEN of the 1-minute bar after the bucket's last 1-minute bar (entry bar = last bar index + 1), valid only if that bar exists and starts exactly 1 minute after the last bar of the bucket (so there is no entry across the break, a halt or a missing :x9 minute). Signals whose last-bar OPEN time is 15:00-17:59 ET are discarded (signal-time block: the bucket 14:50-14:59 passes, buckets from 15:00 do not; the entry of the 14:50-14:59 bucket is stamped 15:01 and is then removed by the lock engine). The lock engine additionally removes entries stamped (bar end time) 15:00-16:54 and 18:00-18:05 ET (raw list: 35 entries at 15:00-16:54, 0 at 18:00-18:05). 10 lots as 10 x 1-lot market slices 2 s apart in the direct pricing (S10x1_g2), as the other DS3 books.

**1.6 One trade at a time.** One position: a signal whose entry bar is <= the exit bar of the open trade is dropped; an opposite cross while in a trade is ignored (no reversal; the position leaves by target, stop or the 16:55 flat). Of 6,778 replay crosses (5,678 library events) 2,976 library entries remain.

**1.7 Bracket (DS2 bracket, fixed 60/60; stopm 60, tgt 1.0R, read from te_core.gen_entries):** stop-market 60 pt and limit target 60 pt OCO from the entry (bar-open) price; stop exits worked as touch-join for 3 s then market (XJ3, unvalidated live). Flat 16:55 ET (market at the close of the 1-minute bar ending 16:55; early-close days at the final bar), applying only to trades alive before 18:00: a trade entered 18:00-23:59 or 00:00-14:59 runs until the target, the stop or the next 16:55 (maximum hold 1,254 min; median 75 min, 90% 466 min, 99% 892 min). Replay convention when both levels fall in one 1-minute bar: the stop is taken (the library resolves it on the 1-s tape).

**1.8 Sessions / mix:** by entry-bar end hour: 9.9% 00-02 ET, 23.1% 03-08, 7.1% 09, 31.8% 10-14, 1.2% 15-17, 27.0% 18-23. Exits 49.8% target, 45.3% stop, 4.9% flat (16:55). Raw trades 15.5 per week; after the lock engine 14.6 per week in WF (median 14, 25-75% 12-17, 5-95% 8-22); 10.8 in the 2023-04..2024-01 window. Raw points per trade +2.75 (1-s path, before costs): 2023 +0.33, 2024 +4.57, 2025 +3.82, 2026 +1.83.

**1.9 Lots / dollars (the lots rule as scored):** fixed 10 lots (unsized cell), R = 10 x 60 x $20 = $12,000 (engine size = lots/14). Locks (exact 1-s engine, firmlib.Ctx.run, te_core.spec_for(10)), per-book DS2 locks: day -2R = -$24,000 and +5R = +$60,000 (a new entry is skipped once breached), give-back arm +2R = $24,000 with 50% kept, week floor -12R = -$144,000, combined day cap off. Locks cut the raw 15.5 trades/wk to 14.6 in WF. Pricing: direct S10x1_g2 replay points + XJ3 gain + 0.5 where a replay row exists (79.3% of trades), mapped path-table points otherwise; WF direct $8,308/wk vs fully mapped $8,760/wk, HOLD direct 8,164 vs mapped 8,412 (so the mapped part does not change the picture).

**1.10 Warm-up:** the MAMA cross sign forgets its start within 24 h of 10-minute bars (section 2). Recommended NT8 setting: load at least 3 days (432 ten-minute bars) of 1-minute history before the first signal, skip signals until 300 buckets exist, and do not start the strategy mid-position without history (the busy state is rebuilt from the replay of the bars, nothing else is stored). The library itself starts only 1.5 days before its first counted trade; its first month shows 6 mismatches (cold start).

## 3. Data, roll, holidays
Continuous front NQ, back-adjusted; the MAMA recursion uses the price level through linear filters (sum of FIR weights 0 for the phase branch, 1 for the average), so a constant offset does not matter but a different roll adjustment does (section 2). Flat 16:55-18:00 ET. Holidays and half days: no bars -> no signals; early closes flatten on the final bar. A missing :x9 minute drops that bucket's signal.

## 4. NT8 implementation notes (UNTESTED in NT8)
- Build the 10-minute closes inside one OnBarUpdate of the 1-minute series (bucket complete when the 1-minute bar ending on :x0 closes; use the bar with :x9 open time as the last bar); do not rely on an added 10-minute data series, whose callback order against the 1-minute series decides whether the new close is visible on the signal bar. Keep p[] as an array in the strategy and run section 1.3 on it once per completed bucket.
- MAMA availability in NT8: the TR1 report states "MAMA not native, custom NinjaScript". My recollection is that NT8 ships a MAMA(fastLimit, slowLimit) indicator (plots MAMA and FAMA; defaults 0.5 and 0.05), but I could not verify it here (no NT8 source, no downloads). Even if it exists, its seeding, price input and phase handling may differ from section 1.3; treat it as usable only after a bar-by-bar comparison on the same 10-minute closes against x_tr1.mama_fama (the sign of MAMA - FAMA must agree on > 99.5% of buckets, the entry list on >= 98%). Parameter names if native: FastLimit, SlowLimit. The safe route is the custom port of section 1.3.
- Order handling: at OnBarClose of the :x9 1-minute bar with a cross, submit one market order for 10; attach stop 60 / target 60 OCO from the fill (240 / 240 ticks); flat by 16:55 ET. Same bracket container as ST/HM.
- The atan is the one-argument arctangent in radians for the period and degrees for the phase; implementing atan2 or the textbook quadrant corrections changes the signals.
- Do not feed the median price or other series: the hl2 variant reproduces only 28% of the entries.

## 7. What could kill it
