## Universe and path (what a "trade" is)
11 books, library base-bracket rows (clean, one-at-a-time per book, NO lock engine, NO TH, uncut): ST, HM, KB, SM, PE: out/ba/rows3/base_*.parquet (60/60); WT: asm_lib.gen_wt_rows (45 stop / 33.75 target, tgt = 0.75R); PB (= D6 PB7/A6 family, PBS): out/xpb/PB_ST10_SWZ_T3 (60/60); DN: out/d4a/don_tt_map (stop-entry, 60/60); MV, MA: out/xtr1 TR1A/TR1C (60/60); CR: out/d4a/crt_tt_asscored_cons (dynamic CRT exit, STORED).
Entry second and exit second come from the 1-s path (/mnt/l2/l2vast/ds3_g2, library back-adjusted prices) via the firmlib sim_rrt scan: the scan reproduces the stored exit type for 99.97% of trades (path_ok=1); 15 trades (MV/MA/DN) differ and keep the STORED exit type/price with the exit second at the end of the stored exit bar (path_ok=0, flagged). CR is STORED (entry/exit seconds kin/kout and exit price from the stored row; no static bracket, dist_tgt/dist_stop are NaN; y_tgt = stored exit==Target). Labels are on this library basis (basis column in trade_index). MEASURED cost is in `rem_pts_meas` (see dictionary).
Decision point = END of second s (ts = s+1). Profit row: upnl>0 at the close of second s; loss row: upnl<=0. Seconds without a print carry the last close (dense grid).

## THP_POLICY features (exact formulas; the distilled policy may use only these)
pct = profit: upnl / target distance (tgt_pts) ; loss: upnl / stop distance (R_pts), negative. mins = seconds since entry / 60. secs_ext = profit: seconds since the last new MFE ; loss: seconds since the last new MAE. dd = MFE - upnl (pts). recov = upnl + MAE (pts, recovery from the adverse extreme). vel30 = side*(close_s - close_{s-30}) pts. eff120 = |c_s - c_{s-120}| / sum|1-s close changes| over 120 s. delta60 = (buy-aggressor - sell-aggressor contracts) over the last 60 s x side, where aggressor is the exchange flag (equals last>=ask / last<=bid classification for prints at the touch; NT8 recomputes it per print from last vs bid/ask).

## Feature leakage audit
Design: every feature at decision (trade, s) uses only (a) 1-s path seconds <= s, (b) L2 1s bins with ts_end <= s+1 and state as of that bin, (c) 1-min bars closed at or before s+1 (last-closed-bar index lc; a bar enters only when (s+1)%60==0 or later), (d) other trades only through open/closed status known at s+1, (e) regime keys by their known-at time. Labels use seconds > s only (reverse scan).
Test (thp_audit.py): 246 profit trade-cuts plus loss-mode cuts, each recomputed with EVERYTHING after a random cut second (path seconds, L2 bins, bars, ES/RTY, other trades' exits) replaced by random garbage; every non-label column at ts <= cut compared (rtol 1e-5): 346 trade-cuts (profit and loss modes), 669,856 rows, 46,364 feature-column comparisons, 0 mismatches.
Known soft spots: (1) the ET-hour intensity baseline, ATR-median and VIX terciles use only prior days; (2) the vol_tag threshold uses a 20-day median of prior days; (3) ES/RTY series are back-adjusted additive: moves are differences, so roll gaps do not enter; (4) `stk_*` uses the library rows of all 11 books (not the lock-engine live stack); (5) library prices are back-adjusted additive: level distances are exact, absolute prices differ from raw by a per-contract offset (used to match the L2 book). (6) The ES/RTY npz series are zip-compressed so each member is decompressed whole and truncated at the cut in the same statement (no post-cut value inspected).

## JADE and loss rule ports
j_* is a dense-grid port of g2_kern profit-side TH; on 360 random ST/HM/KB/SM/PE/WT trades it agrees with g2_kern.run_trade on TH-exit yes/no and exit time within 60 s for 357 (99.2%), within 2 s for 258 of 267 common TH exits (median |dt| 0 s). lc_* (loss) uses approximate live parameters (momentum 6 pts/30 s, stall 30 s with recovery <= 4, efficiency < 0.35 over 30 s, eligibility MAE >= 15) because the exact STStrat.cs loss values are not on disk; treat lc_* as features, not as a replica.

## Notes for users of the table
* hold-to-bracket is the label: rem_pts_lib is the gross library result; subtract fill_cost_pts (MEASURED) and 0.242 pt fees.
* Row counts are large; the rows of one trade are highly autocorrelated: cluster by tid/date_key, use dp10s/dp1m for fitting.
* Sample sizes by window are in trade_index; no table row exists past 2026-02-06.
