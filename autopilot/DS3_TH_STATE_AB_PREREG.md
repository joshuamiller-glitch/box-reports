## 1. Base, world, statistic
* Base: S1-COMB trade list (21,067 trades, 43 months 2023-04..2026-10, /mnt/l2/l2vast/_th_state/base/S1-COMB/). Reference rows: S1-COMB (the live cell of this base), NEVER-CUT (hold-to-bracket proxy), PLAIN6060 (engine run, BASE-S1, when its 43 months land).
* Tier S first-order world W0 (as DS3_TH_STATE.md Stage 1): every trade has its 1-s path from the entry second to the bracket touch (stop = signal price -+ 60, O7 40; target = entry +- 60, O7 90; time exit 16:55 ET, O7 16:00; touches from p_low/p_high); trades whose actual exit is StackCut / BookLock / TimeBlock / O7 time exit end at that actual exit with hold = actual points. Value of a trade under a rule = mid(s+1) -+ 0.80 pt (points, side-signed) at the first firing second s (decision end of s, exit s+1, bracket touch in (s,s+1] wins), else hold-to-bracket points. The baseline value of every trade is the S1-COMB cell run by the same kernel (state_base.advance, per-book cell + session overrides). Delta = (value_rule - value_COMB) x lots x 20 USD. W0-COMB is compared with the actual engine gross (fidelity line in the report).
* Statistic: USD/week delta vs S1-COMB, per book (other books unchanged = S1-COMB), windows L1M(30d) L2M(60d) L3M(90d) L6M(182d) HOLD(365d) as of 2026-10-31, MID, PRE, X' (tiers_stats.windows_asof), carrying week dropped (windows >= 8 weeks), MDE = 2.8 sd/sqrt(n); stack maxDD with/without (drawdown first, L6M and PRE); S = min(L6M, PRE).
* Selection data: label days <= 2026-10-31. The live week 2026-11-01..11-05 (187 trades, frozen file sha256 424c68da...) is NEVER used in selection; held-out table = delta of each finalist vs S1-COMB on the 187 live trades (path to the actual exit, hold = actual points, cuts on the state arrays).
* Per-book pick (tier rule, tie -> simpler): among cells with nfire >= 30 in selection: E1 recent-pass & tolerant & drawdown-first, E2 tolerant & ddfirst, E3 ddfirst, E4 any; best S inside the first non-empty tier. A book whose best cell has S <= 0 is reported 'no improvement over S1-COMB: keep the COMB cell' (the S1-COMB row is the zero row of every family).

## 2. Program A families (remaining A axes; the core A1 axes ARM/MULT/window/persistence/newMae/lot-scaled V1,V2 were searched by STATE-SCORE and are not repeated)
Per-trade params of the S1-COMB cell of the trade's unit (book / session override) are written c0 = (ARM0, MULT0, W0, PERS0, newMae0, var0).
* A2 book-flip add-on triggers (OR with the COMB cut; earliest wins): feature F in {imb, ice, dlt, swp} x strength quantile q in {.50,.70,.80,.90,.95,.99} = 24 cells, fire at the first second with -unreal >= 30 pt AND F >= thr(F,q) (persistence 1). Features from the 1-s state arrays (against side = ask for a long, bid for a short):
  imb = against share of top-5 resting size, a(s) = opp5/(own5+opp5), F = a(s) - a(s-10) (rise of the against share over 10 s = the book flipping against the position);
  ice = number of refill events on the against-side best level in the last 30 s (refill = best price unchanged s-1->s, a print at that price in (s-1,s], size(s) > size(s-1)); thr = max(1, quantile);
  dlt = aggressive volume against the position minus with the position over the last 10 s, divided by MedLevel (delta turn);
  swp = max over the last 3 s of (1-s aggressive volume against the position) / MedLevel (sweep).
  thr(F,q) = the q-quantile of F over all rows of all selection trades with -unreal >= 30 (feature distribution only, no P&L).
* A4 post-cut blackout (trade-list level + engine): after a StateCut exit of a book, entries of that book are skipped for N min; N in {0,5,15,30,60} x scope {same-side (only entries in the cut trade's direction), both-sides (any direction)} = 10 cells per book (N=0 is the S1-COMB row; U7 N=30 same-side is the live D7 rule - the S1 base has NO blackout because the old ThL2Cut that set it is removed: finding to report). Blocked trades are removed sequentially (a removed trade cannot start a blackout); delta = -gross of the removed trades (first order, locks/re-entries ignored).
* A5 lot-scaled arm beyond the grid: arm_eff = clip(ARM x (lots/4)^gamma, 15, 50), other params = the unit's COMB cell, ARM in {20,25,30,35,40,45,50} x gamma in {-1.0, -0.25, +0.25, +1.0} = 28 cells (gamma = -0.5 / +0.5 are V1 / V2, already in STATE-SCORE).
* A6 sustained-cut cells: dwell D in {2,5,10,20,30} s x depth X in {20,30,40} pt = 15 cells A6a: the COMB cell condition first fires at s0 (full condition incl. persistence); the cut is CONFIRMED at the end of second s0+D only if -unreal >= X at every second s0..s0+D, exit at s0+D+1; if the price recovers above -X inside the dwell the cut is cancelled and the state machine resumes scanning from s0+1 with the run reset. A6b scale-out in two halves (lots >= 2, q = lots//2, 1-lot trades unchanged): first q lots cut at s0+1 (COMB), remaining lots: hold to bracket / cut at s0+D if -unreal >= 15 with D in {10, 30, 60} = 4 cells.
* A7 HM path rule (H7 only): the DS3_THL_HM_RETEST family L6_a{20,25,30}_r3_w{10,20,30} (eligibility = adverse excursion >= a; 3 of 3 of: 4-pt adverse momentum over w s, no new adverse extreme for >= w s with recovery <= 4, efficiency over w s < 0.35; 1-s evaluation) = 9 cells, ADDTO mode (on top of the H7 COMB state cut) and ALONE mode.
Family sizes (rule cells x books): A2 24x7, A4 10x7, A5 28x7, A6 19x7, A7 9x1 (x2 modes) -> A family total 24+10+28+19+9 = 90 rule cells, 637 book-cells (max-stat family size for A).

## 3. Program B families (L1 loss; DS3 TH-loss grid)
* B1: ThMinPoints {10,15,20,30,40} x ThRequired {2,3,4} (votes needed = min(req,3)) x momentum (window {15,30,60} s x points {3,5,8}) x stall (seconds {30,60,90} x pullback {2,4,6}) x efficiency (window {30,60,120} s x threshold {.30,.40}) x evaluation frequency {1 s, 10 s} = 14,580 cells, per book (x7 D7 books). Vote definitions as DS7.cs ManageLoss / rules_replica._l1_loss on the 1-s trade-print path: eligible once the adverse extreme >= ThMin; evaluated at the first eligible second and then every `freq` s; momentum = price now worse than price w s ago by >= pts; stall = adverse extreme at least st s old AND recovery from it <= pb; efficiency = |net|/path over ew s < thr (path = sum of |1-s last-price changes|). Modes: ALONE (path replaces the state cut: L2 off, path on) and ADDTO (path on top of the S1-COMB state cut, earliest wins). ReplacePath in D7 = path off, L2 on = the S1-COMB row (zero row).
* B2: the 8 of 18 mappable THL_BOOKS cells (KB->K7, SM->U7, PE->P7, MV->M7 x {TH_LIVE: 15 pt, 3 of 3, 30 s/4 pt, 30 s/4 pb, eff 30 s .35, 1 s ; MAE15: 15 pt, 0 votes}); MA/DN have no D7 book, the 6 TIME_ONLY cells are placebos (run through the placebo machinery, not cells). Each in ALONE and ADDTO.
* B3: B finalists stacked on A finalists: top-4 distinct B1/B2 cells per book-set x A finalist policies, modes ReplacePath (= A policy alone) and AddToPath (A policy + path), at policy level.
B family total 14,580 + 8 = 14,588 rule cells x 2 modes (7 books for B1) -> 204,232 book-mode cells (max-stat family size for B).

## 4. Nulls, walk-forward
* Placebo (per finalist book-cell): same fired trades, 1,000 draws, exit at a uniformly random eligible second (A: -unreal >= the cell's arm level; B: adverse extreme >= ThMin; add-on: before the COMB exit); p = (1+#{S_null >= S_obs})/1001.
* Family max-stat (Westfall-Young style): W shifted-signal worlds; world = the trigger signal (state feature / vote flags) circularly shifted within each trade by a random offset while the price path and cut prices stay; the family's per-book maximum S over all cells of the program is the null; p_family = (1+#{max_w >= S_obs})/(W+1). W = 100 for A families, W as many as fits for B1 (reported; >= 20), the B1 null covers the whole grid or says explicitly what was dropped.
* Purged walk-forward by month 2024-01..2026-10: each month the cell with the best trailing 12-month S-style delta (1-month purge) per book among ALL cells of the family is applied to the next month; compared with the S1-COMB zero row and 200 random-cell draws; positive = total delta > 0.
* ENTER test vs S1-COMB: L6M AND PRE beat S1-COMB with the carrying week dropped and above the MDE, placebo p <= .10, family p <= .10, purged walk-forward positive, drawdown first not worse, held-out live-week table not negative. Labels LEAD (S>0 plus recent+tolerant+ddfirst but a null fails), CONFIRMED only through all of ENTER, best-of-F otherwise.
