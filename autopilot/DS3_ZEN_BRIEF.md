## 2. What to import (read the header of zen_lib.py; it is the API document)

```python
import sys; sys.path.insert(0,'l2vast/ds3/code/zen')
import zen_lib as Z, zen_lines as ZL, zen_struct as S, zen_features as FE, zen_gate as G, zen_bars as B
Z.set_threads(5); c = Z.Ctx(); b = c.b1                    # 1/5/15-min context, cached indicators
R = Z.regimes(c)                                            # dict R1,R2_20/40/50,R3,R4,R5,R4R5,R6,R7,R8 -> int8 side per closed 1-min bar
sig, side = Z.candidates(c, R['R1'], 'PRIMARY')             # ALL regime+window qualifying signal bars = the random-in-regime candidate set
e, E, ok = Z.entries_market(b, sig, side)                   # entry = open of the NEXT bar (signal bar j is closed)
stop, tgt = Z.fixed_bracket(E, side, 15.0, 20.0); flat = Z.flat_index(b, e, 840)   # flat 14:00 (or 955 = 15:55)
df = Z.simulate(b, e, side, E, stop, tgt, flat)              # net1/net15/net2 in pts per contract = 10-lot-equivalent; per-trade structural stop/target = arrays
real = Z.sequence(df)                                        # one-open-trade rule, applied to real AND placebo
P = Z.placebo_in_regime(simfn, cand_sig, cand_side, real_sig, real_side, ndraw=100)   # same regime/window/bracket, random minute
V = Z.vs_placebo(real, P, 'PRE')                             # effect, CI (week blocks), rank, MDE80, weekly $ effect
```
Library facts that matter: bars are tick-built library bars (not NT8); fills are 1-min OHLC and conservative (stop first on ties, gap at the open, targets never improved, limit needs a 1-tick trade-through, next-bar rule for BE/scale); `Z.simulate_multi` = multi-unit (scale-in layers, pyramid adds, all P1 trails, give-back); `S.grid_eval` = one pass per trade for a whole stop x target grid (tell it the stop PRICES per source and target PRICES per source); `S.reality_check` = best-of-N over every pair; `FE.feature_matrix` = the Addendum 4 vector (leakage-tested); `G.oof_auc` = week-block nested CV; `B.heikin_ashi / anchored_time_bars / line_break / load_zen_bars`; `Z.load_xinstr('ES'|'RTY'|'YM')` for M9 (1-min only). If you need a primitive that is not there (a trigger detector), write it in YOUR module; do not edit the shared files (report a lib bug in MORNING.md instead - it will be fixed once for everyone).

Your detector must obey the CLOSED-BAR RULE: the signal at index j uses bars <= j (HTF values via `c.asof`), and a unit test in your module must show the signal array is unchanged when all bars after j are deleted (copy the pattern in `zen_lib_test.t_leak`: build `Z.Ctx(cutoff=20250102)` and compare).

Simulate-once-select-many (essential for speed): for any family where the entry set is a boolean mask over regime-qualified bars (LINES_B, F1 regime axis), simulate every candidate bar once with the cell's bracket and select by mask; never loop a simulation per cell.

## 4. Gates (screen stage on PRE; the top 30 then face the holdout stage)

Screen (all on PRE, mapped): **G1** effect vs random-in-regime > 0 with the week-block CI lower bound > 0 AND rank >= 0.95 of the draws (pool expectation in grid screens); **G2** effect vs random direction > 0, rank >= 0.95; **G3** mean net > 0 at 1x and at 2x cost; **G4** realised win rate > the cost-adjusted break-even win rate of the realised stop/target (`Z.breakeven_wr`, `Z.be_empirical`; structural brackets: `S.realised_be`); **G5** n trades >= 100 in PRE (below 100: a count, not a verdict) and effect >= MDE80 (else "inside MDE": inconclusive, still listed). Holdout stage (top 30 per family by PRE effect vs random-in-regime, ONE logged look): **G6** HOLD effect sign agrees and CI lower > 0 vs random-in-regime; **G7** X span effect >= 0; **G8** best-of-N: reality-check p <= 0.05 over the family's N (and the program N reported); **G9** positive in >= 2 of 2024 / 2025 / 2026 and no year > 60% of WF; **G10** direct 1-s/L2 basis (replay) mean > 0 and paired vs the bar-fill result not negative. Labels: all of G1-G10 = CANDIDATE; plus forward-only replication per the program rules = CONFIRMED. Cells reported with the exact failed gates and by how much. **Never-empty-handed:** the final table lists the top 10 cells of your family by effect vs random-in-regime REGARDLESS of verdict, with failed gate(s), MDE80, n, win rate vs break-even, trades per week, PRE/HOLD (if looked)/X, forward weeks for 80% power (as DS3_PBX_FINAL section 2).
