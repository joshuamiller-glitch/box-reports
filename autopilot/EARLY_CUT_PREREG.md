# EARLY_CUT_PREREG (W-X, T-EARLY-CUT) - frozen before any rule scoring; DS3_EARLY_CUT_TABLE.md published first (evidence only, no rule scored on it)
Evaluator: code/th_ec/ec_fo.py (first-order, per-trade 1-s u paths from ec_paths, entry to raw-bracket resolution; base outcome = LPB_BASE exit). Fill model: market cut decided at close of second j, exit at row j+1: pts = u[j+1] - slip, slip central 1.2 (live loss-cut calibration 1.19-1.20; engine 0.80 = low case); structure/native stop filled at level -1.4 pt (live native 1.4; engine fills native ~1.9 better than level = low case). Scope BASE = rule fires only before the base exit, else base outcome; scope RAW = hold-to-bracket continuation (no state cut) for geometry; recoveries lost judged on base Target exits and on raw target.
Objective: full-stop $/week and count/week (base exit <= -90% of stop distance; also all loss exits >= 2/3 stop) minimised s.t. recoveries lost ($ of trades the rule cut that would have reached target); net $/wk; stack maxDD cut and mean secondary (Z.score_daily L6M/HOLD/PRE/X'). A cut losing more recoveries $ than stops saved $ on L6M is not a candidate.
Grids: a THESIS (pullback fractal 1/3/5-min, Keltner mid (5-min EMA20 close), Supertrend (5-min ATR10 x3), session VWAP from tick prints), buffer {0,2,4,6} pts, exit-on-break and as-initial-stop (lots x 60/dist, dist capped 25-60, lots factor 0.33-3); b GEOMETRY stop {25,30,35,40,45,50,55,60} x target {45,50,60,75,90} (P7 45/60 first, four windows) fixed and equal-$-risk lots; c NFT X {5,10,15,20} x N {2,5,10,15,20} min exit, and half-exit; back-to-entry after MFE>=Y {10,20,30,40}; d SCRATCH after MAE>=d {25,30,35,40,45} exit at -s {0,2,5,10}; recovery lock (arm at -a {10,20}, exit at -a-g, g {5,10}); e PARTIAL F {.33,.5,.67} at -d {15,20,25,30,35}, with/without re-add at -d/2; f every family by context {fresh, reentry, chasing, ALL} and lots (>=5 vs <5); g state cut (40/5x/p3 live base) reference rows and combinations a-e.
Placebos: forward-only (fire second shifted forward), family null (random fire times matching fire count per book, 200 draws). Finalists: exact one set per job via SZ-CORE queue, private copy of the driver hooks, private trees. Acceptance per order s4 and the 19:45Z standing principle (scorecard a-e via W-Q behavior_scorecard.py).
