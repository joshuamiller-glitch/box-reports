## NT8 fidelity (step C). Source: no NT8 documentation text is on the box except the box's own spec l2vast/ds3/code/bars/SPECS.md (written from NT8 behaviour); statements below marked 'unverified' are NT8 behaviour from general knowledge, not checked against NT8 itself.
- Tick bars: NT8 bar closes on the Nth trade; next trade opens the next bar; session break resets. Ours identical (closing print belongs to the closing bar). Print granularity: MBO 'T' records (one per match event, aggressor-sized). NT8 Tick counts exchange trade prints from the data feed; equality of print counts with NT8's feed is unverified (the engine already uses these same prints).
- Volume bars: NT8 splits the closing print's contracts across consecutive bars (a 5-lot print overshooting a 1,000 threshold by 2 contracts puts 2 in the next bar); ours does NOT split (closing print entire in closing bar). DIFFERENCE: bar boundaries are the same except overshoot <= one print size; unverified detail. Exact NT8 volume bars would need a split flag; ours is the SPECS.md convention.
- Range bars: NT8 closes the bar when price would exceed N ticks of range, the exceeding print opens the next bar (no overshoot); ours the same (range <= N ticks inclusive, breaching print opens next bar and defines known_ts). Unverified whether NT8 allows range == N or N+1 ticks inclusive.
- Renko (classic): NT8 brick closes when price reaches open +/- brick size; reversal needs 2 bricks from the last close (new brick opens at the previous brick open). Ours identical (classic). Multiple bricks from one print: NT8 emits them all; ours too. Session break resets: ours yes (NT8 per session template).
- Time bars (seconds/minutes): NT8 anchors minute bars to the session template start and emits a bar only if a print arrived; ours anchors to the first print of each of OUR sessions (London 02:00, pre 08:30, NY AM 09:30, NY PM 12:00, close 16:00, Asia 18:00 ET). For periods dividing the session offsets (e.g. 5-min at a :00 or :30 boundary) identical; for 7/13/45/90-minute periods NT8's anchor would be the template start (18:00 ET), so bar edges differ. DIFFERENCE stated; custom anchoring needed to reproduce exactly.
