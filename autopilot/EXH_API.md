# EXH_API - T-TH-EXHAUST framework API (EX-CORE). Part 1 (universe layout, published early for EX-FEAT); parts 2-5 appended below as they land.

## 1. Universe  /mnt/l2/l2vast/_th_exh/universe/   (code/th_exh/build_universe.py, rebuild idempotent)
- trades.parquet (all months) and trades_YYYYMM.parquet. One row per never-cut trade, sorted (entry_ns, book) inside a month.
  Source per month (column `src`): S1b_NOCUT_tick (base_b/NOCUT DONE months; replica engine + tick bar close), S1_nocut_timer (stored hist/A2 never-cut run, for months NOCUT has not finished; rebuilt automatically when a month turns DONE), u5_replica_live_cutrun (month 202611 = the live week from the u5 replica run, it is a CUT run: entries are used, its engine exits are not the never-cut).
- **tid = entry_sec*100 + bookidx*2 + (side>0)**, bookidx = K7 0,P7 1,M7 2,U7 3,A7 4,H7 5,O7 6,X3 7,X4 8,X5 9. Stable across source swaps for the same entry (key panels on tid, never on row number).
- Columns: tid, month, book, session (entry session 0 asia 18:00-02:00 ET, 1 london -08:30, 2 pre -09:30, 3 nyam -12:00, 4 nypm -15:00, 5 close), entry_sec (epoch s of the entry), label (trading-day label = ET date of ts+6h), side (+1/-1), lots (live lots), fill_avg, signal_px, stop_px (= signal_px -+ 60; O7 40), target_px (= fill_avg +- 60; O7 90), flat_sec (16:55 ET; O7 16:00), br_k / br_sec / br_px / br_type (hold-to-bracket exit: second offset, epoch, price, 0 stop at level, 1 target nominal, 2 time exit at mid -+ 0.80), n_path, pnl_hold_usd = side*(br_px-fill_avg)*lots*20 - lots*4.84, eng_exit_sec/eng_exit_px/eng_exit_name/eng_net_usd (the engine's own exit, for reference only; includes StopJoin/TimeBlock/StackCut), src, live_week (label 20261101..20261105), row0 (row index of k=0 in days/<label>.npz), day_t0 (ts[0] of that file).
- Paths  paths/YYYYMM.npz: tid[n] int64, off[n+1] int64, entry_sec[n], br_k[n] int32, and flat float32 arrays mid, high, low, last (points; high/low/last = print extremes/last print of the second, NaN if no print; mid forward-filled).
  **Second offsets: path index k of trade j is flat index off[j]+k; its state time is ts_end = entry_sec + k (the book at the END of second entry_sec+k-1, = the row of the 1-s state file with ts == entry_sec+k, i.e. row index entry_sec+k - ts[0] of days/<label>.npz). k=0 is the entry instant. high/low/last of index k are the prints in (entry_sec+k-1, entry_sec+k]. Decisions are taken at k, execute at k+1.** br_k is the first k whose print range touches the bracket (k>=1).
  Path length: k = 0 .. br_k + 2 for stop/time exits; k = 0 .. br_k + 1800 (capped at flat time) for target exits (room for target extension / trails that outrun the nominal target).
- Joining the 1-s state arrays for features: file days/<label>.npz, row(k) = row0 + k (so ts[row(k)] = entry_sec + k).

## 2. Technique outcome contract (code/th_exh/exh_core.py)
Run from `code/th_exh` (`import exh_core as E, exh_metrics as X`); NOT with `python -I` (own modules).
A technique cell returns per trade `(k1, px1, n1, k2, px2)`:
- k1 / px1 / n1: first exit leg at second offset k1 (state time entry_sec+k1) at price px1 for n1 contracts. k1 = -1: no leg. n1 = lots is a full exit; 0 < n1 < lots is a scale-out (use `E.nlots(lots, frac)` = floor(lots*frac); a 1-lot trade cannot scale). A leg at k1 >= br_k loses to the bracket (bracket wins ties).
- k2 / px2: exit of the REMAINING contracts (-1 = hold to the original bracket br_k/br_px). k2 may exceed br_k only when it comes from `walk_to_bracket` with changed levels.
- P&L = sum n_i*side*(px_i-fill_avg)*20 - lots*4.84 (`E.pnl_usd(side, lots, fill, legs)`; `Outcome.pnl_usd`). Decisions are taken at second k, execution is at k+1.
Helpers (all @njit, callable inside kernels):
- `E.market_exit(side, mid, high, low, k, stop, tgt, br_k, br_px) -> (k_exit, px)`: executes at k+1 at mid[k+1] -+ 0.80; a touch of stop/tgt in (k, k+1] wins; at or after the bracket it IS the bracket.
- `E.limit_exit(side, high, low, from_k, px, br_k) -> (k, px)`: nominal fill at px at the first second in (from_k, br_k) whose print range reaches px, else (-1, nan).
- `E.walk_to_bracket(side, mid, high, low, from_k, new_stop, new_tgt, br_k, br_px, br_type) -> (k, px, type)`: target first, stop at level, NaN removes a level; type 0 stop, 1 target, 2 time, 3 path end.
- `E.nlots(lots, frac)`, `E.unreal_pts(side, fill, mid, k)`.
Kernel template (numba): `kernel(side, lots, fill, stop, tgt, br_k, br_px, br_type, mid, high, low, last, F, P) -> (k1, px1, n1, k2, px2)`; mid/high/low/last = this trade's path (index = second offset); F = float32 [nf, path_len] view of feature panels (flat panels aligned with `U.off`, built by you or by EX-FEAT; `run(U, P, idx=None, F=panels)`); P = float64 parameter vector.
`run = E.make_runner(kernel)`; `U = E.Universe()` (full universe, 3.3 GB RAM, 2 s; `months=`/`books=` for tests); `out = run(U, P, idx=book_rows, F=...)` (idx = rows to evaluate; the others do not fire). Working example: code/th_exh/smoke.py (panels(), kern()).
Scale-out: `n1 = E.nlots(lots, 0.5)`; leg 1 via `limit_exit`; the rest trailed via `walk_to_bracket` -> k2/px2.
Held-out live week: `UL = E.Universe(root=E.UNI_LIVE)` (186 of the 187 frozen live trades; one exits after the data end; bracket = the ACTUAL live exit, br_type 4; file sha 424c68da... checked by build_live.py), `outl = run(UL, P, F=panels_for_UL)`, `live = X.live_delta(UL, outl)` -> {book: (n_fired, delta_usd vs actual)}; pass `live=live` to score_cell.

## 3. Registering a cell, ledger, metrics (code/th_exh/exh_metrics.py)
`X.score_cell(U, out, technique, family, side, params, B=64, agent='<your name>', live=live)`: side in loss|profit|both; params = JSON-able dict; cell_id = sha1(technique|family|params)[:12]. One call writes 77 scope rows (book x session; book in ALL + 10 books, session in ALL, 0..5) to /mnt/l2/l2vast/_th_exh/ledger_parts/<agent>_<cell_id>.parquet (atomic, append-only, one file per cell), the placebo/family null draws and sparse per-day deltas to /mnt/l2/l2vast/_th_exh/cells/<cell_id>[_delta].npz. `X.consolidate()` -> ledger.parquet (the persistent ledger of every cell ever scored). score_cell needs the FULL universe (raises otherwise).
Ledger columns: cell_id, technique, family, side, params, book, sess, then per window w in L1M L2M L3M L6M HOLD MID PRE X': `{w}_mean_{t,n,c}` (weekly mean USD, carrying week dropped; t = technique, n = never-cut, c = S1b-COMB live reference row), `{w}_dd_*` (weekly maxDD, all weeks), `{w}_w20_*` (sum of the 20 worst weeks, min(20, nweeks)), `{w}_ulc_*` (Ulcer = rms drawdown, USD), `{w}_cal_*` (Calmar = mean*52/maxDD), `{w}_dmean_n`, `{w}_dmean_c`, `{w}_mde_n`, `{w}_mde_c` (2.8 sd/sqrt(n) of the weekly delta), `{w}_nweeks`; nfire, ntrades, pers_L (share of L1M..L6M with delta > 0; flag > 0.6), pers_all, p_{rand,shift,shuf}_{dd,mean}, p_plc (largest of the three on the drawdown statistic), live_n, live_delta, ts, agent.
Windows (as of 2026-11-09, data ends 2026-11-05): L1M 20261011-, L2M 20260911-, L3M 20260812-, L6M 20260512-, HOLD 20251111-; MID 20260207-20260430; PRE 20240201-20250630; X' 20230401-20240131. Weeks = ISO weeks of trading-day labels; stack = all books summed; per book and per entry session are scopes.
Nulls: placebos = same fired count; (rand) exit at a uniformly random second of the trade, (shift) real decision shifted by +-60..600 s, (shuf) decision timing taken from another fired trade of the same book; statistics = L6M maxDD reduction and L6M mean delta; p = (1+#null>=obs)/(B+1). Family max-stat `X.family_p()`: over every cell and book-level scope in cells/, z of the observed statistic against its own null draws; family null draw b = max over all cells of the standardized null draw b (conservative: cell nulls independent). Purged monthly walk-forward `X.walk_forward(cell_ids, scope, first=202401, train_weeks=26, embargo_days=7)`: pick on trailing weeks by (maxDD, worst-20, Ulcer, -mean) subject to mean >= never-cut mean, apply next month; returns monthly table and summary (wf_ok = total >= 0 and WF maxDD <= never maxDD * 1.05). Write results to /mnt/l2/l2vast/_th_exh/wf_table.parquet (cell_id, book, wf_total, wf_ok) for the page.
Labels `X.labels(row, p_plc, p_fam, wf_ok)`: ENTER = recent_pass (L3M, L6M delta > 0; L1M, L2M >= -0.5 MDE) AND PRE, X' delta >= -0.5 MDE AND L6M and PRE maxDD not worse AND L6M delta > MDE AND PRE delta > 0 AND placebo p <= .10 AND family p <= .10 AND WF ok. CANDIDATE-DD = L6M maxDD lower than never-cut AND L6M delta >= 0 AND PRE maxDD <= never PRE maxDD * 1.05 (even inside MDE). LEAD = L6M delta > 0 and L6M maxDD not higher and pers_L > 0.6. else no.
References: `X.load_refs()` -> (never, comb) daily [10 books, 6 sessions, nd]; never = universe hold-to-bracket; comb = S1b-COMB all 43 months (live week from the u5 replica run).
Page: `python3 make_page.py` writes autopilot/DS3_TH_EXHAUST.md from the ledger.

## 5. Known differences (stated)
- Universe = hold-to-bracket (stop at level from signal price -+ 60, target fill average +-60, O7 40/90; time exit 16:55 ET, O7 16:00), NOT the engine never-cut run: the engine also exits via StopJoin, TimeBlock, StackCut, BookLock and holds some trades across the flat time (eng_* columns carry the engine exit). 4,081 of 19,081 trades are from S1b NOCUT (tick close), the rest S1 timer close until NOCUT finishes (rebuild: `python3 build_universe.py build 2`).
- Smoke test (K7 S1b-COMB live line through the API, 202304-202306, vs S1b-COMB K7): 246 of 253 COMB K7 trades match on (entry second, side). COMB StateCut trades 7; the dummy cell fires on 6 with identical P&L to the cent (-5115.88 vs -5285.88: the 7th, a cut after 16:55 that the universe flattens earlier, is the 170.00 difference); 2 further fires coincide with COMB StackCut exits. Unfired Target exits differ by -4,408 over 107 trades, almost all from 2 trades the engine held across the flat time. Live-week K7: 12 cuts +1500.5 reproduces DS3_TH_STATE section 7 (+1501).

## 6. Stack view and one-rule-for-all-books (exh_metrics.py)

## 7. Stage 2 (engine cascade) - code/th_exh/stage2.py
For finalists. The SAME numba kernel + panel function as Stage 1 is run through the replica engine (state_base_b StateBaseRep subclass ExhRep): re-entries, locks, stack gates, caps, U7 blackout, measured fills. At the first manage call of each position the kernel is evaluated on the state path from the entry second (the engine's bracket stop_px/target_px define br_k; kernel causal by contract) and its legs are installed as timed exits `ExhCut` at the state second of each leg (partial legs supported: n1 < lots, then the remainder); engine bracket orders stay live and an engine exit that comes first wins. Base rule = NEVER (old cut neutralised), so "without" = engine never-cut (base_b/NOCUT where DONE, else the stored S1 timer-close nocut; the ledger column `ref_never_src` counts S1b vs S1 months).
Use: put the spec in /mnt/l2/l2vast/_th_exh/stage2/sets/<set>.json = {"spec": {"K7": {"mod": "<module in code/th_exh>", "kernel": "<njit kernel>", "panels": "<fn(Z, r0, L, side)->float32[nf, L] or null>", "P": [...], "keys": ["state array names the panel fn reads from Z, e.g. canc_bid, canc_ask, med, bpx, bsz, apx, asz"]}}, "technique":..., "family":..., "side":..., "params": {...}} (one spec per book tag; Z holds the concatenated day arrays of the replay days, row index = engine state row; Z also always has p_high/p_low/p_last). Then
`cd code/th_exh; python3 stage2.py run <set> 202304-202610 2` (<= 2 workers; each month ~3-4 min, waits for MemAvailable >= 50 GB) and `python3 stage2.py score <set>` -> ledger part stage2_<cell_id>.parquet with `stage` = S2 (same metric vector; nfire NaN; n_months_s2; months not run are filled from the engine never-cut so a partial run shows what it has). Kernel signature identical to Stage 1; the panel fn must give the same panel values as the Stage 1 panel (row r0 = entry row; index k = r0 + k).
Limits: one spec per book tag (the loss+profit pair of a book must be ONE kernel returning the combined legs); the entry-time pos_qty is the kernel's lots (staged fills of later lots are not rescaled).
Other drivers (code/th_exh/exh_drivers.py): `python3 exh_drivers.py wf` (walk-forward of the picking procedure -> wf_table.parquet, wf_global.parquet), `wy` (Westfall-Young maxT family null, common permutations -> wy_table.parquet; labels use p_wy when present, else the conservative independent p_family), `cross` (best loss x best profit per book, profit only on trades the loss rule did not exit, registered as family X_cross). Crosses need per-trade outcome files cells/<cell_id>_out.npz, which score_cell now writes: **cells scored before 2026-11-09 03:00Z lack them; re-score those (cheap) before they can enter a cross.**

## 8. Extended paths for target-changing cells (K family)
`x = U.ext()` (exh_core.Universe.ext, ~7 GB RAM for the full universe): same trades/rows/tids and the same second index k, but every trade whose hold-to-bracket exit is the TARGET (br_type 1) carries its path to min(br_k + 14400 s, flat time) instead of br_k + 1800. Files: /mnt/l2/l2vast/_th_exh/universe/paths_ext/YYYYMM.npz (tid, off, mid, high, low, last for those trades only; built by code/th_exh/build_ext_core.py, re-run after build_universe.py). The clone has its OWN offsets x.off (U.off and the EX-FEAT panels, aligned to U.off, do not apply to it: build panels on x.off yourself or read features by day-file row = row0 + k). Use `run(x, P, F=...)`; pass the ORIGINAL U (not x) to score_cell (Outcome arrays are per trade and aligned); br_k/br_px stay the original bracket, the new target comes from walk_to_bracket over the longer path.
