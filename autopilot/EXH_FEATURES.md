# EXH_FEATURES - per-second feature store for the never-cut S1b trades (EX-FEAT, T-TH-EXHAUST, 2026-11-09)

Code `code/th_exh/` : `feat_core.py` (primitives, baselines, features), `feat_base.py` (slot baselines, run once), `feat_month.py` (month builder), `validate_a.py`, `validate_b.py`.
Output `/mnt/l2/l2vast/_th_exh/feat/YYYYMM.npz` + `YYYYMM.json` (meta, src flag of the universe month used, NaN fraction and inf count per feature). Baselines `_base/base.npz`. Rebuild one month: `python3 -I code/th_exh/feat_month.py YYYYMM` (idempotent, ~25-30 s/month, keyed on tid; rerun when EX-CORE swaps a month from S1 timer to S1b).

## Layout and keys
- Input universe: `universe/trades_YYYYMM.parquet`, `universe/paths/YYYYMM.npz` (EXH_API.md section 1). One panel row per universe path index.
- npz keys: `tid[n]` int64, `off[n+1]` int64 (identical to the universe paths `off`), `n_path[n]`, `row0[n]`, and ONE flat float32 array per feature of length `off[-1]`. Feature value of trade j at path index k is `A[name][off[j]+k]`.
- Time: path index k has state time ts = entry_sec + k, the book at the END of second entry_sec+k-1 = row `row0+k` of days/<label>.npz. Every feature at k uses state rows <= row0+k only (decide at k, execute k+1). Test (b) below.
- Everything is computed from the 1-s state arrays only; prints enter only as per-second aggregates (volume by aggressor, count, max print by aggressor, notional, p_high/p_low/p_last). No per-print/feed quantity. Mid = state mid forward-filled. Points = ticks/4, ticks are state ticks.
- Warm-up: rows of the previous label day (last 7200 s) are prepended when the gap is <= 2 h (Mon-Thu overnight continuity); otherwise (Sunday open) the label day starts cold. Windows needing more rows than exist are NaN.
- Side convention: own = the side supporting the trade (bid for long, ask for short); against (= "ahead" side in the book) = the other side. sd = +1 long, -1 short. "sg" = signed with the trade (positive = in favour).

## Baselines (all causal: previous label days only)
`_base/base.npz` per label day: 96 slots of 15 ET minutes (ET clock of the row) of median MedLevel-x, median tot8, mean contracts/s, mean prints/s, median print size; 6 DS7 sessions median x; RTH (09:30-16:00 ET) hi/lo of mid, opening range (09:30-10:00) hi/lo, overnight (18:00-09:30) hi/lo, median 1-min true range. "Prior N" = nanmedian over the previous N trading-day files, needs >= min(N,5) days else NaN. fast N=5, base N=20, slow N=40.
x = (sum of top-5 bid sizes + sum of top-5 ask sizes)/10 (the MedLevel definition). tot8 = bid 8-tick depth + ask 8-tick depth (levels within 0..7 ticks of that side's touch, the DS7 Depth8 rule). The DS7 live 30-min EWMA depthBase chain (alpha .002 per snapshot) is NOT replicated: tot_rel_* use the prior-day slot median baselines (fast/base/slow). Say so in v1.6 when exporting.

## LOSS side - state (per second, side-dependent)
- Cancels recomputed from the top-10 arrays with the TH_STATE_BUILD rule (kernel reproduces stored canc_bid/canc_ask with 0 mismatches on the checked day): `cn_*` NET of trades = sum max(0, sz(r-1,p) - cur - traded) ; `cg_*` GROSS = sum max(0, sz(r-1,p) - cur) (traded not subtracted). `own`, `ag`, `both` x windows W = 1,2,3,5,10,15,30 (rows r-W+1..r, NaN if fewer rows). Names `cn_own_w5`, `cg_ag_w30`, `cn_both_w10`, ... (42).
- MedLevel variants `med_e001` (stored 0.001 EWMA), `med_e01` (EWMA 0.01 of x, reseeded at instrument change, seeded at the first row of the prepended tail), `med_slot` (prior-20-day median x of the row's 15-min ET slot), `med_h1` (rolling 3600-s median of x, >= 900 rows), `med_sess` (prior-20-day median x of the DS7 session of the row). Ratios `pr_<med>_own_w<W>` (own net / med, all 5 meds x 7 W) and `pr_e001_{cn_ag,cn_both,cg_own,cg_ag,cg_both}_w<W>`. The live line is `pr_e001_own_w5` (= pulled5/MedLevel).
- `imb_ag5`, `imb_ag10` = (against-side top-n size - own-side top-n)/(sum), >0 = against heavy. `ahead8`, `behind8`, `ahead5`, `behind5` (ahead = against side), `r_ab8`, `r_ab5` ratios, `tot8`, `tot_rel_{fast,base,slow}` = tot8/prior slot median tot8, `ahead_rel_{fast,base,slow}` = ahead8/(0.5 x that median) (DS7 ahead_rel form), `tot_rel_h1` = tot8/rolling 1-h mean.
- `ice_ag_w{10,30,60}`: count over W seconds of against-side refills; refill event = a top-10 level present in r-1 with trades at that price in second r by the aggressor hitting that side AND size(r,p) > size(r-1,p) (increase despite trades).
- `adv_best_move` = adverse move of the own-side best price in ticks in the second (bid fall for long, ask rise for short; 0 if a side is empty); `sweep{2,4,8}_w{10,30,60}` = count of seconds with adv_best_move >= k ticks.
- `micro_sg` = sd x (microprice - mid) in ticks (>0 in favour), microprice = (bid x asz + ask x bsz)/(bsz+asz) of level 0; `spread_t` ticks; `ownbest_sz`, `agbest_sz`, `ownbest_rel60` = own best size / its trailing 60-s mean; `qd10_own/ag` = best-level size / size 10 s ago; `dtot8_w{5,15}` = (tot8 - tot8 lag)/w, `dtot8_rel_w*` divided by the base slot median.
## LOSS side - flow (per-second aggregates of prints)
- `dlt_w{10,30,60,120}` = sd x (buy-aggressor volume - sell-aggressor volume) summed over W; `dlt_med_w*` / med_e001; `dlt_v60_w*` / trailing 60-s volume.
- `pps_w{10,30}`, `cps_w{10,30}` prints/s and contracts/s; `*_rel_*` divided by prior-20-day slot MEAN (mean, because slot medians of per-second counts are degenerate).
- `lp_ag_w{10,30}` / `lp_with_w*` = max print size by the against / with aggressor over W divided by the prior slot median print size (flag at the consumer: >= k).
- `vol_ag_w{10,30}` against-aggressor volume, `retr_w{10,30}` = own best price retreat over W (ticks, sd-signed, >0 adverse), `abs_fail10/30` = 1 if against volume in W >= own best size W ago and retr>0 (absorption failing).
- `vwap_ent_sg` = sd x (cumulative VWAP since entry - entry) ; `vwap300_sg` trailing 300-s VWAP; `cdelta_ent` cumulative with-trade delta since entry; `cdiv_w60/w120/ent` = +1 when delta with the trade but price against, -1 when delta against and price with, else 0.
## LOSS side - price path (mid based unless `_pr`)
`unreal` = sd x (mid - fill_avg); `mae`, `mfe` running extremes with 0 baseline at entry (>=0 points); `mae_age`, `mfe_age` (= `stall`) seconds since the extreme was last reached/tied; `pullback` = mfe - unreal; `bounce_from_mae` = unreal + mae; `rf_bounce_last` = size of the bounce (best unreal since previous low minus that low) that preceded the most recent new low (recovery failure); `mae_pr`, `mae_pr_age`, `mfe_pr`, `mfe_pr_age` the same on print extremes (p_low/p_high per second, NaN-skipping); `unreal_last` on the last print; `mom{10,30,60,120}` = sd x (mid - mid lag w) (`vel30` = mom30, `vel30_chg15` its 15-s change), `eff{30,60,120}` = mom / sum|dmid| over w (signed), `k` time in trade (s), `tbin` 0 (<120 s)/1 (120-600 s)/2, `pct_stop` = max(-unreal,0)/stop distance (60, O7 40), `pct_target` = unreal/|target-fill|.
Bars (mid, completed bars only; a bar is complete at its last second row): `atr1m`, `atr5m` = mean of the last 14 true ranges (simple mean, not Wilder); `barclose1m_rel` = sd x (last completed 1-min close - entry); `nbar_fail` = number of consecutive completed 1-min closes beyond entry (adverse side) after entry (0 until a bar completes after entry); `swag{1,5}m` = sd x (mid - last confirmed 2/2 fractal swing against) (long: swing low; negative = swing broken), `swah{1,5}m` = distance to the swing ahead; `kijun_rel`, `ema20_rel`, `ema50_rel`, `ema_x` on 1-min bars (Kijun26 midpoint of 26-bar hi/lo; EMA span 20/50; ema_x = sd x (EMA20-EMA50)); `er20_5m` = 20-bar efficiency ratio on 5-min closes.
Levels: `d_pd_ahead/against` distance (points, can be negative) to the previous trading day's RTH high/low (ahead = high for long); `d_or_ahead/against` to the opening-range (09:30-10:00 ET) edges, rows before 10:00 ET or after 18:00 ET use the previous label day's OR; NaN until available.
## PROFIT side
`pct_target`, `ahead_rel_*`, `tot_rel_*` (above), `wall` = sum of ahead-side level sizes within +-2 ticks of the target when the window lies inside the visible 10 levels (long: ask level 10 price >= target+2 ticks) else NaN (mostly NaN: the 60-pt target is only visible in the last ~2 pts), `wall_med` = wall/med_e001; exhaustion = `vel30_chg15`, `dlt10_chg10` (change of dlt_w10 over 10 s), `mom*`; time-in-profit `tip_cum` (seconds with unreal>0 so far), `tip_run_tip0/30/50/70` (current consecutive seconds with unreal>0 / pct>=.3/.5/.7); pull-ahead = `cn_ag_*`/`pr_e001_cn_ag_*` (cancels on the side ahead).
## CONTEXT
`lots`, `entry_sess` (universe session), `entry_hour`, `entry_slot30` (ET 30-min slot at entry), `er20_entry`, `atr_regime` (per second = atr1m / prior-20-day median of the daily median 1-min TR) and `atr_regime_entry`, `sess_row` (session index of the row), `hour_row`, `min_since_sess`, `min_since_open` (minutes since 18:00 ET), `rth_min`, `side`, `tbin`, `b02_quiet` (overnight range 18:00-09:30 of the label day < 0.85 x median of the previous 20 days' overnight ranges; NaN with < 20 prior days) and `b02_applies` (book K7/P7/H7 and entry 10:30-17:59 ET), `n_open_same` / `n_open_opp` (other universe trades open at that second on the same / opposite side, open = entry_sec <= t < br_sec, hold-to-bracket windows), `day_real_usd` (realised net_fee of S1b-COMB / u5 trades of the label day that exited <= t, excluding this trade's own COMB twin), `since_cut_book_side`, `since_cut_book_any` (seconds since the last cut exit (StateCut/ThL2Cut/PolicyCut) of this book that happened BEFORE this entry; NaN if none; cuts inside the trade are deliberately excluded - a cut of the same trade would be a label).
Not built (state quantity unavailable or ambiguous): DS7 flip level (BT flip) distance - the flip is a bar-engine quantity not in the state arrays; $-based and ATR-scaled arm variants are rule parameters (use `atr1m`, `lots`); chandelier/trail are path functions of `mfe`/`atr`. Day P&L is realised only (open P&L of other books not included).

## NaN rules
Warm-up (insufficient rows, baseline < 5 days) NaN; book not live (no depth at the row: `have`=0) leaves the arithmetic as computed on zero book, flagged by `have` only in the state file (rare; none in the 931 days). Division by zero gives NaN or inf; inf counts are listed in the json (expected 0 or tiny). Per-feature NaN fractions per month: `YYYYMM.json`.

## Validation
(a) Live-line reproduction: S1-COMB StateCut exits vs the first-fire second computed from the stored features (`pr_e001_own_w<win>` >= mult, `-unreal >= arm` with the V0/V1/V2 arm variant on the filled lots, `mae_age <= win` for newMae, persistence): months 202608/09/10, trades matched to COMB by (book, side, entry second): 500 of 523 StateCut exits reproduced EXACTLY at the fire second (95.6 %), 512 within 2 s (the remainder: engine row-timing/entry price differences and 6-8 trades where my rule never fires, 7 of 523); 851 of 856 non-cut trades show no fire before their COMB exit. Run: `python3 -I code/th_exh/validate_a.py 202608 202609 202610` (table feat/validation_a.csv). (b) No look-ahead: every state row after s0 of one day replaced by noise: `python3 -I code/th_exh/validate_b.py 202609 <label> 0.55`: 39 trades, 120,978 trade-seconds at ts <= s0, 265 features, 0 differing values; the same run shows 244 of 265 features differ after s0, so the test has power. (c) NaN/inf statistics: `YYYYMM.json`, summary 44 months 202304..202611, 19,081 trades, 203.5 M trade-seconds (paths include the 1800-s post-target tails), 265 features each; inf only in qd10_own/qd10_ag (10 values each, lagged best size 0) and dlt_v60_w120 (46,382 values, no volume in the trailing 60 s); mean NaN fraction > 5 %: wall/wall_med 94.7 % (target not visible), rth_min 82 % (outside RTH), er20_entry 6 % (warm-up). Sources used: S1_nocut_timer 29 months, S1b_NOCUT_tick 14, u5 live-cut run 1 (202611): rebuild months when EX-CORE swaps.

## Size and run
206 GB uncompressed float32 (265 x 203.5 M); per month 0.8-4.4 GB. Build 25-30 s per month on one worker (L6M first, then reverse chronological). Known limitations: DS7 EWMA depth chain not replicated; BT flip level absent; COMB-derived context (day_real_usd, since_cut_*) comes from the S1-COMB run (u5 csv for 202611).
