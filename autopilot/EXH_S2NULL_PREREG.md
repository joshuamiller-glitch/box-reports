# EX-S2NULL PREREG (2026-11-09, before any placebo draw is scored)
Question: do the engine-confirmed Stage 2 candidates (exla_pb1 M7,H7,O7; phi_pb P7,O7; phi_thick K7,P7; bc_c_uniform K7) beat causal placebos run through the SAME engine cascade?
Design (code/th_exh/s2null.py, s2null_launch.py, s2null_score.py): per real set, every book of the set keeps the set's firing statistics but the rule is replaced by a null_ver-2 decision per position at its first manage call:
- rand: fire w.p. (real ExhCut rows of the book-month)/(real rows)/alive_frac (alive_frac = share of never-cut universe trades of that book-month still open at the real decision seconds; book-month level calibration so the EXPECTED fire count equals the real one; no per-trade life is used); which positions fire independent of every path; decision second drawn from the real fire seconds of the book-month.
- shuf: same inside book x entry-session.
- shift: the real kernel runs; its decision is moved LATER by U[60,600] s (never earlier).
Decision at kd executes at kd+1 by exh_core.market_exit (mid -+0.80; bracket first), full position. Engine cascade (re-entries, locks, gates, U7 blackout) plays out as in the real run. Draw d uses mode rand/shuf/shift cyclically (d-1)%3; seeds 1000*(mode+1)+d; per-position rng keyed on (seed, tag, entry_ns) so a draw is deterministic.
Windows: L6M months 202605-202610 (draws 1-20) and PRE months 202402-202506 (as many whole draws as time allows, draw order); no other windows, live week not run.
Statistics (book scope, all sessions, weekly USD at live lots, carrying week dropped for means as in the ledger): L6M and PRE maxDD reduction = never-cut maxDD - rule maxDD; mean delta = rule - never-cut weekly mean. p = (1 + #draws >= observed)/(N + 1), pooled over modes, plus per-mode and the house max-of-modes p. Real value from the same code path on the set's own runs. Label effect: placebo p <= 0.10 on the L6M maxDD cut is necessary for ENTER; failing it keeps the label at CANDIDATE-DD/LEAD/no (labels still need family p, WF, live week from the ledger; this study never claims PASS).
Determinism check: exla_pb1 202610 run twice more as s2null_deta/detb; trades.parquet compared with the original.
Load: <= 2 workers per set, STAGE2_MEM_GATE 44 GB, NUMBA_NUM_THREADS 4, OMP_NUM_THREADS 1; private tree /mnt/l2/l2vast/_th_exh/stage2 only; fees 4.84 RT per FEES.md.
