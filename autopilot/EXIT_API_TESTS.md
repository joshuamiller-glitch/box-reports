Rows are taken P6 trades whose BASE exit is the original stop (type 0) or target (type 1) - NOT already ended by a TH-L2 cut: an injected exit competes with the TH-L2 cut (the EARLIER of the two applies; the delta is always relative to the LIBRARY exit, not to the cut), so for rows the cut already exits the net change is dN_injected - dN_cut. Each example injects ONE exit on ONE taken P6 (PE) trade and reports the engine's own net $ for that trade before/after. $ per pt per lot-of-total is calibrated by the cost-sensitivity pair (xcost 0.80 vs 1.80: one extra point of cost) and the delta formula is checked against it: Delta net$ = dN x $/pt, with dN = side*(px - exit_px_lib) - xcost + fill_cost*(original exit not target) (per lot of the position that exits).
