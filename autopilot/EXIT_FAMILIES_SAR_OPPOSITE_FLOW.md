## 1. What is built (code/th_exiteng/)
| family | name | how it runs in the engine | files |
|---|---|---|---|
| B OPPOSITE-SIGNAL EXIT | oppx_v25 (stop vol 2.5), oppx_v15_t2 (stop vol 1.5 + 2R target) | one book via th_majorf/mf_inject; per-entry exit_ts = first OPPOSITE-side signal of the same cell (both-side signal frame, even for a long-only cell) +1 s (screen convention gexit.opp_force), else session end; exit class UWTime (engine market exit at that instant). Same path as the passed clock family. | xb2_events.py |
| A STOP-AND-REVERSE | sar_v15 / sar_v40 / sar_v60 (disaster stop = vol k x u, k = 1.5 / 4 / 6, no target) | **CAN be done**: two ONE-SIDED books through code/th_combo/mf_multi.py (own tag, own position, own state each: MF1 = long signals, MF2 = short signals). Each book enters every signal of its side while flat; a repeat same-side signal while in the trade is skipped by the engine (= screen sar rule i0 >= last); it exits at the first opposite signal +1 s, which is the entry signal of the other book (entry +2 s). So a flip = exit of one book at t+1 s + entry of the other at t+2 s: the reverse leg is its own injected trade at the exit time, the engine sees an exit and a new entry. After a disaster stop the book re-enters on the next same-side signal (screen rule). Session end flat. Why one book cannot: a one-position hook rejects the new entry while the old exit is pending; two books remove that. Caveat: the two legs are two orders (not one 2x order) and for a few seconds both books can be on the account; costs are charged per leg as for any trades. | xb2_events.py + th_combo/mf_multi.py (unchanged) |
| C ORDER-FLOW EXIT | flow_v25 (stop vol 2.5, flow flag any P&L), flowp_v15_t2 (stop 1.5 + 2R target, flow exit only when the print is better than the entry) | NEW hook xb2_flow.py = ex_inject (-> mf_inject) + per-second adverse-flow flags of _grid/flow1s/<YYYYMM>.npz (delta flip, absorption, book OFI, wall appear/pull, speed burst; OR = 'all'; components selectable via par flow.comp). Rule identical to the screen kernel (SP_FLOW): at the first print of tape second k > fill second, exit (market, request_exit, name ExFlow) if the flag of the previous tape second k-1 for the position's side is set. Causal (flag windows end at k-1). Uses data already on box 1 (_grid/tape ss.npy + flow1s), no purchase. | xb2_flow.py |
Support files: xb2_events.py (events + sets, names TL3_EXE_<cell>_<recipe>_<ADD|PLAIN|SARN|FLOWN>_IDN), xb2_walk.py (independent same-entry walker + inert compare), xb2_count.py (screen vs engine entry set), xb2_all.py (runs all checks), xb2_loop.sh (local runner).
