## 1. What was built (code/replica/, private data /mnt/l2/l2vast/_replica/)
One event-driven state machine over the 2,316,491 NQZ6 T records of the blind week (ts_recv order; the pre-trade 10-level book of each print = the NT8 OnMarketData snapshot; a 100 ms last-record book grid for fills) plus 7.65 M warm-up prints (raw/NQ/ext 2026-10-12..10-30) so the engines are warm. No calibration factor, no injected live exit/lot/offset/cost; the replica never reads a live file.
- extract.py / merge.py / l2pre.py: raw -> per-print table; l2pre.py = literal L2OnDepthSnapshot (MedLevel EWMA 0.001, imbalance, iceberg, sweeps), L2ThSnapshot (Depth8, half-hour depth baseline, pulledLog), the sgn rule, DepthLive.
- bars.py: NT8 time bars from prints, [k*P,(k+1)*P), bars exist only with prints, closed at the boundary (timer convention; first-print-after-boundary tested: no effect); 45-s bars hour-aligned (the confirmation times :15/:30/:45 reproduce the live P7 NY entry stamps 10:02:15, 10:20:15, 10:46:30, 11:51:45 to the second); Range-32-tick and Volume-500 bars for X3/X4 (conventions UNVERIFIED).
- ports.py: Keltner (K7, 3-min), St10 (U7, 10-min), PbEngine PB3B (P7) and PB7 (A7), MomentumVote (M7), session VWAP + Hm5Engine on 5-min buckets (H7), OpenDrive (O7), OnRangeGate, PoiSet (no-trade set + OTE-62), SsState (signal-state), AltEngine (X3-X5).
- sim.py: SessionLotsAt (A06 slots), TrendSize ER ladder, TryEntry order (blackout, confirm hold, L2 arm), L2Arm (OTE B73, NTZ, 70/30 split with banker's rounding), SubmitEntry (1 lot / 2 s slices, ArmStopPx basis, TradeStopPts), L2Pump with the 8 gates and the 1-s throttle, L2AddStage (incl. SlicesSent = Qty, which drops unsent slices), PlaceBracket on every fill, native stop / catastrophe 80 / JoinThenMarket (3 s passive join then market) for K7,M7,U7,P7 (H7,A7,O7,X native), PumpExit / RequestBookExit, ManageThL2 (loss branch; profit tighten only in the old panel), ManagePolicy (loss line; 300-s poll chain; Mon 08:05 take lines), CheckLimits / CheckBookLock / week floor, U7 blackout, stack rule, session flatten, O7 16:00, outage/restart handling.
- Fills: market orders walk the 10-level book LAT_FILL = 1.0 s after the decision (user-measured); resting targets fill on the first print at/through the level with time priority; native stops trigger on a print at/through and walk the book; the passive stop-join uses the displayed queue.
