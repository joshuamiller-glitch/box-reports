# GATE0_SPEC - Gate 0 acceptance harness (S4a for T-TH-REDO; QA: CHAR-C). Written and sha256-logged BEFORE any engine-V3 number.
Research only. Gate 0 = the fixed engine reproduces the ALREADY-LIVE blind week (Sun 2026-11-01 18:00 ET .. Thu 11-05 11:05 ET; live file data/live/StratTrades_DS7_<acct>.csv sha256 d918fee4e83e18521538aa37728c563036ca3597f8c6759b9610d1bf14565d00, 187 trades). No TH table is published until it PASSES; interim numbers are labelled PRE-PROOF.
Code: code/gate0/gate0_check.py (sha256 in DECISIONS.md with this spec). Reuses ZL-1's compare_live_model.py and blind_cmp_config.json unchanged (greedy nearest match on (book, side) by signal second; exact tolerance 2 s, P7 47 s, near tolerance 120 s, minute-resolution autodetect; live exit type from exitName: ThL2Cut -> thl2_cut, PolicyCut -> policy_cut, BookLock -> lock, _Stop, _Target; ThL2Trail / PolicyTake -> other).
## Input
Engine trade list (BASE-4 format; .parquet, .csv or .pkl with key T): signal_sec, book, side, lots, entry_ts, exit_ts (epoch s), entry_px, exit_px, exit_type, net_usd, optional closed (rows with closed false are dropped), period, th_cut. ENGINE CUT = exit_type in {thl2_cut, policy_cut} or th_cut true. Live CUT = exitName containing ThL2Cut or PolicyCut (92 in the blind week: ThL2Cut 53 + PolicyCut 39; live cut $ -140,350). Book tags: K6/P6/A6/H6/M6/U6/O6 are mapped to K7.. by the config alias.
## The four PASS/FAIL gates (all four must pass = GATE 0 PASS)
| # | gate | definition | threshold |
|--|--|--|--|
| 1 | trades matched | matched / union, matched pairs from the compare tool (exact + near levels), union = engine + live - matched; also printed: matched/live, matched/engine | >= 0.85 |
| 2 | net | abs(engine net - live net) / abs(live net), net = sum of net_usd (engine, closed rows) vs sum of pnlNet (live) | <= 0.15 |
| 3 | cuts matched | cut pair = a matched trade pair (gate 1 matching, same book, side, entry within the entry tolerance) in which BOTH sides are cuts AND the exit seconds differ by <= 10 s (CUT_X; engine decision/fill second vs live exit time); gate value = cut pairs / (live cuts + engine cuts - cut pairs), i.e. by trade, symmetric, penalising both missed and false cuts; recall (pairs/live cuts) and precision (pairs/engine cuts) printed | >= 0.85 |
| 4 | cut dollars | abs(sum engine net over ALL engine cut trades - sum live net over ALL live cut trades) / abs(live cut sum) (so unmatched and false cuts count) | <= 0.10 |
Also printed (informational, NOT gates): exit-type agreement on matched pairs, maxDD (realised, by exit time) engine vs live and the gap, the matched-pair cut-dollar delta (live minus engine over matched pairs where either side cuts, as a fraction of abs live cut $), per-book cut table (live cuts, engine cuts, matched, cut $ each, missed, false), the lists of missed cuts (live cut; engine held / no engine trade / cut off by more than 10 s) and false cuts (engine cut; live held / no live trade / timing off).
The cut timing tolerance 10 s is fixed here; it is wide against the live 1-s decision cadence plus 1-s latency and narrow against the 10-s engine grid, so the old grid cannot pass by luck. No parameter of the check may be changed after a V3 number exists; a change needs a new spec with its own sha256 and all earlier iterations re-printed.
## Iteration log
Every run appends one line to autopilot/GATE0_ITERATIONS.md (>>): time, label, tree/config sha (--cfgsha), prediction file sha, the four values with P/F, GATE 0 result. BASE-4 runs it as: python3 -I code/gate0/gate0_check.py --pred <list> --label <name> --cfgsha <engine v3 config sha>.
## Guard
The live file may be read only with --live-open-ok, except the blind-week file by its sha256 (already read and sealed against). Any other week's live file requires the flag and a logged prediction seal.
