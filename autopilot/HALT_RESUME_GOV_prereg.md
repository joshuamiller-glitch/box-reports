# HALT_RESUME_GOV_prereg - T-HALT-RESUME (GOV-1), written before any halt cell was scored (2026-10-31)
Engine: D6-faithful lock engine (gf_lib: all-signal running-max BookR, session-lot R, per-book day/week locks, COMBINED 12R(K6) week lock), integer half-up min-1 lots, live lots, Native 1.28, N basis, 70/30 integer split (A6 market). UNTOUCHED never read (cap 20260206). Windows L3M 20251106.., L6M 20250801.., HOLD 20250701.., PRE 20240201..20250630, X' 20230401..20240131.
Mechanics: decision at each baseline-taken trade of a book (the paper track = the baseline stream of those trades with the same fills/brackets); trigger read from trades closed before the signal; halted entries are removed from the lock engine (halted books absent, locks/re-entries real, open trades run to brackets); lots not re-allocated (equal-risk factor reported). Resume rules are checked at each later signal; after a resume the trigger needs at least one new closed trade before it can fire again.
