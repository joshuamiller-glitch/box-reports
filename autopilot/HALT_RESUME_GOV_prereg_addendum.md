# HALT_RESUME_GOV_prereg_addendum - stage 2: market-condition, combined and learned halts (GOV-1), written before these cells were scored
Same engine, windows, mechanics and carry rule as HALT_RESUME_GOV_prereg.md. Fixed definitions (not tuned):
REGIME BAD STATES (from the T-TREND-GATE store, readings at every library signal of all books used as a pseudo time series; persistence M in {30,60,120} min = at least 2 readings in the last M minutes and ALL of them bad): er = 5m ER20 < 0.30; ci = 5m Choppiness(14) > 61.8; adx = 5m ADX(14) < 20; vr = variance ratio q5 W240 < 1; xasset = ES-NQ 20-min correlation below its PRE+X' tercile cut. Regime reversed for M min = at least 2 readings and none bad.
MAP HALTS (per book, from its own PRE and X' map, a state is halted only if its mean r < 0 in BOTH PRE and X' with >= 15 trades in each): vol (rv5m vs 20d median, terciles with PRE+X' cuts), dow (weekday), daytype (prev_daytype tag), event (FOMC/NFP/CPI day). MAE shift: rolling mean MAE over the last K (10, 20) trades > expanding mean + 1.5 SE.
Not run (named): HMM chop state, negative-autocorrelation measure, 'everything together' macro score (stack), ES/RTY direction disagreement beyond the 20-min correlation, release-window minutes (only day flags).
COMBINED: perf in {streak4, rs10_3, rs20_3, wk2_3, ddt20_5, z20_1.5} x regime in {reg_er_60, reg_ci_60, reg_adx_60, reg_vr_60, map_vol, map_dow, map_daytype, reg_xasset_60}, AND and OR; resumes mem (halted only while the condition holds), ses, day, w2.
Resumes for regime halts: mem, rev (regime reversed >= M min, the M of the halt), ses, day, hi.
LEARNED: per book, features = streak, last 5/10/20 sums, equity minus MA20, three perf flags, ER20 / chop / ADX / VR / vol ratio / ES-NQ corr at the signal, weekday, session; label = the next 5 trades of the book sum < 0; logistic regression (C = 0.05, standardized), re-fit every week on all earlier decisions whose label window closed before the week (expanding window, >= 200 samples; the directive's 3-month window gives < 100 samples per book so the window is expanding - stated deviation); halt when p > 0.55 / 0.60 / 0.65 (memoryless); shuffled-label placebos (2 seeds) with the same code.
