# HIST-PIPE validation criteria (PRE-PROOF; written before the full-range run; dev runs on the blind week preceded it, disclosed)
Code: code/hist_pipe/{hp_core,hp_stream,driver,val_compare}.py (sha256 recorded in DECISIONS.md line). No PnL, no rule scoring, no PASS claim.
Data: raw NQ.v.0 mbp-10, monthly 2023-02..2026-10-11 + ext daily 2026-10-12..10-30; private output /mnt/l2/l2vast/_hist_replica/ only.
V1 blind-week equality: regenerate labels 20261102..20261105 from raw/NQ_blind with the final code; every array (p_ts_recv ts_event px sz side seq flags lastdep bpx bsz apx asz; all keys of blind_l2pre_c2.npz incl. med, cb, ca, rel, snap, live, row, sgn, ice*, sw*; cnb cna tnb tna; 100-ms grid all keys; 1-ms grid level 0 ts/bpx/bsz/apx/asz) equal to the existing replica arrays by np.array_equal (NaN-aware). Allowed exception, stated in advance: prints that open an old hourly extractor file before its first non-trade record have lastdep=0 in the old arrays (extractor artefact: last_nont reset per file); there the new arrays carry the true value and live may differ; every difference must be explained by this and be at an old-file-start print.
V2 warm-up convergence: month blocks start with W warm-up trading days from a fresh state. Reference = block 2026-09 with W=40 calendar days; candidates W in {3,5,7} calendar days. Choose the smallest W such that, on owned days from the second trading day on: snap/live/row/sgn identical, max relative |med diff| <= 1e-6, cb/ca equal on >= 99.99% of snapshot rows, rel equal within 1e-6 relative on >= 99.9% of non-NaN rows. If none qualifies use W=7 and report. Day 1 reported, not part of the criterion. (Convergence to the long-warm-up reference only: neither is the unknowable true live state.)
V3 determinism/resume: delete the last 2 day files and manifest lines of a finished block, resume: sha256 of regenerated day files identical to the originals.
V4 independent count: for one full month (2025-06), an independent simple reader (action=='T' count and sum of size per label day) equals n_prints and contracts of the day files for every day.
V5 per-day flags (reported in the coverage table; no day excluded by the pipeline): ts non-monotone count 0; weekday of label Mon-Fri; n_prints >= 1; crossed/locked book at T <= 1e-4 of prints; number of instrument ids <= 2 and 2 only on roll days; |last price old id - first price new id| flagged if > 600 pts; RTH (09:30-16:00 ET) record gaps > 60 s listed; early-close/short days flagged (last print before 16:30 ET Mon-Fri, or first print after 18:30 ET).
Roll rule used: the instrument id present in the file (Databento NQ.v.0 = volume leader, switch at 00:00 UTC mapping date); what the live NT8 platform used is unknown and not verifiable from disk.
Pipeline validated (PRE-PROOF) iff V1, V2, V3, V4 all hold; V5 flags are reported only.
