# IDEAS_BM - batch BM (worker BK, 2026-10-17), registered BEFORE any BM run
Ten literature mechanisms with no hit (keyword search over LEDGER, GAPMAP*, BACKLOG*, IDEAS_*, PREREG, every REPORT_*) for the key terms: leveraged-ETF rebalancing, Amihud illiquidity, Faber/SMA-200 timing, weekly reversal, monthly reversal, ADR exhaustion, high/low time-order, up-day fraction, daily z-score reversion, overnight persistence. Excluded as covered: pivot points (12 hits), roll-week (15), run-length (17), key reversal/outside day (5), hourly boundaries (7), Friday-Monday (9), XS intraday momentum (2 hits, BASKET/XS), volume spike (SW6).
1. BM1 LETF end-of-day rebalancing (Cheng-Madhavan 2009; Tuzun 2013): leveraged/inverse index ETFs must buy after up days and sell after down days into the close, in proportion to the day's return; sign WITH the day's move since the prior close, entry 15:20/15:30/15:40 ET, exit 15:55. Indices only (ES NQ RTY YM).
2. BM2 Amihud illiquidity day (Amihud 2002; liquidity-provision premium): after a day of high |return|/volume the next day earns a premium (long) or reverts; general (8 instruments).
3. BM3 Faber timing (Faber 2007): long when the prior close is above its 100/200-day SMA, or short below; general. The classic drift-sensitive rule; the matched null is the test.
4. BM4 Weekly reversal (Lehmann 1990; Jegadeesh 1990): the prior week's return reverses at the start of the week; sign AGAINST; general.
5. BM5 Monthly reversal/continuation at month start (Jegadeesh 1990; Heston-Sadka 2008 seasonal return persistence): first 1-3 trading days of the month against/with the prior month's return; general.
6. BM6 ADR exhaustion: after the label day's range so far exceeds 0.8-1.0 x ADR20 by 12:00/13:30 ET the move is spent (ranges mean-revert to their average; Parkinson range dynamics); sign AGAINST the day's direction; general.
7. BM7 High/low time-order: when the prior day printed its high before its low (distribution then sell-off) vs low first; informed-flow sequencing (Dalton/market-profile; Lo-Mamaysky-Wang pattern literature is about shapes, this is time order); sign WITH the late extreme (low-first = bullish); general.
8. BM8 Up-day fraction (Kaplanski-Levy / sentiment-persistence): fraction of up days in the last 5/10/20 days beyond 70/80% (30/20%) continues or reverses; general.
9. BM9 Daily z-score reversion to the 20-day mean (Poterba-Summers variance-ratio mean reversion; Bollinger at the daily scale): sign AGAINST for |z| >= 1.5/2.0; general.
10. BM10 Overnight persistence (Lou-Polk-Skouras tug-of-war, the overnight-to-overnight leg: overnight returns persist across nights; BI2 tested RTH->overnight and overnight->RTH): next Globex session (18:01-09:25) in the direction of the prior Globex return or prior close-to-close return; general.
## Protocol (frozen)
Machinery: ap_bj_pipe.py clone (ap_bm_pipe.py): SW sleeve pipeline with the drift- and clock-matched random-entry null (real long/short mix, the family's valid mask pins the clock), 200-replicate false-selection test and 200-replicate own null on the selected cell, clean-only selection (>= 100 clean trades, MINTR 60 for the daily-cadence BM2-BM9, small-sample flag < 100; weekly Sharpe > 0 in both clean halves), H1/H2 once, additive 10/20/30/50% (+0.10 on clean/H1/H2, worst week within the share), bootstrap, plateau +-25%, 2x slippage, worst-decile corr <= +0.30, ERA flag with cost decomposition, library save, replication leg (ap_bi_rep). Instruments: BM1 ES NQ RTY YM; BM2-BM10 ES NQ RTY YM GC CL ZN BTC (the 8 instruments with a conforming series file); the extension to the other outrights (6A 6B 6C HG HO LE NG NKD PL RB SI ZC ZF ZS ZT ZW HE ETH) is run for any family that reaches LEAD. Fill: next 1-min open, 1 tick/side + $4.36/contract; time exits at the open of the exit minute. Priors <= 3%.
## Grids
- BM1: entry T {15:20, 15:30, 15:40} x |price - prior RTH close| >= x {0.4, 0.7, 1.0} ADR20 x dir {with, against}; exit 15:55; 18 cells.
- BM2: prior-day |close-open|/volume percentile among the previous N {60,120} days >= p {80,90} x mode {long, with day sign, against day sign}; enter next RTH open, hold flat; 12 cells.
- BM3: SMA length N {100, 200} daily closes x mode {long above, short below} x hold {RTH, close-to-close}; 8 cells.
- BM4: prior-week return z (/ ADR20 x sqrt5) >= th {0, 0.5} x dir {with, against} x hold {RTH Monday, 2 days}; 8 cells.
- BM5: first k {1, 3} trading days of the month x dir {with, against the prior month's return} x hold {RTH, close-to-close}; 8 cells.
- BM6: clock T {12:00, 13:30} x range so far (label day high-low) >= x {0.8, 1.0} ADR20 x dir {against, with the move from the label-day open} x hold {60, 120}; 16 cells.
- BM7: prior-day extreme order x range filter f {0, 1.0} ADR20 x dir {with the late extreme, against} x hold {120, flat}; 8 cells.
- BM8: window N {5,10,20} x threshold {0.7, 0.8} (and 0.3, 0.2) x dir {with, against the majority}; enter RTH open, hold flat; 12 cells.
- BM9: |z| of prior close vs SMA20 / sd20 >= k {1.5, 2.0} x dir {against, with} x hold {RTH, 2 days}; 8 cells.
- BM10: state {prior Globex return, prior RTH close-to-close return} x threshold {0, 0.15} ADR20 x dir {with, against}; entry 18:01, exit 09:25; 8 cells.
