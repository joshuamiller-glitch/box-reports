# NEAR_ZONE_API (W-N, 2026-11-11) - for W-N2 (families k l r s t u v and the near-zone joint stage)
Code: code/th_nz/  Bulk: /mnt/l2/l2vast/_nz/ (grids, finalist json, extraction in x/). Shadow only. Frame: LPB_BASE stored trade list (20,807 trades, 16,283 with a 1-s path; cache /mnt/l2/l2vast/_th_ptr/cache/LPB_BASE: U.npy side-signed mid u in pts per second from the first u>=0.2 T to 2 s before the live exit; F.npy 38 features; off.npy row offsets; trades.parquet with r0 r1 file = rows in the state day file /mnt/l2/l2vast/_th_state/days/<file>.npz).
## Objective and definitions (same everywhere; per WEEK, L6M = 24 wk, ALL = 43 months)
d = new P&L under the rule minus live-rule P&L per trade. net = sum d over every fired trade; removed (zone) = d over fired non-fills that reached 80% of target; clipped = sum(base-new) over fired trades that filled under live rules; other saves = d over fired non-fills outside the 80% zone; net = removed - clipped + other. key = min(net L6M, net ALL). Trader test: no L6M trade that reached 90% closes <50%, none that reached 80% closes <=breakeven (columns v90_*, v80_*; b90/b80 = live-rule counts).
## Modules
- nz_kern.py: kernel for families a-g (ladder, reversal, flow, bank, stall/work, zone, block). base_params(**{'p<i>': v}); eval_cells(F,U,off,T,P,ue,us) (numba parallel; set NUMBA_NUM_THREADS). Param slot map in the module docstring. Output ue = u-equivalent + 1.2 so ptr_fo.score(slip=1.2) and nz_eval.metrics work unchanged; p31 = forward lag seconds (placebo only).
- nz_kern2.py: families h i j m n o p q: eval2(...), cells in nz_grid2.cells(). Uses per-second print extremes H/LO, queue QM (resting size at the target level / MedLevel; NaN when the level is beyond the top-10), VT, extension EU/EL (30 min after a Target fill), aux (ATR14 of 1-min mid ranges, t0off, PDH PDL PWH PWL ONH ONL). Passive limit rule: fills at price - 0.25 when a later second printed >= price + 1 tick (queue-conservative).
- nz_extract.py -> /mnt/l2/l2vast/_nz/x/{H,LO,QM,VT,EU,EH,EL,eoff}.npy aligned to cache offsets (state prices are int32 quarter-points: divide by 4). nz_prep.py -> x/aux.parquet.
- nz_eval.py: Universe(p7x) (p7x=True rescales P7 lots 12/7,7/4,7/4, per-lot probabilities identical), run_cells, metrics(U,book,idx,ue,us,fracs) -> per-cell frame (net/rem/clip/gb/rt/v90/v80 + FO stack cuts L6M/HOLD/PRE/X'). nz_grid.py (a-f main, c flow), nz_final.py (g combos), nz_grid2.py (h-q), nz_pipe.py (merge, forward time-shift placebo p_plc/p_fam, finalists best_pass_market/best_pass/best_market/fam_*), nz_accept.py (trader test, 20 worst, live week), nz_report.py (scorecard), nz_page.py (DS3_NEAR_ZONE.md), nz_exact.py (exact sets + chain), nz_dead.py.
- Registry: /mnt/l2/l2vast/_nz/all_<book>.parquet (a-g, one row per cell incl. src/cell_i), grid2_<book>.parquet (h-q), fin_<book>.json (finalists with param vectors P (nz_kern slots)). Books: P7x = P7 at 12/7/7, P7, K7, M7, U7, H7, A7, O7.
