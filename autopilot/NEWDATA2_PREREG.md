## 1 ES order-by-order (priority 1) - data Aug 2-Oct 31 2026 only, L3M-only smoke
Build: th_newdata2/es_mbo_sec.py = the NQ book code (th_confl_cf2/mbo_sec.py imported unchanged) on the ES monthly files with state carried across months; per-second table, same columns. First UTC day of a newly tracked instrument (roll) is dropped until 23:00 UTC (book not rebuilt) = NaN.
(a) Frozen NQ L3 lead on ES at each NQ entry second T: value = (own-side adds within 5 ticks of own touch - opposite-side adds)/max(sum,1) over the 60 complete seconds ending T-1 ("H_arrival_imb60", same code); yes = value <= 20th percentile of the same raw value over entries of the previous <= 20 trading days (all books, >= 150 prior entries; expanding until then, same as the NQ rule); no refit, no new threshold. Also W=30. Reported: lift (yes minus no, $/trade base lots, week-cluster t) and the nonsense bar from 200 persistence-matched nonsense conditions (P(yes)=0.2, day component 0.6); cell = "half the trades that are NOT yes" and "skip the top-20% (arrival_imb60 hi)" scored as entry cells with the full control set.
(b) ES-minus-NQ divergence: the same value on NQ (cf2_mbo per-second table, same code) for the same trades; groups yes_ES & !yes_NQ, !yes_ES & yes_NQ, both, neither; the partial association = weekly-cluster regression of trade $ on yes_NQ and yes_ES together (ES adds only if its coefficient is nonzero with NQ in).
(c) Turning against an open trade in ES order flow: ES 60-s market arrival imbalance (bid adds - ask adds)/(sum) signed with the trade, trigger = signed value <= the NQ training (exit days < 2025-11-01) q = 0.05 / 0.10 quantile of the NQ entry-time distribution of the same quantity (frozen threshold from NQ; no ES refit), checked each minute in-trade, cut at the next minute on the NQ path; controls = shifted labels + random exits with the same share and minutes-since-entry distribution.
Books: all 7 pooled and per session (asia thin). Decision rule (user/lead): ES reaches SMOKE-LEAD in L3M without refit AND the ES coefficient is nonzero beside NQ -> quote the full history; else stop. Nonsense family: ES value from a non-adjacent period (shifted 60 sessions) + random-walk order flow.
