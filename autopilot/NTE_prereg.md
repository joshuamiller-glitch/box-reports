## 4. Section B (single-state rules)
Cell = mask x action x base x scope. Actions on fired signals: skip, size 50%, size 25%, delay 5 min, delay 15 min (hold the signal, take it at market at the first print second >= N min later +1 tick if the original stop / target / arm has not ended it, stop = original stop level, target = fill + td; invalid = skipped, scored as such), re-target (target x0.5, stop and lots unchanged). Section D actions: keep-only (skip every defined signal OUTSIDE the mask), size-up x1.5 and x2.0 inside the mask. Bases MKT and SPL. Scopes: ALL, 10 books, 6 sessions. Cells: 1,038 masks x 9 actions x 2 bases x 17 scopes = 317,628 cell-scopes (18,684 pooled cells); this is the multiplicity (cumulative with earlier programs: UF_TRIALS side followup_nte).
Score = gain per signal of the scope (rule net - base net over ALL the scope's signals, so skipped winners are charged), kept-signal gain per contract of final lots, skipped signals' mean P&L beside it, fire rate, kept trades per week, lock-engine stack $/wk (selected cells), the lot-factor-matched uniform scaling control (gain minus (lot ratio - 1) x base mean), $ at live lots and research lots.
SELECTION (PRE u X' only, basis N): a cell is eligible if gain per signal > 0 in PRE and in X', n_fire(PRE u X') >= 100 (>= 50 in a book / session scope); ranked by z(PRE u X'); carried = top 400 pooled (ALL scope) per base + top 60 per book scope per base + top 30 per session scope per base + the NAMED cells (every directive-quoted rule, listed in nt_named.py). The carried list is hashed in DECISIONS.md BEFORE the recent windows are touched. ONE recent look (L3M, L6M, HOLD, Y26) per prereg group {B single-state, C combinations, D opposite side, L learned}.
Placebos on every carried cell: (a) random fire sets at the same count per book x session x target-distance x side stratum (200 draws; skip / size / keep-only / size-up: exact; delay / re-target: the same random sets through the same outcome vectors), rank of the real L6M gain; (b) shuffled-day state (states permuted across label days within book), 100 draws; (c) time-shifted state (state of the signal 60 s earlier is not available for all; the lag-by-one-signal-in-book state), 1 draw. Tiers (poi_tier gates, not softened): LEAD (PRE>0 and X'>0 and L6M >= 0), CANDIDATE-RECENT (L6M>0, HOLD>0, per-contract L6M>0 and HOLD>0, placebo >= 0.90), PASS_pre_RC (all that + placebo >= 0.95 + above MDE + stack > 0 in L6M and HOLD); a rule reaches the Sunday brief only if per-contract >= 0 in L6M and HOLD, stack >= 0, placebo beaten. Selection-window evidence of selected cells is label 'selected'; anything named after a recent look is 'post-hoc'.
## 5. Section C (combinations, learned)
Pairs / triples of the top-30 masks ranked on PRE u X' (single-cell gain, skip action, basis N), any-of-k (k = 2, 3 of the top 10), four-legged (one mask from each of location / time / volatility-book / after-event, best PRE u X' per leg), nested with the 8-line set (set8 line ahead within 20 pts AND a state). Learned: LightGBM binary classifier of P(target) (market base) from ALL 655 states + sided signal-quality columns, walk-forward: weekly re-fit on the trailing 3 months (and 12 months) of trades CLOSED before the re-fit, predictions for the following week; policy: skip / 50% / full by predicted-P buckets (thresholds = the training window's 20th / 40th percentile of predicted P); calibration curve by decile; shuffled-feature placebo (rows permuted within book in the training window, 10 draws); <= 6-rule extraction (depth-3 tree fitted to the model's skip decision on PRE u X'); retained gain; per book and pooled; stack line for each.
