# NTZ-1 PREREG group B (entry rules by the POI AHEAD / BEHIND the signal) - 2026-10-30
Agent NTZ-1. Mechanism and predicted effect: a signal whose target lies beyond a FRESH reversal-prone POI is less likely to reach it; skipping / sizing down / re-targeting such signals should raise the per-signal and per-contract result in the windows, with the effect largest for the POI classes the map (section C, PRE u X' ranking) ranks highest; a POI BEHIND the entry (support) should do the opposite (size up / tighten). Predicted size: P(target) differences of the map are 0.03-0.10 on n of 100-500 per stream, i.e. rule gains of order 0.1-0.5 pt per fired signal, i.e. inside MDE for most books; the program expects mostly DEAD with a small number of CANDIDATE-RECENT cells and has no prior that any survives the placebo (random fire set at the same rate; random level at the same distance distribution).
Disclosure: section C (DS3_POI_MAP.md, prereg sha in DECISIONS.md) already printed recent-window (L6M / HOLD / 2026 / L3M) adjusted differences of P(target) for its ranked streams and for named lines. The rule groups below SELECT on PRE u X' only; the recent windows are therefore not independent of the map for the streams the map listed, and every rule cell's recent number is labelled with 'map-seen' when its stream was in a printed table.
Data/bases: 44,370 capped trades (10 books), measured fills; bases M, N (no target correction), LIVE (= LIVE-P9: stop-class exits 2.45 pt); entry bases MKT (market at the signal second, 1 lot) and SPL (70/30 plain 3-pt dip split, risk-sized remainder, target re-based on the average = the L2SE floor via cf_engine). Masks own and capped 20260206 (Y26, L6M, HOLD, PRE, X'; L3M = 20251106..20260206 VIEW only). UNTOUCHED never read.
## Cell grid (feature-only enumeration; fire counts on PRE u X' >= 100; no outcome used) - file out/ntz/cells_B.csv sha256 c7fa6d6f8f73cf5556005abcc304a52ae1c5de00863db2511a7d0e5d1bbe3fa2 (127,548 cells x scope ALL + 10 books)
stream (689 POI streams, definitions in code/poi/README.md) x D {5,10,15,20,30,40,60 pts; 0.5,1,2,3 ATR(15m,14)} (BEHIND: {2,5,10,15,20 pts; 0.25,0.5,1 ATR}) x variant {fresh, any (fresh or mitigated)} x action x base.
Actions: skip | z50 | z67 (size 50 / 67 %) | rt (target = nearest fresh POI ahead - 2 ticks, lots kept; untargetable if < 2 pts: unchanged) | rs20 / rs30 (re-target, skip if the new target < 20 / 30 pts) | wt (market entry the second after price trades 1 tick through the POI; stop = original stop level; target = fill + original td; unfilled = no trade) [MKT only] | b73 (70 % at the signal, 30 % added after the trade-through, original stop/target) [MKT only] | u150 (size 150 % when a fresh POI of the stream is BEHIND within D) | ts (stop to just beyond the supporting LINE POI, +2 ticks, lots scaled to the original risk, cap 2 lots) [line streams only].
POI definitions are the code/poi store (ahead = between entry and target; behind = between entry and stop; direction-bearing arrays count ahead only when they support the other side).
## Metrics
PRIMARY: gain per signal (planned-lot unit) = mean over ALL group signals of (rule net - base net) on basis N; week-clustered SE, z, MDE = 2.8 SE. SECONDARY (always printed): per contract of final lots on the kept signals vs the base (rule net/lots - base net/lots), kept share, skipped signals' mean P&L beside the kept signals' mean (a filter that skips winners is scored as such), fired-signal mean under the rule vs base, lots ratio, and the lock-engine STACK line ($/wk, exact engine, 6 engine books) for every selected cell. A result is real only if it holds on the planned-lot AND per-contract AND stack units (CF-A/CF-B lesson). Re-target / wait / split-behind cells are STRUCTURE unless they beat the random-level placebo at the same distance distribution.
## Selection (PRE u X' ONLY; one selection file hashed and logged before any recent window is read)
Per (action x base) group and per scope (ALL and each of the 10 books): eligible = gain per signal on N > 0 in PRE and in X' separately, nfire >= 100 (ALL) / 40 (book) on PRE u X'; rank by z (week-clustered) on PRE u X'; keep the top 3 per scope. Plus the USER-NAMED cells (evaluated regardless of selection, labelled NAMED): per book and side-pooled, streams {ARR|FVG|4h, PDX|day|H, PDX|day|L, PDX|week|H, PDX|week|L}, D=60, fresh, actions {skip, rt} x {MKT, SPL}.
ONE look at L3M (view), L6M, HOLD, Y26 for the selected + named cells. Per-session breakdown (6 sessions) reported for every selected cell.
## Placebos / validity (QUANT-LAYER, run on every selected cell and on the PRE-selected rows)
random fire set at the same fire rate within strata (book x session x side x td-bin), 200 draws, rank of the real gain (skip/size/u150); random-level placebo (distance distribution preserved, permuted within book), 20 draws for sim actions (rt/rs/wt/b73/ts); shuffled-day POI (feature rows re-assigned across days within book) 20 draws; White RC and Romano-Wolf over each group's cells on weekly PRE u X' gains, studentised, cumulative count 143,584 earlier cells + this program (UF_TRIALS side=ntz); DSR with the number of trials; PBO (CSCV) per group; day- and week-clustered SE; Newey-West; block bootstrap CI; sensitivity (D +-25 / +-50 %, 8-neighbour mean); latency 1 s / 3 s for the market-base actions; breakeven cost; capacity; top-5 % trade share; stack correlation; drift (rolling 3-month, quarter sign count). qv.py (code/quant) is imported.
## Tiers (never softened)
PASS: L6M and HOLD gain per signal on N > MDE and per contract kept > 0, PRE > 0 and X' > 0, placebo rank >= 0.95 (L6M), stack delta > 0 in L6M and HOLD, cumulative RC p <= 0.05. CANDIDATE-RECENT: L6M and HOLD gain on N > 0, placebo rank >= 0.90, fails some other gate. LEAD: >= 0 in PRE and X' and L6M, below MDE or placebo not beaten. BEST-AVAILABLE-NEGATIVE / DEAD otherwise. Rows to l2vast/ds3/out/dead cells (append_cells) and RECENT_WINS (ntz1.csv view, L3M).
