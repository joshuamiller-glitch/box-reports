# PASS2_COMBINER_SPEC (W-P2A, 2026-11-19 ~19:05Z) - pre-registration of the generic combiner screen, written BEFORE the TEST scoring (3 books per session)
Companion of PREREG_PASS2.md (sections 1.1 C1-C3, 1.2, 1.3, 3), which stays the master text; this file only fixes the screen implementation. Code: code/th_pass2/p2_core.py, p2_cond.py, p2_search.py (hashes in the DECISIONS line). A debug run of the code on Asia rank 4 (time_m_3 pullback_ema) happened before this hash while the code was being finished; its numbers are discarded and the code changed after it (score floor, contest = floor-passing settings only, hold-out columns, search-aware null).
1. Book = BEST_BOOKS desc (bar row, trigger module, variant, params, bracket, side); events = the trigger's raw signals in the book's session (session code from the set name), side filter as stated in desc; one lot; screen walker = grid tape walk (gcore2.walk1: same stop / target / print rules, measured slip table, cost 4.84 USD per lot RT) + one-position blocking per UTC month, re-blocked after any skipped event.
2. SCORE = L6M $/wk / max(L6M own ulcer, 200 USD); ordering shown beside it: ulcer, max DD, worst week, $/wk. L3M beside. Fit window L6M only; prior years 2023 / 2024 / 2025 (202511 excluded) are HOLD-OUT columns, never used in selection.
3. Floor (PREREG 1.3): after any setting, L6M and L3M each keep >= 60% of the reference trades and >= F trades per week: Asia 5, NY AM 2 (PREREG), London 3 and NY PM 2 (my proposal for the sessions the PREREG does not fix; reasoning: below the 10th percentile of first-look books). A setting that fails the floor stays in screen_all.csv (gate_ok False) and is out of every contest, ranking and null best-of-K.
4. Library: p2_cond.py (families a-f, about 340 conditions, each oriented to the event side, causal at the bar close of the signal bar; level proximity units u = trailing 50-bar median range of the book's bar: 0.5 / 1 / 2 u; HTF = same bar type at the sizes nearest 3x and 5x; grid state modules = momentum + trend modules with state_fn at DEFAULTS, the book's own trigger module excluded). Conditions with L6M coverage < 0.8 or rate < 2% are 'not applicable' on that book and listed.
5. C1 search: all singles; POOL = top 12 singles by gain (own L6M score minus the mean score of 200 matched random-skip draws) among those with positive L6M gain and L3M $/wk above the null mean; pool completed with the best of the rest up to 6 if fewer qualify; enumeration over the pool: subsets of size 2-3 with k in {all, majority, 1}; greedy chains for N=4..12 with k=all, k=N-1 and (extra) k=majority, each step adds the floor-passing candidate with the best L6M SCORE, stops when none improves; EXTENDED (EXT) beam search: pool 60, beam 25, N <= 10, k in {N, N-1, majority}. Not exhaustive over the library (2^340 subsets); the null pays for the K settings scored.
6. C2: metrics ER20, ER50, ADX14, SQZ_width (Bollinger/Keltner), session range so far vs 20-session median, previous session range vs median; thresholds = percentiles 25 / 33 / 50 / 67 / 75 of the metric over the trailing 60 sessions (events of earlier sessions only); actions trend_only, range_only, flip_in_range, flip_in_trend (flip = take the opposite side at the same bracket); plus squeeze on / off. C3: drop one 30-minute block, keep one contiguous window >= 2 h, drop first / last 1-3 blocks, drop 1 or 2 weekdays; guard: the dropped events' reference-trade P&L must be <= 0 in both the odd-week and the even-week half of L6M, otherwise the setting is listed but not eligible.
7. Null: block-matched random skip (same number of kept EVENTS per week, drawn within the week, same walker incl. re-blocking; flips = same number of flipped events per week). Draws: 200 for every screened setting, 1000 for the top 10 of a component, 10000 for kept settings. Best-of-K (max-T): 200 replicates of the best score over K random sets of the sizes of the floor-passing settings of the component; the component best must beat the 90th percentile. SEARCH-AWARE null (C1, TEST uses 10 replicates, draws0 = 30 for the inner pool gain): the whole C1 search repeated on condition rows permuted within weeks; the real best must beat the permuted bests.
8. Kept per component: C1 5, C2 3, C3 3 = 3 (C1: 3) by SCORE + the rest by lowest L6M ulcer with $/wk >= 80% of the reference, each with floor passed and p6 <= 0.10 against the 200-draw null (dedup of identical keep vectors > 97%); if none passes, the best floor-passing setting of the component is carried with the note BEST OF COMPONENT, not proven. Labels follow PREREG_PASS2 section 2; this screen never labels above WEAK-BUT-POSITIVE on its own.
9. Interface to W-P2B: flags parquet /mnt/l2/l2vast/_pass2/flags/<setid>.parquet (ts = signal t_close s + 2, side, flag_<setting>, flip_<setting>, er, state, bits, nconf_<setting>), null file <setid>_null.parquet (flag_null_<setting>_<seed>, seeds 0-19), settings JSON /mnt/l2/l2vast/_pass2/combiner/<setid>/kept.json, all-settings table screen_all.csv.
