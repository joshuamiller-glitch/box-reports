# PASS2_HOOKS (W-P2B) - engine hooks for the pass-2 components. Research only. Updated 2026-11-19 ~19:30Z (first post; updated as identity lands)
Code (copies only; live strategy code and the production driver untouched): code/th_pass2/ = p2_inject.py (the hook), p2_events.py (events + set JSONs), p2_ref.py (independent references), p2_identity.py (same / audit_cool / walk / split), p2_equalrisk.py, p2_loop.sh (local runner on the PRODUCTION driver tp_launch.py + th_works_j/jn05_run2.py, nice 10, NMAX 4, MemAvail guard 50 GB).
ONE hook wraps xb_inject (so every W-EXITENG/W-XB1 exit recipe composes); multi-stream mode wraps th_combo/mf_multi (separate Book per stream). Set names: TL3_EXE_P2_<cell>_<VARIANT>_P2ID (suffix _P2ID, deliberately not _IDN). Identity results: /mnt/l2/l2vast/_pass2/identity.jsonl.
## Flag-file interface (agreed with W-P2A; PASS2_COMBINER.md section 6)
/mnt/l2/l2vast/_pass2/flags/<setid>.parquet, keys ts (signal t_close s + 2) and side (original side) = the engine events file; flag_<settingid> int8 (1 take); optional state, er, q, nconf_<id>, bits, flip_<id> (flip==1 trades the OPPOSITE side, same bracket: HOOKED). Hook params: p2.flags, p2.flag_col, p2.flip_col. Events with no flag row are taken and counted (counts.jsonl in /mnt/l2/l2vast/_pass2/logs). Null files flag_null_<id>_<seed> work as flag_col unchanged (matched random skip).

EQUAL AVERAGE RISK (definition, code/th_pass2/p2_equalrisk.py): risk of a taken event = lots x initial stop distance (pts) x $20; average risk = mean over the events the book takes (same event set for sizer and flat reference); the sizer is rescaled by k = flat_mean / sizer_mean and rounded (>= 1 lot) with the residual ratio reported; dollars also shown per $ of average risk, and the realised downside (mean loss x losses) beside it. A sizer that wins only by taking more risk fails.
## Cost of one book's joint stage (set-months)
Not yet measured at fleet rate (box at load 100: one set-month ~25-30 min at nice 10). Screen-only components cost nothing in the engine. The hook adds no measurable engine time over mf_inject (per print: two dict lookups in manage()). Per-book joint = (settings in the joint grid) x (months): use the W-P2P cost table with 6 months L6M per setting + 37 months for the winner; the hook runs in the same set-month as the plain book (one run per setting).
