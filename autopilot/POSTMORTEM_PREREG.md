# W-PM prereg (P5 post-mortem + P8 full stops), written 2026-11-14 ~16:20Z before any rule scoring
Base: JN05W2 exact trades, runs_rf/JN05W2/<ym>/trades.parquet, 43 months 202304-202610, 19,798 trades; 1-s raw-bracket paths and ctx from _early_cut/jn05w2_90 (joined on book+sig second). Day = Globex label (exit ET + 6h), week = ISO week of that label.
P5 patterns (flags per trade, non-exclusive): full_stop (exit Stop*), cut_late (cut exit with loss > 45 pts), cut_never = full_stop, ssr_book (same book, same session instance, previous closed trade same side was a loser), ssr_any (any book, same session instance, same-side loser closed before entry), entry#>=3 / >=5 in book-session and in stack-session, open_after_down1R / 2R (day realised P&L at entry <= -1R / -2R; 1R = median full-stop loss $), trend_against (session net move opposite to side, efficiency ratio >= 0.25), chop (ER < 0.12), event day (event_flags any_<session>, from 2024-10 only), ctx fresh/chasing/reentry. Rank by gross loss dollars in the 20 worst weeks and 40 worst days; lift vs all periods; permutation placebo (1000 random sets of 20 weeks / 40 days). A pattern with > 5% share of loss dollars becomes a rule candidate for the exact engine (hook module, identity first).
P8: stopped vs target-reaching trades in first 1/3/5/10 min from the 1-s paths (max adverse, time under water, new favourable extreme); first-order time-stop / no-progress / flat-cut grids per book and session on the path file (cut at -35/-40/-45/-50 flat, time stops below -X after N min), then exact engine for survivors. Windows L3M, L6M first, then HOLD, PRE, X', GAP; tolerant gate; placebos = same rule on shifted triggers (11/23/37 days); WF every 2 weeks; W44 removed.
