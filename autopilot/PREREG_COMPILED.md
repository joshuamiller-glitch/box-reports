# PREREG_COMPILED (W-COMPILED, order 1337Z item 3) - written before any identity or speed number is scored
Scope: a compiled (numba) replacement for parts of the exact engine's per-print path, opt-in FL_COMPILED=1 in the launcher layer; nothing switches before identity passes. No P&L number is scored or published by this work.
Identity criterion (same as PREREG_FAST_LADDER): the trades parquet of a set-month run with FL_COMPILED=1 is equal to the production exact result: same row count, same columns, every int equal, every float within 1e-9 (cmp_trades.py). Sample: the 217 set-months in /mnt/l2/l2vast/_fastladder/sample.json (seed 20261119) + the newer kinds (ASI RK7/RH7/RP7/RU7, ASI M ADD/RA7, NYE RP7/RM7/RH7, LO/SO sets, layer-fit sets, EXE sets) at >= 3 months per kind. Any mismatch = no switch, fall back to FL_FAST/exact.
Speed metric: CPU seconds per set-month (process_time) exact vs FL_FAST+FL_NEXT vs FL_COMPILED on the same host, same set-month, no profiler, reported as a ratio with the n of cases.
Standing rules: prereg before scoring; 2% exact re-check forever (fl_recheck.py, exact path) and automatic fallback; research only; no spend; box-1 <= 8 cores nice 5, MemAvail > 40 GB.
