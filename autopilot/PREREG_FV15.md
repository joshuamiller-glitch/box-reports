## 3. Executed families (feature scale -> horizon class: H1 = 1-min run length, H2 = 3-15 min windows, H3 = 30-240 min windows, H4 = Globex-session-to-entry, H5 = prior-session)
Features (all causal, windows end the minute before the entry bar): A5 (5-min aligned signed-volume imbalance, H2), ALIGNRUN (H1), ALIGN15 (H2), ALIGN30, ALIGN60, PERS30, AC120 (H3), ONFLOW (aligned imbalance since the Globex session open, H4), PDFLOW (aligned imbalance of the previous session, H5), VR15 = ln(RV15/RV120 scaled) (H2) and VR60 = ln(RV60/RV480 scaled) (H3) realised-vol ratios (D08).
- FV15A FLOWEXIT (M5; D01 H4, D02 H1/H4): exit at the open of the bar after the first minute (>= 3 minutes after entry) at which the trailing-W-minute aligned imbalance is <= -q: W in {10,20,30} x q in {0.15,0.30,0.45} = 9 cells. Gating null: PZ2-style random victims (same count drawn from all accepted rows, event bar at the same elapsed fraction).
- FV15B VOLEXIT (M5; D08 H1/H4): exit at the open after the first adverse 1-min bar whose range >= k x median(1-min range, 60) and that closes against the position, k in {3,4,5}, with/without requiring a closing-adverse bar = 6 cells. Same null.
- FV15C TILT (M8): multiplier norm1(1 + sg x 0.5 x rankz(feature)) for the 11 features x sg in {+1,-1} = 22 cells. Gating null: joint within-block (book, year, ET hour) permutation of all features (ap_py7_core.permute_world).
- FV15D SWRISK (M4 switch x0 and M7 risk x0.5 on the adverse tercile): flow-aligned features (A5, ALIGNRUN, ALIGN15, ALIGN30, ALIGN60, ONFLOW, PDFLOW) low tercile; PERS30, AC120, VR15, VR60 both tails = 15 sides x 2 actions = 30 cells (clean-frozen tercile cuts).
- FV15E ML (D12; M4/M7/M8): walk-forward ridge (quarterly refit, expanding window from 2023-02, first test quarter 2023Q3) predicting trade points per ATR from the 11 features (+ ET-block dummies in the second feature set), alpha in {10,100}, use in {SIZE norm1(1+0.5 rankz(pred)), SWITCH skip bottom third by expanding rank, RISK half size in bottom third} = 2 x 2 x 3 = 12 cells. Null: joint within-block feature permutation with refit.
Total 79 cells, five pipelines, each with its own 200-replicate null and 200-world family null (the family null is per pipeline; across pipelines the chance-pass expectation is stated in the report).
