# PREREG FV4: structure-conditioned FVG sleeves (written 2026-10-16 BEFORE any FV4 run; code ap_fv_struct.py)
Question: is the FVG pullback better when the imbalance is created by a structure event (BOS / CHoCH) or follows a liquidity sweep, i.e. the composite ICT models in M2/M3 modes, versus the unfiltered FVG? Base = P1 (PREREG_FV2) at tf in {3, 5}, X1 bracket, R-sized, fills as PREREG_ICT.
Cells (12): tf {3,5} x condition {BOS, CHOCH, SWEEP} x window {a: event on the FVG-forming bar or the 2 bars before; b: within 6 bars before}. BOS/CHOCH = fractal-5 structure events (ap_ict_det.struct_events, displacement >= 1 ATR, same direction as the FVG); SWEEP = a pool sweep (SESS, PDHL, EQ pools, 4 ticks, N 2) whose reversal direction equals the FVG direction within the window. Control per cell: the complementary set (FVGs failing the condition). 
Gates for a cell to be a lead: (i) mean net R per trade of the conditioned set > the unfiltered set's AND > the complementary set's; (ii) conditioned clean Sharpe above the p95 of 200 random thinning draws with the same retained fraction (selection-corrected: best of the 12 cells vs best of 12 in each thinning replicate); (iii) additive uplift >= +0.10 on clean/H1/H2 at 20% (R-sized) and the P1 gates (plateau on the structure parameters fractal k 5 -> 4/6, displacement 1 -> 0.75/1.25, window +-25%, 2x slippage, wd corr, bootstrap). H1/H2 are non-virgin: max status FOUND-PENDING. A cell that only matches the unfiltered sleeve scaled by trade count is NO.
