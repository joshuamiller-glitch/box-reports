# PREREG RC-B3 (set exits: OR / AND / k-of-n of mirrored triggers) - RC-1, 2026-10-30, written before any RB3 scored cell
Same masks, fills, costs, bases, clusters, MDE, controls, tiers and multiplicity rules as PREREG_RC_A.md (fc2854a2...) / RC_B1 / RC_B2. Members come from the hashed RA selection file (selection_RA.json sha256 869b51866fc16225117739a07f595f194fa85757dbea22dc60ae29811718c096; PRE+X' ranking): variant TOP = the 5 best distinct (stream, trigger) pairs of the book's top-50 list (any fire rate); variant HF = the 5 best distinct (stream, trigger) pairs among cells with PRE+X' fire >= 5% (so that OR/AND sets can fire). Per (entry base in {MKT, S7030}, book in 10 books, variant): 25 sets = OR5 (any member, k=1 of 5), k=2,3,4 of 5, AND5 (all five), 10 AND pairs, 10 AND triples; a member 'fires' on its first qualifying mirror event after the first fill; the set state is true from the k-th distinct member on (sticky) and is evaluated at every later member event; x the 36-cell grid (action x min age x state) = 900 cells per (base, book, variant), 36,000 total.
Entry AND-sets from the combo stage (out/confirm/combo/stage1B) are fib/OTE/PD level-touch members without an event stream or a defined mirror event; they are NOT scored here (named in the report as awaiting CF-COMBO event-stream export). The set exits are therefore applied to the market and 70/30 bases (the 'AND-set entry -> OR/AND mirror exits' of the directive is covered for the exit side only).
Selection (PRE and X' only): per (entry base, book, variant) eligible = N >= 0 and LIVE-CAL >= 0 in PRE and in X' separately, fire_PX >= 0.5%; rank = pooled PRE+X' N / SE; top 3 per (base, book, variant) SELECTED; one recent look; recent columns sealed until the selection file is hashed. Controls on selected: random exits at the same rate and age distribution (200 draws), shuffled-day mirrored members.
