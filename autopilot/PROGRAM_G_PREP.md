# PROGRAM G PREP - learned TH rule (ZL-1, 2026-11-06). Preparation only: no engine number, no performance number. Plan/prereg = CHAR-B (TH_REDO_PROGRAM_PLAN.md); this page + code/progg/{g_lib.py, g_smoke.py, g_trunc_test.py} are the machinery.
## 1. Evaluation rows and features (per book, every decision second)
* Row = (trade, second s) while the trade is open; loss mode = unrealised <= 0, profit mode = unrealised > 0; decision at the END of second s (ts = s+1), exactly the published thp_build.process_trade output (142 columns). It is built from the trade's 1-s path and the 1-s mbp-10 tables for ANY id of the v3 tree (extras included) by the same function (derived private copy in /mnt/l2/l2vast/ds3_v2tree/derived/).
* L1 path (thp_kern.path_kernel, dense 1-s): upnl, mfe, mae, dd_mfe, dd_mfe_pct, sec_since_mfe, sec_since_mae, sec_uw, recov_pts, recov_pct, er30/er120/er300 (efficiency), vel30/vel120 (momentum), nhigh60, dist_tgt/dist_stop (+R), upnl_R, mfe_R, pct, mins, secs_ext, JADE live profit-side TH state (j_c1..j_c4, j_cnt, j_trig, j_fired) and the loss-side analogue (lc1..lc3, lc_cnt). Stall seconds = sec_since_mfe / sec_since_mae; pullback points = dd_mfe; momentum window/points = vel30/vel120 plus upnl differences over w in {5,10,30,60,120,300} s (to add in g_lib.l1_extra when the plan fixes the grid: pure functions of the path). The PhMin/PhReq/PhTrail parameters are rule parameters of the DS3 profit path rules (not features): the learner sees the underlying state (mfe, dd_mfe, sec_since_mfe, upnl), the hand rules stay as comparators.
* L2 book at 1 s (process_trade): ob_age_s, spread_t, imb1/5/10 (sided), sz_behind1/sz_ahead1, liq_ahead4/8 and liq_behind4/8, delta10_s/delta60_s, vol10/vol60, intens10/intens_rel, big1_net30_s, big1_tot30, big2_tot30, absorb10_s, absorb_fav10_s, pulled_sup10/pulled_opp10, ofi5_10_s, micro_off_s. Rich L2 (pulled/support multiples at w 2..30 s, thick book, depth ratios, iceberg-against, sweep, delta turn, walls: l2feat) exists on the 10-s grid; it is joined AS-OF the last completed 10-s boundary (causal, g_lib.join_l2feat). ZL-2's dense arrays (ds3_v2/dense: cum_a, cum_b, med_a, med_b, has, age_row, lastrow) give pulled multiples at any window per second and replace the l2feat pulled columns on the 1-s clock.
* Context: session, minute of day, ATR ratio, VWAP/ST/EMA distances, regime tags, stack state (stk_*), ES/RTY moves.
* Excluded from the default feature set: all label columns (rem_pts_*, y_tgt, res_type, t_res, fut_dd, fut_mfe, fill_cost_pts), identifiers/time keys, and sz_tgt_lvl / sz_stop_lvl (the library-minus-raw price offset used to place the target/stop in the book is a 31-row centred median filter = up to ~15 print rows of look-ahead in a near-constant offset; harmless in practice, excluded to keep the causal claim clean).
## 2. Decision target (value of exiting now vs holding)
y(trade, s) = side*(PX[s+lat] - E) - c - (pts_lib - fill_cost): engine K.cut convention, lat = 1 s (decision at s, fill in the next second), c = exit cost (parameter; default 0.57 pt = Z1 touch + 0.57; sensitivity 0.36 / 0.80 / 1.18 mid-referenced), same formula for cut (loss mode) and take (profit mode); hold = 0 by construction. g_lib.exit_value() implements it on the c3 path cache (path_px) for every id, so targets exist for extras without any new build.
## 3. Learner, validation, null (Program G as ordered)
Per book (11 library books, books with < N trades reported as 'none'): purged walk-forward by month, training rows only from trades closed before the month starts (closed_ts, which covers the label horizon since y depends on the final outcome), <= 6 leaves, min_samples_leaf, row subsample, 3 seeds, fire rule = first second with prediction >= theta (theta from a fixed quantile list of the training predictions), trade gain = y at the first fire else 0 (stage-1, paired vs the book's own base); finalists go through the engine (stage 2). Windows on every cell: L1M/L2M/L3M/L6M (30/60/90/180 days back from the last label day) + HOLD/MID/PRE/X'. Null: random exits (same trades fire, uniformly random eligible second), 1,000 draws, family = Westfall-Young max over every (book, seed, theta, mode) cell of the program; compare with the best hand rule of Program E (same windows, same null). Output: g_lib.policy_line() writes a THP_POLICY-style line per book (section loss|profit, tree as OR of AND-conditions on features, action cut/take) or 'none' with the reason.
## 4. Checks run now (mechanics only)
* Causal truncation test on real rows (g_trunc_test.py, derived thp_build with its built-in corrupt_after switch: every path/aux value and every L2 row after the decision instant replaced by garbage, features at the decision must be bit-identical): 60 of 60 (trade, second) pairs identical in loss mode and 60 of 60 in profit mode (6 KB + 6 PE trades of 2026-03, 5 seconds each). NOTE the test must use corrupt_after = decision time ts; using ts-1 corrupts the L2 bin that legitimately ends at ts (that bin holds the records of [ts-1, ts)) and shows a false failure, which I hit first and document here.
* Mechanics smoke test on a synthetic noise world (g_smoke.py: 2,400 trades, pure-noise features and target): walk-forward runs, gain 10.6 vs null mean 2.8 (sd 41.9), p 0.47, i.e. no signal where there is none; feature_cols excludes labels; exit_value reproduces the hand calculation.
