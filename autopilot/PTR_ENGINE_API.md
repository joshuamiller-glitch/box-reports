## 1. What exists
- **Cache** /mnt/l2/l2vast/_th_ptr/cache/LPB_BASE/ (9.3 GB): per-trade, per-second feature paths of the LPB_BASE exact trade list (20,807 trades, 43 months, 16,283 with a path = trades that reach +0.2 x target; 124 M rows): U.npy (u in pts, side-signed), F.npy float16 [rows, 38], off.npy, trades.parquet (row order; columns book7 side lots entry_ts exit_ts entry_px exit_name pnl ld sess tgt path_ok). Rebuild for another universe: `python3 -I ptr_cache.py <SETNAME>` (reads exact_b/runs/<SETNAME>, 3 min).
- **Features** (ptr_feat.py, 38 columns, 1-s top-10 state, signed WITH the trade): pulled_mult[win 2,3,5,8,10,15] (own-side cancelled net of trades / MedLevel), pulled_against_mult[win], wall_ahead_mult[wall_ticks 2,4,8,12,20] (largest level on the against side within T ticks / Med), ice_against (30 s), imb5, imb10 (+ with the trade), delta_mult[win] (aggressor delta against / Med), tot_rel / ahead_rel / behind_rel (fast and slow half-hour baseline), sweep_against[win] (ticks the own-side best price retreated in one second, max over win). pct, secs_fav, dd come from the kernel (not cached).
- **Grammar** (ptr_grammar.parse): `profit <book> <session|*> pct>=A <cond>[ or <cond>] <take|tighten X|lock X|step X|scale F> win=W persist=P wall_ticks=T`; conds with >= / <=; suffix _slow on tot_rel / ahead_rel; secs_fav>=N, dd>=X allowed. Decision at the close of second s, market exit at row s+1: price = mid(s+1) - side x slip. tighten ratchets only in the trade's favour (trail = favourable extreme - X, latched once fired); lock X = stop at entry + X; step X = trail in X-pt steps; scale F = floor(F x lots) at market (lots >= 2), rest keeps the bracket.
- **Kernel** ptr_kern.py (numba): `advance(...)` incremental (engine) and `eval_cells(F, U, off, specs, uexit, uscale)` (first-order). One kernel for both, so first-order and exact use identical definitions.
- **First-order API** ptr_fo.py: `U = FO.Universe(); idx = U.book_idx('K7'); ue, us = FO.eval_specs(U, 'K7', specs); df = FO.score(U, 'K7', ue, us, slip=1.2)` -> per cell nfire, cut_<w> (stack maxDD cut %, all weeks), dmean_<w>, eq_cut_<w>, w20cut_<w> for w in L1M L3M L6M HOLD PRE X'. Build specs with ptr_grammar.parse(line)[2] (np.array(list of specs)). Speed: ~4 s for a book load + 0.03 s per 1,000 trade-rows-cells; pass thousands of cells per call. slip cases (REDO-R9, vs the fill-second mid): central 1.2, low 0.57, high 1.6, engine continuity 0.80; the decision-at-close / exit-at-next-row timing is already the second-delay frame: do not add another delay.
- **Exact hook** ptr_hooks.py (`make_rep(Base, par)`, sz_exact hooks mechanism): set json {"state": <LPB inline state>, "hooks": {"path": ".../th_ptr", "module": "ptr_hooks", "par": {"panel": {"p7_daycap": [42000, 8400], "p7_sess": "7,4,0,4,0,0"}, "rules": [<grammar lines>], "slip": 0.8}}, "cell": "PTR_x", "base": "S1B-COMB"}; helper mk_sets.py `mk(name, rules, slip)` writes it with the LPB state. Queue lines `PTR_x:yyyymm` in /mnt/l2/l2vast/_th_sz/exact_queue_6_ptr.txt (any exact_queue*.txt; PTR_ = tier 3.2 / top tier now). No `rules` = LPB_BASE exactly (identity test PTR_ID, 202610).
