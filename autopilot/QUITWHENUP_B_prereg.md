# QW-2 T-QUIT-WHEN-UP prereg, SECTION B (the quit rules) - written 2026-10-31 before any section-B cell was scored (smoke runs disclosed: 12 specs on D6, to check that the overlay ties out; their numbers were not used for any choice below)

Research only; masks capped at label day 20260206; UNTOUCHED never read. Engine: ss2_lib exact lock engine (sdlib: A6 = PB7) with a STACK-LEVEL QUIT OVERLAY inserted between the day give-back arm and the week floor: (1) per-book entry filter and day arm run as live; (2) the quit trigger is computed on the stack (or per-book) day path (realised + open, 1-s) after the arm; (3) later entries of that day are cancelled (or scaled for size rules), open positions are flattened at the next printed second (FL) or left to their brackets/locks (LR); (4) the exact week floor (12R, causal running-max) is re-run on every touched (book, week). Trigger and cancel are causal (entries before the trigger are unaffected). Re-entries and the busy filter are as in the base (the quit never ADDS a trade; a flatten can only free the busy filter for later trades, which are not added: conservative, stated); the first-stop cut and zone/PE states come from the base run and are not re-solved after the quit (the 3-pass cut iteration is not repeated).
Bases: (1) D6 composite = live lots K6 2 / P6 7 / U6 4 / H6 4 Asia, 2 NY-AM / M6 2 / A6=PB7 1 Asia, integer half-up min-1 ER lots, fractional 70/30 add (slip 0.25), A6 at market, Native 1.28, basis N (43,493 $/wk L6M, ties to D1); (2) the stack as it is (market entries, no rules, join 2.45; 21,715 $/wk L6M). Every cell is scored on both; the D6 composite is the headline, the as-is stack the second base. Measured fills (basis N; the live-cal stop is not re-run: the quit changes WHICH trades, not their fill model; the D6 stack at join 2.45 is a stated sensitivity for the selected cells only).
R units: K6-R = K6 BookR = 2 x 60 x $20 = $2,400 (D6's combined week-lock R; stack rules, directive X = 1/1.5/2/2.5/3/4/5); Rs = the sum of the six live BookR = $24,000 (stack-scale extension, X = 0.25..2 Rs, labelled extension); own = each book's own BookR (planned lots x stop pts x $20) x its running-max SizeMult at the latest entry (per-book rules, each book quits on its own day, exactly D6's day-lock R).
GROUPS (set size = multiplicity; each variant added later is counted and labelled):
G1_plus (80): quit at +X: stack K6 X=1,1.5,2,2.5,3,4,5; stack Rs X=.25,.5,.75,1,1.5,2; book own X=1..5; each x measure {realised-at-closes R, realised+open RO} x action {let run LR, flatten FL}.
G2_timeif (~224): no entries after T if the day is up >= X at T (realised+open at T): T=11:00,11:30,12:00,12:30,13:00,14:00 ET; X=0,.5,1,2 K6-R, 0,.25,.5,1 Rs, and X=-inf ("regardless" = the session-table cut control); LR and FL; all days / Friday-only / (Mon..Thu at T=12:00,14:00); book-level own R.
G3_trail (72): day profit trail: stop and flatten once the day's peak >= A and the day falls to peak - B: K6-R A=2,2.3,2.5,3 x B=.5,1,1.5; Rs A=.5,.75,1,1.5 x B=.1,.2,.3; stack and per-book (own) versions; on realised and on realised+open. Reference = the live per-book give-back lock (arm 2R keep 50%) that is already inside the base.
G4_count (~52): quit after the N-th winning parent trade (N=2,3,4,5) or the N-th entered trade (N=6,8,10,12) (stack); per book N-th winner 1,2,3 / N-th trade 2,3,4,6; "quit after the first loser following a +X morning" X=1,2,3,4 K6-R (stack, per book), Rs .25,.5,1; LR and FL.
G5_regime (~40): no entries after T=11:00,12:00,13:00,14:00 if the day is a chop day at T (causal tags from the 5-min grid: 5m ER20 below the PRE+X' lower tercile, or Choppiness-14 above the upper tercile, or first-hour range below its lower tercile (T>=11:00), or the prior day's range below its lower tercile), and the opposite "keep trading the afternoon on trend days only" (quit on every non-trend day); tercile cut points from PRE+X' days only.
G6_resume (~260): every stack quit cell of G1 (RO), G2 and G3 (RO) with entries re-opened at the next session boundary 12:00 (only for quits before it) or 15:00 vs staying off until the 18:00 rollover (= the base cell). Note: at live lots nothing enters after 15:00 (K6 NY-PM is the last live session), so the 15:00 resume equals the stay-off cell; reported as such.
G7_size (~62): size down instead of quit: after +X (first touch, realised+open) or at T if up >= X, new entries of the rest of the day x0.5 / x0.33 through the engine multiplier route (never pts scaling), integer lots half-up min-1 (and fractional beside); the inverse size UP x1.5 / x2 after a losing morning (loss <= -X), reported, expected negative.
G8_combo (~100): time and profit and day-of-week and regime combinations (T=12:00,13:00,14:00 x X=0,2 K6-R,.5 Rs x {all days, Mon-Thu, Fri} x {no regime, ER-chop, CI-chop}), plus OR-combinations (plus + trail; N-th winner + time rule).
G9_learned: separate prereg section below.
SCORING (every cell): stack weekly mean / SD / maxDD / worst-20-weeks / Sharpe of the rule stack and the delta vs the base with its MDE (2.8 x paired weekly SE), windows PRE, X', PRE+X' (selection), L3M, L6M, HOLD, Y26; the share of days affected; forgone (sum of the negative per-trade changes) vs avoided (positive) $/wk; the equal-risk factor lambda = SD_base/SD_rule (and by maxDD and worst-20 where defined), equal-risk delta = lambda x mean_rule - mean_base (label: STRUCTURE = more lots, not a rule edge); per book delta and per planned lot; block-bootstrap CIs on the weekly delta (blocks of 1 and 4 weeks, 2000 draws); White RC and Romano-Wolf step-down per group (qv.rc_rw on the daily delta matrix, PRE+X' for selection, L6M for the recent look), DSR (n_trials = group size + all prior cells of this program), PBO; quarterly drift (sign count), day-of-week and regime splits.
SELECTION / LOOKS: selection on PRE+X' only (mean delta of the stack, D6 base); per group the top 3 cells by PRE+X' delta among cells with both PRE and X' deltas >= 0 ("LEAD" set; if none, the top 3 by PRE+X' delta labelled DEAD) get ONE recent look (L3M / L6M / HOLD), together with the prereg-named canon cells: G1 stack K6 X=2 RO LR and FL, G1 book X=2 RO FL; G2 stack K6 12:00 X=2 LR, 12:00 regardless, Friday-only 12:00 X=0, 14:00 X=0; G3 stack K6 A=2.5 B=1 RO FL; G4 3 winners LR, 8 trades LR, first loser after +2R; G5 ER-chop after 12:00 and trend-only after 12:00; G7 x0.5 after +2R int; G8 first cell. The full-grid tables print PRE, X' and PRE+X' for every cell and recent columns ONLY for those shortlisted cells (this is the "ONE recent look per group"; a cell outside the shortlist is not looked at in recent windows by me).
TIERS (never softened): DEAD = PRE+X' delta < 0; LEAD = PRE and X' deltas both >= 0 and the rule does not raise SD; CANDIDATE-RECENT = LEAD and L6M delta >= 0 and HOLD delta >= 0 on the recent look; CANDIDATE = CANDIDATE-RECENT and group RC p <= 0.10 on PRE+X' and random-day placebo rank >= 0.90 and random-time placebo rank >= 0.90; PASS = CANDIDATE and delta >= MDE in L6M or HOLD and the quarterly sign count >= 5 of 8 (last 8 quarters) and Romano-Wolf survivor. Models: gradient-boosted trees (depth 2, 150 iterations, lr .05, min leaf 20) and ridge (benchmark). Refit every week on the trailing 3 months (and the anchored expanding variant) of days strictly before the test week (1-day embargo); first test week 2023-07-03. Policy: quit if prediction < -theta, theta = 0, 0.5, 1 K6-R; size-down x0.5 if prediction < -theta; three-level (continue / x0.5 below -0.5R / quit below -1.5R). 3 T x 3 theta x 3 policies x 2 models x 2 windows = 108 cells, all reported.
