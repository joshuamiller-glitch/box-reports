# RA placebo void list (W-RA, 2026-11-16) - which earlier 'beats random' statements stand
Draw design check (measured): random blocks were hashed once per signal second (signals are >= 60 s apart, no consecutive-second re-evaluation), BUT a blocked signal is re-drawn at the NEXT signal bar: 83 of 1,342 blocked M7 London evaluations (6%) were followed within 5 minutes, with no close in between, by an unblocked draw (the real cap would have kept blocking). A persistent-draw variant (one draw per session instance and number of closes) is built (PP1-3 on JL2).
VOID (do not cite):
1. 'CAP3 / CAP2 / CAP4 M7 London beats all placebos in L3M, L6M, HOLD' (DS3_REENTRY_ALL scoped placebo table) - the all-books placebos PL1-3_CAP3 keep more M7 London entries than the real CAP3 (realized keep of n>=2 entries 0.70-0.73 vs 0.62): INVALID CONTROL for that scope. Same for CAP2/CAP4 where the book-level keep differs by > 0.05: PL1_CAP2 U7, PL1_CAP4 M7, PL3_CAP4 M7, PL3_CAP3 A7.
2. Section 5c numbers 'CAP3 +919 $/wk vs placebo seeds -271 / -188 / +703' and CAP2 / CAP4 vs their seeds (all-books placebos, invalid for the M7 London scope).
3. 'BLKiv equals its placebos, so the evidence content adds nothing': PL BLKiv sets block at p = 1.0 (A7, H7, U7) and 0.98-0.85 (M7, K7) by construction, i.e. they are nearly the same rule; PL1/2_BLKiv K7 are INVALID CONTROL (+0.05). The statement is void; evidence rules are untested against a valid control.
4. HALF placebo comparisons (random half size) - PL3_HALF incomplete, PL1/2 keep not measured against a size control; void.
STILL STANDING but PROVISIONAL (valid by keep share, not persistent): TL3_RA_M7L_CAP3 (JN05W2 base) vs PL1-7_M7L_CAP3: real +1,176 $/wk (t 2.68) vs +245..+663; realized keep 0.53-0.60 vs 0.565. Superseded by the JL2 cells with PL1-3 and persistent PP1-3 (DS3_BRACKET_DD_BUILD_RA.md).
Unaffected: the live-night hand application, the descriptive entry-number tables, the 2-week walk-forward (its placebo is random CHOICE of variant, not random blocking).
