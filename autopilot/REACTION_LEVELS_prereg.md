## 1. The map (exact, causal)
* Events: fractal reversals on 5-min, 15-min, 1-h bars, N-bar fractals N = 3, 5, 7 (1, 2, 3 bars each side, strict inequality), highs and lows, confirmed at the close of the last confirming bar (cf_engine bar `ek`). Weight = size of the move reversed = |pivot - latest opposite pivot of the same series before it| in pts (min 0.25; first pivot of a series: bar range).
* Density: each event adds weight x 2^(-age/10 days) (age in wall-clock days) x a triangular kernel of half-width 4 pts on a 0.25-pt grid. Window at snapshot T (every 5-min bar open, state before the block): events confirmed in [first second of the label day N trading days back, T), N = 5, 20, 60 (today so far + N complete label days). Valid only when N complete label days precede T (60-day maps are invalid before ~2023-05-05; signals there are treated as "no band" and the invalid share is reported).
* Maps: ALL (all 9 TF x N series), TF5M, TF15M, TF1H (3 N each) x lookback 5 / 20 / 60 = 12 density maps.
* Bands: local maxima of the density (>= left, > right neighbour) non-maximum-suppressed at +-4 pts; class 1 / 2 / 3 = peak density >= 80th / 90th / 95th percentile of all 0.25-pt bins in [lowest low, highest high] of the closed 5-min bars of the window (nearest rank). Band = a LINE at the peak bin.
* Composite profile: plain sum of the 1-s-volume profiles (bars2 volume spread uniformly over [low, high] ticks of each second, path price frame) of the N prior COMPLETE label days (N = 5, 20, 60), triangular kernel +-4 pts; HVN class 1/2/3 = local maxima (min distance 4 pts) at >= 80th / 90th / 95th pct of the range; LVN class 1/2/3 = local minima at <= 20th / 10th / 5th pct of the inner range (5th..95th volume percentile prices); refreshed once per label day; 6 profile maps (HVN, LVN x 3 N), each x 3 classes.
* Band sets: (12 density + 6 profile) x 3 classes = 54. Signal features (the state at the signal second = latest 5-min snapshot at or before it; profile: the signal's label day): ahead distance (nearest band between entry and target, <= td), behind distance (nearest band between entry and stop, <= sd), near (min |band - entry| within 10), tc (nearest band ahead 30..60 / 30..90).

## 2. Cells scored (filters, ZONES frames) = 1,296; list out/reactlevels/cells_filters.csv sha256 0ff569d5589df4347b1b86ff06d7c5abbec81ca894a75c8699daf27df2c83119
Per band set (54) x frame/parameter/action (12) x base (SPL 70/30 live base, MKT market at the signal) (2):
* AHEAD: band between entry and target within D = 10 / 20 / 30 pts: SKIP (no-trade) or RT (re-target to band - 0.5 pt, invalid when < 2 pts -> signal skipped, as ZONES-2).
* BEHIND: band between entry and stop within B = 10 / 20 pts: TS (stop tightened to band + 0.5, valid 2 <= new stop < original, lots UNCHANGED; no pts scaling).
* AT: keep only signals with a band within R = 2 / 5 pts either side (take-only); signals without a valid map are kept.
* TC: target chooser: target = nearest band 30..cap ahead minus 0.5 (cap 60 / 90), unfired signals keep the original target.
No size rules are scored (a size rule would go through the engine multiplier route only; none is run).
* Money: per planned lot per signal vs the unfiltered base (headline basis M = measured fills), N and LIVE-CAL (M with stop 2.45) beside; per final contract; session and book columns; week-clustered SE, MDE = 2.8 SE.
* Population: headline LIVE6 = KB, PE, SM, HM, MV, PB signals in sessions with live lots (ss2_lib live table); ALL 11 books beside.
* Stack: the one-convention engine (oneconv/oc_lib.py via inst/common/ic_stack.py), live lots, integer half-up ER lots, running-max SizeMult, add slip +0.25, stop parity, no combined lock (C1, headline) and 12R / 20R beside, D6 zone rule ON in the composite and in the base (INST-3 convention). SKIP = mask OR-ed into the engine's zone skip; RT / TC / TS re-simulate the fired rows on the 1-s path and write them into the engine's o array (PE NY-AM / NY-PM confirmation entries keep their original bracket: stated limitation). Run for the CARRIED cells only.

## 4. Selection and looks
* Stage 1 scores ONLY the PRE and X' windows for all 1,560 cells (the recent windows are not computed for any cell at this stage).
* Filter cells (SPL base primary, MKT scored and carried on the same rule): eligible when the gain per planned lot per signal on LIVE6 is > 0 in PRE and in X' on both M and N, nfire >= 300 in PRE and >= 100 in X', fire rate <= 85%; ranked by the precision-weighted z of PRE and X'; the top 10 per (frame x action) family are CARRIED (families: ahead-skip, ahead-rt, behind-ts, at-keep, tc), so at most 50 carried per base. Fade cells: eligible when M and N mean > 0 in PRE and in X' at delay 1 s, >= 400 trades in PRE u X'; top 10 by z carried.
* The carried list is frozen and its sha256 written to DECISIONS.md BEFORE the recent windows (L3M, L6M, HOLD, 2026) are computed for any cell. ONE recent look, on the carried cells only. Nothing is promoted; post-hoc labels. Walk-forward chain not run (no learned layer).
* Gates (ic_tier.gates, T-SIXTY addendum): STRICT = L3M, L6M, PRE, X' all positive (per contract and stack); TOLERANT (literal, headline) = L3M and L6M positive (per contract, N basis, and stack), PRE and X' each >= -0.5 x that window's MDE (per contract and stack), PRE worst-20 weeks no worse than the stack's own, and the L6M->PRE drop < 100% of the L6M gain (= PRE stack gain > 0); TOL-B (PRE > -1.0 x L6M gain) and TOL-nc (clause 5 dropped) shown post-hoc beside; NOW-ONLY = L3M and L6M positive. Counts per column and per family are reported. Tiers: LEAD / CANDIDATE only on TOLERANT; DEAD otherwise; no PASS.

## 5. Validity layer (carried cells only; DEAD mass gets the RC / placebo columns)
