## Why the earlier T2 number (+0.70..+0.94 pts/trade) was wrong
The mapped model prices each exit by natural pts +0.5 minus the exit-type haircut measured on Set A. For STOP exits that haircut is negative (about -2.8 pts: stop-join + convention gain on Set A's losing stops), so every trailing-stop exit - a profitable exit for the remainder - was credited ~+2.8 pts it never earns; the direct replay shows a trailing exit costs ~0.4 pt versus its level (and the P9 baseline for target rows is 2.1 pts below the fill-anchored 60). The mapped paired effect on the same trades is +1.04 pts (central cell) against -0.17 direct: a 1.2-1.5 pt mapping overstatement, the same order as the +4-7k/wk overstatement already seen in the ATR20 cell. The earlier 'direct-calibrated' check only corrected the stop-vs-stop gap, not this credit.
