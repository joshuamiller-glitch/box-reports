# REXIT_PREREG (W-RX, T-REBUILD addendum 3: EXIT CONFLUENCE) - frozen 2026-11-16 before any C1 / C2 scoring. Parts A and B (tables) are measurement, not scoring.
Code: code/th_rexit (build_grid.py add_z.py features.py build_rows.py run_all.py + c12.py when written). Sources: raw = T-REBUILD stage-0 trades (runs_rf/TL3_RB_S0_<BOOK>, months present are listed on the page), jl2 = runs_rf/TL3_EV_JN05W2JL2 (today's stack, real exits).
## A / B tables
One row per closed minute of every trade, first decision 60-120 s after entry, capped at 480 minutes in trade; price at T = last 1-s mid <= T-1; features from the grid row m = T-60 (cf2_grid1m sec1m + feat1m, frame-fixed min1 bars, T-ALPHA walk-forward core forecast), day vote / session VWAP / atr_rel / range used / levels re-read at T with d10_core + bd_room (same functions as the entry reading). Signed with the trade (negative = against). Label rem_R = (exit price - price at T) * side / stop (stop 60, O7 40), exit_better = rem < 0, exit_better_slip = rem < -1.2 pt. Flow items at 5 s: the existing tape_intrade 5-s table for the first 60 minutes (separate add-on; marked on the page when it lands).
## C1 single in-trade conditions
Condition = signed reading in the AGAINST state (ternary vote -1: signed value < -0.5, items already in {-1,0,1} unchanged). Outcome rem_R at the checkpoints k = 5, 15, 30, 60, 120 minutes in trade (row j = k, trade still open), pooled over checkpoints (one row per trade-checkpoint) and per checkpoint. Cells: book x session (0 asia, 1 london, 3 nyam, 4 nypm; >= 60 rows per cell), book, ALL. Windows: all months present, L6M (2026-05-01..2026-10-30), HOLD (2025-11-17..2025-12-10), years. Statistic: lift = mean(rem_R | against) - mean(rem_R | not against); t over calendar weeks of the trade entry (week clusters, >= 8 weeks with both groups). A useful exit reading has a NEGATIVE lift.
Controls beside every condition: (1) shifted labels: the flag of the same cell and checkpoint taken from the trade n = 11, 23, 37 trading days earlier; (2) 30 persistent-draw random flags (bucket = 300 s, hash of seed, trade key and 5-min bucket) with the same share as the real flag in that cell; realised share vs the real share printed, more than 0.05 apart = invalid and redrawn (next seed); (3) nonsense items = the same pipeline on the shifted and random flags (the nonsense bar of a cell = 99th percentile of |t| of the random draws over all conditions of the cell). Percentile of the real lift among the >= 33 control lifts. SURVIVOR = lift < 0, |t| >= nonsense bar, percentile >= 95, Benjamini-Hochberg q <= 0.10 over the conditions of the cell (normal p of t), same sign in L6M and in >= 3 of 4 calendar years (each side >= 30 rows). Everything else is a LEAD at most. W44 (ISO 2026 week 44) removed shown as a second column. Missing controls = "not finished".
## C2 exit confluence count
16 clusters (code/th_rexit/features.py CLUSTERS, members frozen): TREND, TREND15, OSC, MACD, SQZ, VWAP, DAY, XIND, XMOVE, NKD, ALPHA, TAPE, BOOK, WALL, L3, RANGE. Cluster vote = mean of members' ternary votes (known members only); a cluster is AGAINST when the mean <= -0.5. Count = number of clusters against among those known; rows with fewer than 12 known clusters are dropped (stated per cell). Staircase table: mean rem_R by count 0,1,2,3,4+ with week-clustered SE, n, and the same table by open-profit state (open < 0, open >= 0). Main statistic: slope of residual rem_R on min(count,4); the residual is rem_R after regression on open_R, give-back R, ln(minutes in trade) and cell fixed effects (path state is mechanically correlated with how many readings are against). Raw slope shown beside. Controls: the same count built from 3 shifted versions (11/23/37 days) and 30 persistent-draw random cluster flags with the realised share of each cluster matched within 0.05; percentile of the real slope among the controls. Staircase = >= 3 of 4 steps downward on the real count and percentile >= 95 on the adjusted slope.
## Trials
C1: about 190 single conditions x 36 cells x (pooled + 5 checkpoints) x 2 sources = about 41,000 tests plus 33 controls per cell-condition; C2: 16 clusters, 1 count x 36 cells x 2 sources. Ledger rows REX1 and REX2 (TRIALS_LEDGER.csv). Correction: nonsense bar + BH 10 percent per cell; nothing fitted in C1/C2 (no PBO needed; C3 is fitted and gets its own prereg line and PBO).
## Planted-edge check (before any real result is read)
Plant an exit signal into the rows: a synthetic reading that lowers rem_R by +0.15 R / +0.08 R / 0 (at a 15 percent flag share, flag built from the true future outcome with noise) and run the C1 pipeline; report recovered lift, t, percentile, share found. A "nothing passes" statement is not issued unless the plant at +0.15 R is recovered in the same cells.
