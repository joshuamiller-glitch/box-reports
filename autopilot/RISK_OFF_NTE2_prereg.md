# T-RISK-OFF (NTE-2 part) prereg - written 2026-10-31 before any pass-1 table was read
Scope (lead split): REVERSE CONFIRMATION, SIGNAL DECAY, STACK, TIME/SESSION, VOLATILITY/REGIME triggers x all destinations; then combinations / staged ratchets / learned policy across all families (incl. RO-2's order-book and path tables); FINAL merge.
Engine: l2vast/ds3/code/riskoff/ro_engine.py. Trades = ss2 d (44,370), D6 books KB PE SM HM MV PB DN, library 60/60 bracket market entries, single contract; 10-s THP/L2H path-cache rows for row triggers (1-min decision cadence for state triggers firing on >2.5 M rows), 1-s path for the moved-stop scan. Stop live from the next second; ratchet (tighter only); never at/through the market (>= 1 pt behind); target unchanged; same-second as original exit -> original stands.
Fills: stop cost 2.45 (LIVE headline) on every stop fill incl. the hold arm; Native 1.28 and join-fix 0.5 re-scored for selected cells; target = M basis with year correction; time 0.995; fee 0.242.
Cells: rows triggers (51) x 19 destinations x gate {always, under, profit} x min age {0,60,120,300 s}; RC event streams (146 streams x {against, lost}) x 13 destinations x gate x age {0,120}; STACK events (same-side other-book stop, same-side other-book target, opposite-side entry, same-side entry) x 18 destinations x 12. Set size ~ 34,000 cells x 8 scopes; multiplicity = the set size plus every variant added later (counted).
Selection (PRE u X' ONLY): per family, cells with gain > 0 per trade in BOTH PRE and X' (scope ALL pooled, and per book), touched >= 150 trades in PRE u X', ranked by the smaller of the two window t-values (t = gain / (MDE/2.8)). Top 10 per family per scope carried. L3M/L6M/HOLD columns are computed in the table but not consulted for selection; ONE recent look per family at the carry list (logged in autopilot/RISK_OFF_NTE2_looks.txt with the carry-list sha256 before the look).
Tiers (unsoftened): CANDIDATE-RECENT = selected + per-trade gain > 0 in L6M and HOLD + placebo rank >= 0.90; PASS needs also above MDE in L6M and HOLD, stack >= 0 in L6M and HOLD, program-level RC. Anything chosen after seeing recent data = post-hoc.
Placebos (selected cells): random-tighten (same count per book x session, same time-since-entry distribution, same destination) 100 draws; shuffled-day trigger (trigger time-since-entry and fire flag taken from another trade of the same book x session on a different day, destination computed on this trade) 100 draws.
Stack: finalists only, through ss2 (live lots, integer half-up, running-max locks, Sunday composite): stop moved by rule on the engine rows.
Combinations (B): AND pairs / triples / k-of-n of the carried triggers; staged ratchets; learned (walk-forward LightGBM P(stop before target from here), E[remaining]); selection PRE u X' only; same one-look rule.

## Addendum C (disclosed variant, before the weighted fit was read)
The first learned fit (v0) weighted every sampled row equally; its labels are time-weighted (long trades contribute many rows) and its out-of-sample correlation with realised gain was -0.03. A second fit (w) weights each row by 1 / (rows of its trade) so the label is the per-trade average. Both are reported (variant count +1). Tree extraction: max 6 leaves on PRE u X' row labels per destination (mae10, sw5, atr1), positive leaves fire, first firing row per trade.
