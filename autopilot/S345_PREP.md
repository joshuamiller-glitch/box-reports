## 5. Blockers (exact)
1. **Exactness:** pnl at new lots is first-order (per-lot scaling); sliced entries, caps, locks, adds and TH timing do not re-simulate. sim.py has no lots-override hook; an exact ER-variant run needs the engine patched (trend_size via a rule/param) - not done (engine unchanged). Optional validation: re-run the L cell exactly on 3 months and compare with the scaled estimate.
2. **Zone leads:** V13T `feats.npz` (SET8 fresh/mitigated distances, af/am/bf/bm) matches replica signals only 46-71% by exact second (K7 49, P7 48, U7 71, M7 46, A7 69, H7 ~1, O7 0). Runner uses the replica PoiSet replay instead (documented tie 88.8%); Skip leads and 'any-freshness' (am/bm) variants are not reproduced. Fix needs the POI store built on the S1 trades' signal times (poi_build_feats.py is keyed to the V13T index).
3. **Sizer ports not built:** equal-risk lscale scan (needs exact lots scaling), PA9 (moot for size-down-only), walk-forward, exposure table, features beyond ER (rv_pct_5d, delta30_s, S2/S3 pools: keyed to V13T rows; S3 triple is not portable without rebuilding those features at the S1 signal seconds). ER-only leads (Q1 L/A/B/C, S1B book x session, ZL-1 vol-target) are ported.
4. **Stack gates:** frames exist only for finalists (6,734); placebo/family/walk-forward are not re-run (stack-independent except the stack-Calmar-gain placebo statistic); T-INSTR-2 original cell frames are not stored (CL tie differs by frame). WATCH items without frames (Monday long, CMD4, RTY) are not scored until frames are exported.
5. **Dependencies on BASE-S1:** autopilot/TH_STATE_BASE_S1.md not yet written; S1-COMB has months 202304..202512 and 202609 on disk (format verified on 2 months: S3 runs); the other months and S1-UNIF are pending. HOLD/NOCUT/PLAIN6060 references arrive only for 3 months in the chain.sh (full runs needed for the regression rows, not for S3-S5).
6. O7 (open drive) has no research-book counterpart in the sizer/zone tables; kept as OD in all stages (no Q1-A/zone reference from the V13T era). H7 (replica) does not coincide with V13T HM signals.
