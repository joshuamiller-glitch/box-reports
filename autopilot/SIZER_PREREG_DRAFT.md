## 0. Objects and conventions
* The sizer multiplier m_i of signal i multiplies the planned lots of the signal exactly the way the live ER sizer does in the engine (ov['extra_mult'] row multiplier fed through the ER row-multiplier hook; integer half-up, min 1 lot; governors keep the unrounded multiplier; running-max SizeMult over TAKEN signals; ov key and engine hook verified by a TIE-OUT cell first: the live ER mapping rebuilt as an extra_mult vector on a base with the live ER sizer switched off must reproduce the reference to 0.0 $). THE EXACT LIVE MAPPING (thresholds/ladder, DS7 code) IS READ FIRST (section 1.0) and the engine's model is er_thr 0.30 / hi 1.5 / lo 0.5 with the 5-min ER(20) of the last closed bar; any difference found in DS7.cs (e.g. a four-step ladder x0.25/0.5/1/1.5 as the overnight log suggests) replaces the reference and is stated before scoring.
* RANK: for a feature x and signal i of book b, r_i = (number of EARLIER signals of the same book with a feature value strictly below x_i) / (number of earlier signals of the book with a valid value); defined only when >= 100 earlier signals exist (else NaN -> multiplier 1.0). 'Earlier' = sig_sec < sig_sec_i (ties by tid). All signals of the book count (taken or not), as EINT1 crank. Arrays: ranks_book.parquet. Direction d in {+1 (high rank is good), -1 (low rank is good)}: the cell uses r' = r (d=+1) or 1-r (d=-1).
* MAPPINGS (the only mappings used anywhere; lo/hi = min/max multiplier): 
  L3(lo,hi): r'<1/3 -> lo; 1/3<=r'<2/3 -> 1; r'>=2/3 -> hi.   L5(lo,hi): quintiles -> lo, (lo+1)/2, 1, (1+hi)/2, hi.   LIN(lo,hi): m = lo + (hi-lo) r'.   SIG(lo,hi): m = lo + (hi-lo)/(1+exp(-6 (r'-0.5))).   U3(hi): r'>=2/3 -> hi else 1 (size-UP only).   D3(lo): r'<1/3 -> lo else 1 (size-DOWN only).
  (lo,hi) pairs for section 1: A=(0.5,1.5) [live range], B=(0.25,2.0), C=(0.5,1.0), D=(1.0,1.5). Section 2 uses A only (U3 hi=1.5, D3 lo=0.5) for the mapping grid; the best features get B-D in section 3.
* Every cell reports its LOTS DISTRIBUTION: mean lots vs reference, % signals at <=x0.5 / x1 / >=x1.5, max lots; and equal-risk results (lot scale so ALL worst-20 = the reference's; secant <= 5 runs).
* SCORES: drawdown first at live lots per window (L3M L6M HOLD MID PRE X'): weekly-cumulative maxDD, worst-20, Calmar, SD, ulcer, CVaR5, mean $/wk with paired MDE (2.8 SE); cut = 1 - maxDD(cell)/maxDD(reference ER sizer); equal-risk mean; per book x session x vol tercile; carrying week (episodes of DS3_ZONES_EPISODES_V13Y/V13T recomputed on the reference) and ONE-WEEK; STRICT/TOLERANT/NOW-ONLY (literal z2lib tiers); PA band = Z3 V13T PA9 FINAL (DS3_ZONES_3_NOISE_V13T_FINAL.md, flip-5 values: L6M .219 HOLD .205 MID .322 PRE .099 X' .182 for cells whose multiplier != 1 on > 3.5 % of signals); no-harm in DOLLARS (every window's maxDD increase <= max(band x ref maxDD, 0.5 x ref weekly SD) and mean change not below -MDE); two-episode rule.
* PLACEBOS (>= 100 draws x 3 kinds, ONLY for cells that pass the PA band rule or are the best of their family; same engine, same cost model): P1 RANDOM LOT MULTIPLIERS with the same multiplier distribution (multipliers of the real cell permuted among the signals of the same book x session x side); P2 SHUFFLED-DAY multipliers (the real cell's multiplier vector of one label day assigned to another label day of the same weekday and book x session, circular shift by a random number of days >= 7); P3 AR(1)-MATCHED STATE PATHS (for each book the feature's rank series is replaced by a simulated series with the same marginal (uniform ranks) and the same lag-1 autocorrelation of consecutive signals of the book, then mapped with the same mapping). Rank = (1+#placebo cut >= real)/(1+n) on the mean of the L6M/HOLD/PRE/X' cuts; chance benchmark (S4a method): share of placebo draws positive in L6M AND PRE AND X'.
* LABELS: RISK-KEEP = L6M AND PRE PA cut above the PA9 band with the carrying episode dropped, dollar no-harm, all three placebo ranks <= 0.05, walk-forward chain positive; LEAD = band rule + no-harm + two-episode but a placebo rank > 0.05 or the drop leaves the cut below band; ONE-WEEK/ONE-EPISODE; FRAGILE (works at <= 1 of the 5 neighbouring parameter values or flips with the pairing of lo/hi); VOLUME (cut explained by lower mean lots: equal-risk cut <= 0 or P1 rank > 0.10); DEAD. Nothing is a lead on one week or one month.
