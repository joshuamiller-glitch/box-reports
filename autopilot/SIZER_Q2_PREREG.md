Frame: T-SIZER base (BASE-4 run_v13t_ts: V13T_LIVE costs, SEQUENTIAL rounding, lock R scaled only when mult > 1, A06 not modelled, zone half before ER), lock none (per-book locks only), harness sizer_harness.py (mode ts). Reference L = live ladder (ER(20) 5-min, x0.5 < .30, x1.5 >= .30). Off is not a cell. ER features from /mnt/l2/l2vast/ds3_sizer/feat_signal.parquet (S4b; er_<bar>_<lookback>, last closed bar at the signal second; NaN -> multiplier 1.0).
Cells (40 + L): 
F1 3-tier ladders on ER(20) 5-min: x0.5 if ER < a; x1.0 if a <= ER < b; x1.5 if ER >= b; a in {.20,.25,.30}, b in {.35,.40,.45,.50,.60} (15 cells T_a_b).
F2 lot-capped x1.5: x1.5 only where the zone-halved rounded base lots rz <= N (N = 2, 3, 4), otherwise x1.0 on high ER, x0.5 on low ER unchanged (3 cells CAPB_N); max-lots cap after the multiplier: lots = min(lots, M) for M = 6, 8, 10, implemented as multiplier min(m, M/rz) (3 cells MAXL_M).
F3 x1.5 by session / book (low-ER x0.5 unchanged, high-ER outside the allowed set -> x1.0): sessions {nyam, nypm} (S_NY), sessions {asia, london} (S_AL); books PE only (K_PE), all books except PE (K_NOPE) (4 cells).
F4 ER window 14 / 20 / 30 on 3-min and 5-min bars (6 features) each with the three mappings M_live (x0.5 < .30, x1.5 >= .30), M_A (x0.5 < .30, x1.0 >= .30), M_B (x1.0 < .30, x1.5 >= .30): 18 cells, of which 5m_20 x 3 are L, A, B of Q1 (15 new cells).
Score each cell on L6M, HOLD, MID, PRE, X', F9: mean, maxDD, worst-20, ulcer, CVaR5, Calmar, paired MDE of the mean difference vs L, maxDD cut vs L, W29-W39 (2026 ISO weeks) dropped from base and cell, equal-risk mean (lscale scan) for the ranked cells, and the lots distribution. RANK KEY (user's standing rule): maxDD among cells whose mean >= L's mean minus the paired MDE (tolerance stated), L6M first then PRE, on the full window and with W29-W39 dropped. FLAG rule: a cell that beats L on maxDD in BOTH L6M and PRE with W29-W39 dropped and mean inside the MDE -> ***FLAG*** block in MORNING_FLAGS.md + MORNING.md line with the exact definition (bar, window, thresholds, multipliers, sequential rounding, lock rule, per book / session). Winners (flagged cells and the top 3 ranked) get exposure_table, equal-risk and equal-mean-lots, and three placebos (permuted-within-book-x-session multipliers, shuffled days, AR(1)-matched; 100 draws each, phase 0 because the base is phase-invariant). Multiplicity: 40 cells scored; a winner is called a lead only if it also beats the placebo mean rank >= 0.95 in L6M and PRE; otherwise it is reported as 'size effect' (less size), not selection. Nothing is a PASS; the user decides.
