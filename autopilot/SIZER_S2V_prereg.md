# SIZER_S2V prereg (ZL-1, 2026-11-02): VOL SCALING UNDER THE LIVE ER LADDER (subset of SIZER_PREREG_DRAFT section 2.1/2.2 volatility features + 3.4 risk parity)
Written and hashed BEFORE any outcome statistic of these cells. Shadow/research only; ER sizer is a KEEP (reference, never removed). Base: V13T_LIVE via code/zones3/sizer/sizer_harness.py (copied to code/zones3/sizer_s2v/), lock none.
## Composition
m_i = clip( ER_i * f_i , 0.25 , CAP ), CAP = 1.5 (headline; so ER x1.5 is never pushed above 1.5 by the vol factor), ER_i = live binary ladder (x1.5 if ER(20)5m >= 0.30 else x0.5, from H.live_mult()), f_i = vol factor below; NaN feature -> f = 1. The zone half factor and integer half-up lots stay in the engine. HEADLINE rounding = lots_round 'sequential' versus the live ladder run with the same rounding; single rounding is reported for finalists only.
## Features (all causal, at the signal second; from /mnt/l2/l2vast/ds3_sizer/feat_signal.parquet and feat_signal_b.parquet)
1 atr_ratio_5m (ATR14/ATR100 of 5-min bars; stand-in for ATR14 / 20-day median, which is not built); 2 rv_ratio_30m (RV 30 min vs 20 days); 3 range_so_far_ratio (current Globex day range so far / mean range of previous 20 days; this IS the overnight range ratio for asia/london/pre signals and the day range ratio later; stand-in for a separate overnight range ratio); 4 dayrange_atrd (day range so far / daily ATR14 = daily ATR position); 5 pk_ratio_20d (Parkinson 60 min / 20 days); 6 VT = vol-target: v_i = mult * expanding median over EARLIER signals of the same book (min 100) of atr14_5m / atr14_5m_i, f = clip(v, 0.5, 1.5), i.e. lots proportional to $risk/(ATR x $20); target multiples mult in {0.75, 1.0, 1.25}.
## Maps (features 1-5 use the expanding per-book percentile rank r in [0,1] from ranks_book.parquet; high r = high volatility)
Direction INV (volatility scaling: size down when volatile): LIN f = 1.5 - r; SIG f = 0.5 + 1/(1+exp(8(r-0.5))); L3 f = 1.5 if r < 1/3, 0.5 if r >= 2/3, else 1.0. Direction DIR = mirror (r -> 1-r), included to show the sign. Variants: FULL (f as is), DOWN (f = min(f,1)), UP (f = max(f,1)). VT: FULL / DOWN / UP of the clipped v.
## Cells
5 features x 3 maps x 3 variants x 2 directions = 90, plus VT 3 mult x 3 variants = 9: 99 cells. All scored on lock None, phase 0, windows L6M/HOLD/MID/PRE/X'.
## Ranking and decisions (fixed now)
Eligible = mean $/wk >= live-ladder mean - MDE in BOTH L6M and PRE (paired MDE from the harness). Rank eligible cells by the mean of the maxDD cut (vs the live ladder) over L6M and PRE; show also cut with carrying weeks dropped (CAR constants), leave-one-episode-out min cut, HOLD/MID/X' cuts (no-harm = no cut below -band2 in PRE, MID, X'). FLAG (MORNING_FLAGS.md) only if a cell beats the ladder on L6M AND PRE with the carrying week dropped and is no-harm. Top 5 eligible plus every cell whose phase-0 L6M and PRE cuts both exceed the PA9 band (flip 2%) get PA9 and the three placebos (perm, dayshuf, ar1; 100 draws, phase 0). Winners get lots distribution per book x session and worst-day exposure. Multiplicity: 99 cells, best-of-99 stated; ledger program SIZER_S2V (dead_lookup before, append_cells after). No selection on L6M/HOLD beyond the stated ranking key; all labels post-hoc.
