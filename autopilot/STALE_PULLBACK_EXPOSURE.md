## 1. Mechanism (code facts)
- A dispatched job runs the driver on a compute host (s2_remote_run.sh -> tp_launch.py jn05_run2.py SET MONTH). jn05_run2 -> state_sizer_ijk_wgtp.run_batch: `if os.path.exists(<runs_rf>/<set>/<ym>/DONE): return 'skip'` (line ~121). So if the HOST already holds a DONE directory for that (set, month) the driver does NOT compute.
- The puller (s2_pull.py / s3_pull.py) asks the host "is <run dir>/DONE there?" and rsyncs the run dir back to box 1 and marks the lease done. Until 21:17Z the puller had no freshness test: a DONE from an EARLIER run (older code / events) was pulled back and counted as the new result (lease 'done' after 37 s, run-dir mtimes = the old run's). W-GRIDOPS edited s2_pull.py / s3_pull.py at 21:17Z: "a DONE older than the lease launch (-120 s) is never pulled". That closes the pull-back but NOT the driver skip: with a stale DONE on the host the job computes nothing and the lease stays 'launched' forever (stuck, not stale).
- Hosts hold run dirs of everything they ever computed (Dallas, A, B, C); box-1 'park' (moving the box-1 result and lease) therefore does not remove the host copies.

## 5. Proposed dispatcher fix (for W-GRIDOPS to implement; I do not edit the dispatchers)
1. QUARANTINE BEFORE RUN: s2_remote_run.sh (and the s3 equivalent) gets the lease launch epoch as an argument; before starting the driver, if <runs_rf>/<set>/<ym>/DONE exists and its mtime < launch - 120 s, `mv` the run dir to <runs_rf>_stale/<set>/<ym>.<epoch> (never delete) and log it; then the driver really computes (today the driver skips and, since 21:17Z, the lease sticks).
2. CODE SIGNATURE IN THE LEASE KEY: at dispatch compute sig = sha256(set JSON + every hook module + every data/config file named in the set JSON; ex_stale_check.loaded_files() does exactly this) and store it in the lease; the driver wrapper writes the same sig into <run dir>/code_hash.json at DONE; the puller accepts a DONE only if code_hash.sig == lease.sig AND DONE mtime >= t0 - 120 s. A result computed with older code can then never satisfy a newer dispatch.
3. FRESHNESS GUARD kept (21:17Z) + a minimum-run-time sanity (< 30 s with no log = suspect, hold for review).
4. PARK = ONE COMMAND: park_result.sh SET MONTH moves the box-1 run dir, the lease, and the run dir on every registered host (Dallas, A, B, C, D from the host registry); ex_park.py + <tmp> are the prototype (ex_park.py already moves leases).
5. DETECTOR CRON: ex_pullback_scan.py (done leases older than DONE) + ex_stale_check.py verify every 30 min; any hit = MORNING line.
