# SZ_API - T-SIZER-EXHAUST framework (SZ-CORE). STUB with signatures 2026-11-09 ~14:20Z; implementation code/th_sz/sz_core.py (import: sys.path.insert(0,'code/th_sz'); import sz_core as Z). Numpy/pandas only, no numba, < 2 GB per process.
## 1. Convention (lead)
Every cell = a multiplier array M, float32, len(base) = 21135 for S1B-COMB, rows in `Z.Base('S1B-COMB').t` order (= C.prepare(C.load_trades('S1B-COMB')) order, sorted by entry_ns, book). M = new lots / base lots, 0 = skip, 1 = unchanged; down-only cells have M <= 1 (up-allowed cells are labelled UP and never promoted). Integer rounding: new lots = max(1, floor(base_lots*m+.5)) if m > 0 else 0 (`Z.round_mult(base_lots, m)` returns the effective M after rounding; call it unless your multiplier is already lots/base_lots exact).
Each family owner saves /mnt/l2/l2vast/_th_sz/M_<family>.npz (key cell_id -> float32 array len 21135). SZ-IJK uses them for J pairs (min and product); the exact driver takes the same arrays as its multiplier table. Controls: base names 'S1B-COMB' (live), 'S1B-NOCUT', 'S1B-UNIF' (each has its own row order and length; M arrays are per base; family files for the controls: M_<family>__S1B-NOCUT.npz).
First-order P&L: pnl_new = pnl_base x M per trade (pnl per planned lot already has the $4.84/contract RT fee, so fee scales with lots; rounding is done before). Daily series on the 2023-04-03..2026-11-05 business-day calendar, label day = exit time with the 17:00 ET roll (as instr2_eval), weekly = ISO week.
## 2. Windows and metrics (exh_metrics conventions, as of 2026-11-09, data end 2026-11-05)
L1M 20261011-, L2M 20260911-, L3M 20260812-, L6M 20260512-, HOLD 20251111-, MID 20260207-20260430, PRE 20240201-20250630, X' 20230401-20240131. maxDD / worst-20 (sum of the 20 worst weeks) / Ulcer (rms weekly drawdown) on ALL weeks; MEANS drop the carrying week (largest |cell - ref| weekly delta). Scopes: ALL (stack), per book (KB PE SM HM MV PB OD), per session.
## 3. Signatures
- `Z.Base(name='S1B-COMB')` -> .t (trades df incl. er, sl, lots, book, book7, sess, sess_name, sig_ts, entry_ts, exit_ts, pnl, ld), .n, .lots, .pnl, .book_i, .sess, .day_i (index into Z.DAYS), .ref_daily (Q1-A = M of ones).
- `Z.daily(base, M, mask=None)` -> float64 [nd].
- `Z.score(base, M, ref_M=None, scope='ALL')` -> dict: per window w: mean_w, dd_w, w20_w, ulc_w, cut_w (% maxDD cut vs ref), w20cut_w, dmean_w, eq_f (global scalar so L6M mean equals the ref's), eq_dd_w, eq_w20_w, eq_ulc_w, eq_cut_w, calmar_w, usd_per_k_w ($/wk mean given up per $1k maxDD cut), plus nfire (M<1), lot_change_share, mean_lots.
- `Z.equal_mean(base, M, ref_M)` -> (f, scored dict) ; `Z.frontier(rows)` -> dominance table (dominates Q1-A on both mean and maxDD / trades off at rate).
- `Z.placebo(base, M, B=100, seed, scope)` -> draws dict {'L6M': [B], 'PRE': [B], "X'": [B]} of the maxDD cut when the same lot-change values are assigned to random trades in the same book x session (same count, forward-only: no outcome information); `Z.p_own(obs, draws)`.
- `Z.save_null(cell_id, family, draws, obs)` -> /mnt/l2/l2vast/_th_sz/null/<cell_id>.npz; `Z.family_p(cell_ids=None)` -> {cell_id: p_family} (max-stat over every saved cell, z-standardised draws of L6M and PRE cut; WY-style max, cells independent => conservative) written to _th_sz/family_p.parquet.
- `Z.wf_pick(daily_by_cell, ref_key, first=202401, train_weeks=26, embargo_days=7)` -> (stats table, picks): purged monthly walk-forward of the picking procedure (lowest weekly maxDD on trailing weeks; ties and no-better -> ref).
- `Z.label(row)` -> label string per directive section 2 (below).
- `Z.live_week(M_fn)` held-out live week from the frozen file (first-order; the caller supplies a function of the live trade frame -> M).
- `Z.write_ledger(family, rows)` -> /mnt/l2/l2vast/_th_sz/ledger_<family>.parquet ; `Z.merge_ledgers()` -> normalised view (columns below) from every ledger_*.parquet including the owners' own schemas (adapters for FGH 'cut_<w>' and IJK '<w>_cut' naming).
## 4. Ledger schema (normalised view, one row per cell x base x scope)
family technique params cell_id base scope down_only nfire lot_change_share eq_f ; per window w in L1M L2M L3M L6M HOLD MID PRE X': mean_w dd_w w20_w ulc_w cut_w w20_ref_w dmean_w eq_dd_w eq_w20_w eq_ulc_w eq_cut_w ; calmar_L6M usd_per_k_L6M ; p_plc_L6M p_plc_PRE p_own p_fam wf_ok live_total live_dd stage (S1 first-order / S2 exact) label.
## 5. Label (directive section 2)
CANDIDATE = down-only AND cut_L6M > 0 AND cut_PRE > 0 AND cut_X' > 0 (one of the three may be >= -3 points: tolerant) AND w20 not worse (w20_cell >= w20_ref, or at equal mean eq_w20 >= w20_ref) AND placebo p <= .10 AND p_fam <= .10 AND wf_ok. 'CANDIDATE (own-p only)' = same with family p > .10 but own p <= .10 (family max alone does not kill, labelled). LEAD = cut_L6M > 0 and cut_PRE > 0 and down-only. 'UP (report)' for any cell with M > 1 anywhere. else 'no'. Add ' FAILS-LIVE-WEEK' when the held-out live week total is worse than the ref by more than 1 weekly MDE. Every label carries PRE-PROOF while entry match < .85.
