# T-INSTR-2 BTC/MBT prereg addendum 2: FEE-ADJUSTED fresh-world family null on the full grid (S4b, 2026-11-06), written before any fee-adjusted null world is scored

Order: take over the BTCM fresh-world null from S4a's replication (S4a keeps GC / Monday / daily) and make it fee-adjusted on BOTH the observed grid and the null (the earlier p-values, count .01 and max-stat .13, were fee-less on both). Shadow only, no PASS claims, no purchases, nothing live.
**Observed (fee-adjusted):** the full 287-signal-set x 84-bracket x 6-session-view BTCM grid (144,648 cells registered, T2BTC_NTESTED.md) re-run with the MBT round-trip fee proxy $1.78 = 17.8 points (half, 8.9 points, added on entry, stop exit, flat exit AND target exit; fee unscaled) and the same slippage (entry 10, stop 15, flat 10 points; target needs 5 points beyond): ds3_t2/BTCM_fee_cells.parquet (n_tested unchanged). Gate and statistics exactly as in the original null (t2_null.py / t2_gate.py): cells with n >= 150 passing the tolerant gate (L3M, L6M, HOLD > 0 with n >= 10 / 20 / 30; MID, PRE, X' not below -0.5 MDE where n_w >= 30) and persistence (> 60%% of months with >= 3 trades positive); statistics per world: (S1) count of tolerant cells, (S2) count of tolerant + persistent cells, (S3) number of distinct signal sets with >= 1 such cell, (S4) max over cells (n >= 150) of min(t_L6M, t_HOLD), (S5) max over cells of the full-sample t.
**Null worlds (fee-adjusted, same fee and slippage):** two placebos, each world re-simulates the full grid (all 287 signal sets, 84 brackets, 6 session views) with the fee: (a) random side: every signal's side is flipped with probability 1/2 (entries and brackets unchanged); (b) forward-shifted trigger: every entry delayed by a random 5-60 min at the same side (timing benchmark, forward only, never earlier). Seeds 2001 upward, alternating (a) and (b). The two kinds are evaluated and reported separately.
**How many worlds:** as many as fit in about 5 hours of wall time on 4-5 worker processes (one world about 435 CPU-s, memory guard 40 GB); the run stops submitting new worlds at the deadline and the completed number N is reported honestly. Reported: for each statistic the observed value, the null median / 95th / max, p = (k + 1) / (N + 1) with k = worlds >= observed, and a 95%% Clopper-Pearson confidence interval for the true tail probability from k of N; no p-value is quoted without N and its CI. Decision rule fixed now: the cluster 'survives the family test' only if S4 and S5 have p <= .10 against BOTH placebos (the count statistics S1-S3 are reported but, being driven by correlated bracket clusters, do not decide); if N < 20 per kind the result is labelled 'not enough worlds' and the WATCH label is unchanged.
