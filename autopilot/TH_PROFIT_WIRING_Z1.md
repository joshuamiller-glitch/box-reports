## 1. What is wired (rule dict = grids.py cell + 'unit' = 'KB_asia'...)
| cell family | rule as coded (1-s clock unless stated) | exit type / price |
|--|--|--|
| C1 thick-book tighten (thick, sec, trail pts) | tot_rel >= thick for `sec` consecutive seconds while in profit arms a trail; the trail starts at the price of the arming second and ratchets with the favourable extreme; exit when upnl <= extreme - trail | resting stop: worse of level and close, minus 2.45 pt |
| C2 gated take (pct, gate, level) / C2b / C2c | pct of the target distance reached AND gate(s): ahead_rel (depth ahead of the advance), tot_rel, pulled_mult (support pulled), ice_against (iceberg count); `cad` = evaluation cadence: 1 (1-s clock) or 10 (the live policy grid) | market, fill = print of the next second minus the market cost |
| C3 lock-to-breakeven (pct, buf) | stop moves to E + buf pt once pct of target is reached | resting stop (as C1) |
| C4 scale-out half (pct, runner target / trail8 / book) | half the lots at E + pct x target (limit, level minus the trade's own fill cost, as the library target), runner: library outcome / 8-pt trail / market when ahead_rel >= 1.5 for 2 s | two legs, delta per lot = half-leg + half-runner |
| C5 trail by book state (trail, state, arm) | armed at arm x target; trail from the arm price, active only while the state holds (thick: tot_rel >= 1.5, thin <= 0.7, pulled >= 10, iceberg >= 1) | resting stop |
| D1 PhMin/PhReq/PhTrail | port of g2_kern mode 1 (momentum fade 4 pt/30 s, stall 60 s + 4 pt, efficiency < 0.35/60 s, range collapse 0.55; votes >= PhReq once PhMin MFE reached, then trail PhTrail) at 1-s cadence on closes | market on breach |
| D2 chandelier (lookback min, mult) | highest of the last n minutes - mult x ATR(14, 1-min path bars), armed once in profit | resting stop |
| D3 ATR trail (mult, arm pct, n) | extreme - mult x ATR(n) on 5-min path bars after arm pct | resting stop |
| D4 time decay (after min, below pct | shrink) | market exit at T if pct < x; or the target shrinks to (1 - f) x distance at T (limit at that level; market if already beyond) | market / limit |
| D5 scale-out half (pct, runner none / trail4 / 8 / 15) | as C4 | two legs |
| D6 | {'C': rule, 'D': rule}: earliest exit of the two parts | |
| E-profit | {'loss': rule, 'profit': rule}: BASE-4's loss screen first, then the profit rule on trades whose own exit is later than the profit exit | earliest exit wins |
Frame logic (== BASE-4's K-row convention): new_pnl = baseline_pnl + lots x 20 x (rule_pts - reference_pts), where reference = pts_lib - fill_cost_pts (or the cut / lock / flatten value read from the path at the baseline's exit second); applied only where the rule's exit second is earlier than the baseline exit; scale-out whose runner is the library outcome uses delta = half-leg - 0.5 x reference (fractional half lots in the screen; integer lots in the engine may differ). Fills: 'measured' = market 0.36 pt vs the print (BASE-4's equivalent of FILL_MODEL_V3), stops 2.45 pt; 'engine995' = market 0.995 pt, same stop/limit conventions. Placebo: same number of exits as the rule has on the unit, random decision seconds uniform in [2, n-3] of random unit trades, market-exit convention, seed 10000 + world.
## 2. Features (profit side; built by me on the 1-s clock from tables/NQ/1s, 2023-02..2026-11, no dp1s rows needed)
tot_rel = depth levels 1-8 both sides / hour base (mean over the previous 20 label days of the day-hour median); ahead_rel = advancing-side depth 1-8 / its hour base; pulled_mult = size cancelled on the supporting side (levels 1-10) in the last 5 s / max(1, median displayed level size at s-1) (the loss rule's p5/med; identical to ZL-2's dense.npz p5/med, corr 1.0000, max diff 0.0001 on the live week); ice_against = number of the last 10 s whose depletion-by-trades of the advancing side was >= 10 x displayed best size (strict). State as of the 1-s row (ts = bin END), windows end at s, no future rows. Validation against the published profit rows (dp10s 2025, 298k sampled rows): Spearman of ahead_rel with published liq_ahead8 0.69, behind 0.66, tot_rel with liq_ahead8 + liq_behind8 0.63 (definitions differ: levels 1-8 and hour-normalised vs within 8 ticks). Distribution: tot_rel median 0.99 (p90 1.36, p99 1.76), ahead_rel 0.97 (1.39, 1.87), ice_against p90 1-2.
## 3. Assumptions the grid leaves open (stated, for CHAR-B)
(a) C1 `trail` is in POINTS: the live rule's '30 ticks' = 7.5 pt, nearest grid value 8. (b) C2 `lvl` 0-3 is an index: ahead_rel / tot_rel {0, 1.0, 1.5, 2.0}, pulled_mult {0, 5, 10, 30}, ice_against {0, 1, 2, 3} (level 0 = feature present, no threshold). (c) pulled_mult has a median of about 107 in this normalisation (churn at all levels vs median level size), so the C2/C2b thresholds 5, 10, 30 pass in more than 85% of seconds: those cells are practically ungated; the discriminating thresholds are far above the grid (the loss line uses 30 only together with a 30-pt adverse arm). (d) D3 ATR on 5-min bars and D2 ATR(14) on 1-min bars are built from the trade's own path (no pre-entry bars): the first bars use the mean of the available true ranges. (e) D1 uses 1-s closes as high and low. (f) the 1-s path is closes only: resting-stop exits trigger on the 1-s close, not on the print (see 5). (g) take lines act on the 10-s grid in the live policy: run C2 with cad = 10 as the live basis and cad = 1 as the 1-s clock reading, both.
