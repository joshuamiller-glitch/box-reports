## The rule (engine v2)
| parameter | frozen value | note |
|--|--|--|
| evaluation clock | **every integer second T** (table row second; 1 s) from the first row after the fill until the row before the original exit (the same row range as the stored 10-s rows) | the ONLY change from the published rule (stored epoch-10-s grid). Fit: informative-trade agreement with live 55/62 (Sun-Tue) and 45/53 (Wed-Thu) vs 31/62 and 27/53 for the 10-s grid; all 186 trades 170 vs 128 |
| persistence | 1 row (first qualifying second fires) | 2 or 3 consecutive rows were slightly worse (fit 54, 51 of 62 at best) |
| arm | adverse <= -30 points on the engine path price of second T (upnl = side x (SC[T-1 s] - E), the stored K definition), E = the engine entry price (stored E for library rows, actual entry price on shifted rows as _l2sl_shifted) | arm 25 about the same, 35 and 40 clearly worse |
| liquidity condition | p5 >= MULT x max(median level, 1) with **MULT = 30**; p5 = sum over the 5 one-second bins ending at T of cancel size (all levels) on the trade-supporting side (bid for longs); median level = median of the 10 own-side level sizes of the book row at second T | the user's rule; MULT 20-100 gave identical agreement on live; the fit-selected variant used MULT 60 and a 3-s window (fit 56/62, held-out 45/53, all 171/186): not expressible on the stored p5/p10/p30 columns and indistinguishable from the frozen value on the live week, so NOT adopted (one live trade of difference) |
| thick-book condition | none | no effect on live agreement |
| minimum age in trade | 0 s | 5-10 s no effect |
| cut price / cost | path price of the firing second, market cost 0.995 (+ the stored fill-cost convention): unchanged engine delta = side x (price - E) - 0.995 - (pts_lib - fill_cost_pts) | unchanged |

## Table spec (v2 K table, built by ZL-2 for every trade of the all_ea tree)
One row per (trade, second T) with upnl <= -15 over the stored row range, columns ti, ts, upnl, cm, med, p5, p10, p30, ne5, ne10, ne30, cut (float32 features; ice, swp, wg, imbf, z and sh columns are 0 and unused). ts = SS[k] + 1 (table bin end), upnl = side x (SC[k] - E) with k the path index of the second before the row, cut as above. Definition source: the stored 10-s rows, verified in the blind tree (K.upnl equals side x (SC - E) on 100% of rows, K.cut formula 100%, K.med equals the table median of the same second on 100%, K.p5 equals the table 5-bin cancel sum on 84% of the blind-week rows, the rest being part of Thu 11-05 where the P2 table differs from the stored value by 1-5 contracts; the history equality is what the build tie-out below demonstrates). Tie-out in the build: restricted to epoch-10-s seconds the table must equal the published loss rows on all old ids (identical), plus a 1-s vs 10-s agreement table (cut/no-cut and cut-second shift) on the old ids.
