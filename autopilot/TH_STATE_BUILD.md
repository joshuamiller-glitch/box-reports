## Definitions
- Label day = ET date of (ts_event + 6 h) (Sun 18:00 ET open -> Monday; 17:00-18:00 maintenance records stay with the closing day). DST via the HIST-PIPE table (America/New_York).
- Clock = ts_event, made monotone by a running max in file (sequence) order; a record that arrives late (ts_event below the running max, 238 of 11.9 B records) joins the running-max second. Second s = [s, s+1) epoch s. Book at second end = the 10-level book fields of the LAST record of the second (file order), carried forward over seconds without records. Identical to the MBO 50 ms grid semantics (events with clock < second end).
- Rows: one per second, contiguous, from 18:00:00 ET of the previous calendar day to max(17:59:59.. last record second, 16:59:59 ET): 86400 rows on normal days (last record in the 17:00-18:00 hour); the final blind day 20261105 is clipped to the data end (last raw record 11:05 ET = 61500 rows; the order text says 16:55 ET, the owned file ends 16:05Z = 11:05 ET). Rows before the first record of a day have have=0 and zero book (none occur in the 931 days).
- Non-trading labels (no T record at all: 187 Sunday pre-open stubs with <= 578 records, 6 weekday holiday stubs 2023-12-25, 2024-01-01, 2024-12-25, 2025-01-01, 2025-12-25, 2026-01-01) get NO day file, are logged in manifest (stub=1) and are skipped in the MedLevel chain.
- Prices = int32 ticks (price/0.25); points = ticks*0.25. Empty level: px 0, sz 0. Sizes int32.
- Prints = every action 'T' record, in file order, assigned to the second of its running-max clock. Side: +1 = buy aggressor (Databento 'B'), -1 = sell aggressor ('A'), 0 = other (3 on 11-02; "side_other" in coverage.csv). Check: +1 prints sit at the ask, -1 at the bid.
- cancelled: for own side, over levels (p, sz1>0) of row r-1 (top 10): cur = size at p in the top 10 of row r; if p not found and the book of row r has 10 levels and p is worse than its 10th level (bid p < bid_px[9]; ask p > ask_px[9]) the level is IGNORED (counted in ign_*); else (found -> its size, not found -> 0); traded = sum of prints at p in row r by the side that hits that side (bid: sell aggressor, ask: buy aggressor); term = max(0, sz1 - cur - traded); canc = sum of terms. Row 0, rows without book, and the row where the instrument id changes (roll=1) have canc = 0 and ign = 0. Ignored levels over the whole history: bid 64.43 M, ask 64.25 M (of 79.7 M rows; ~0.8 levels per side per second, mostly price moves).
- MedLevel (`med`): x_s = (sum of top-5 bid sizes + sum of top-5 ask sizes)/10 at each row; med = x at the first snapshot, then med += 0.001*(x - med) at EVERY row (including carried seconds), including row s; reset (re-seed with x) when the instrument id changes. Block/day independence: for day D the EWMA is run over the previous trading day (not stubs) and D (seed = first book row of the previous day); this equals the infinitely carried value to < 1e-30 relative (0.999^86400), so no state file is needed and each day file is a pure function of the raw. Reset only at a roll (14 roll days, one per quarter).

## Schema (npz, per day, n = rows; keys sorted; deterministic zip, deflate 4)
ts int64[n] (epoch s at END of the second = s+1; the row covers [ts-1, ts)); have int8[n]; nev int32[n] (raw records in the second); inst uint32[n] (instrument id of the book row); bpx,bsz,apx,asz int32[n,10] (best first; ticks / contracts); tr_off int32[n+1], tr_px int32[P] (ticks), tr_sz int32[P], tr_side int8[P] (CSR: prints of row r are tr_off[r]:tr_off[r+1], file order); canc_bid, canc_ask int32[n]; ign_bid, ign_ask int8[n] (levels ignored as outside the visible top 10); roll int8[n]; p_first,p_last,p_high,p_low int32[n] (ticks, 0 = no print); mid float64[n] (points, NaN if a side is empty/no book); med float64[n].
Row r for prints refers to (s-1,s] with s=ts[r]-1 (prints with clock in second ts[r]-1 .. exact: [ts-1, ts)).
