## Statistics, selection, controls
Units: per planned lot (pts per trade, lot-weighted), per contract of final position (same per-trade mean; the multiplier changes lots not per-contract pts), lock-engine stack $/wk (research lots; live lots = x live/research per book). STRUCTURE test: each cell is compared with its LOT-FACTOR-MATCHED UNIFORM LINE (the base scaled uniformly by the cell's mean multiplier, EQR naive scaling c*raw - sweep(c)); a multiplier rule counts only if it beats that line (information = which trades get the lots).
