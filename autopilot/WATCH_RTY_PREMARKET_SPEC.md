# WATCH_RTY_PREMARKET_SPEC - Shadow-only forward watch of the RTY pre-market prior-day-level continuation (CHAR-A, 2026-11-06). Nothing live; no purchase; no PASS claim.
Label: REGIME / WATCH (1b-DEEP): ~95 trades 2024-01..2026-10 on 1-s data, placebo p_book .12-.87, family p 1.00, sign not persistent by year, no calibrated pre-2023 evidence. This file freezes the forward test BEFORE any new data are read. Source rows: DS3_FIND_CHARACTER.md "1b-b" and "1b-DEEP"; code l2vast/ds3/code/find/{tick_levels,tick_events,tick_books}.py; prereg shas in DECISIONS.md (T_FIND_TICKMAP 081e392b3c5d..., T_FIND_1BDEEP 2026-11-06 line).
## 1. Exact definition (all times ET, label day = ET date of wall+6h, RTY front contract = contract with the largest traded volume that label day)
* Data: 1-second book/flow state (mid = (best bid + best ask)/2, traded volume per second) from mbp-10 + trades, rows with spread <= 0 or > 20 ticks masked.
* Level: PDH / PDL = highest / lowest mid of the PREVIOUS label day's RTH (09:30:00-15:59:59).
* Window: 08:30:00 <= t < 09:30:00 (the 'pre' session; table index = seconds after 18:00 ET, i.e. 52200 <= idx < 55800).
* Burst: vol5(t) = traded volume over the 5 seconds ending at t (inclusive) >= the 90th percentile of vol5 over the previous label day's RTH seconds with volume > 0.
* Touch event: the FIRST second t0 in the window at which mid(t0) >= PDH while mid(t0-1) < PDH (upper, side = long), or mid(t0) <= PDL while mid(t0-1) > PDL (lower, side = short); at most one event per level per day; trade only if burst(t0) is true.
* Entry: market order in the approach direction, arriving 1 s after t0 (assumed fill = first print at or after t0+1 s; the 1b-DEEP surface shows 2-3 s latency costs 2-3 ticks of the 30-min edge and stays positive). One position at a time.
* Size: equal-$ risk: lots = clip(floor(1200 / (stop_pts x $50) + 0.5), 1, cap) with cap = 1.7% of the median 5-minute volume of the session (pre: 6.7 contracts).
* Stop: resting stop at max(2 ticks, 1.5 x S) from the entry, S = median of |mid(t0'+1800 s) - mid(t0')| in ticks over the previous 60 events (any burst touch of the same session type; minimum 10 events before the first trade, otherwise skip). No profit target.
* Exit: time stop 1800 s after entry, or 16:55 ET, whichever first; stop exits slip 1 extra tick.
* Costs charged: measured median spread at the touch (ticks) + fee proxy $4.84 round trip (label: PROXY-STD) + 1 tick on stop exits; the surface is re-reported at +1 tick.
## 2. Forward-watch protocol (fixed now)
* Start of the watch sample: label days 2026-11-02 onward (everything through 2026-10-30 is in-sample). Evaluate every Friday close; a read is official only at the criteria below.
* Required new data: RTY mbp-10 / trade tables for each week, built with the existing pipeline (tables/RTY/1s, raw/RTY/ext). Weekly pull is the existing Databento job; if the box has no spare weekly allowance, the only action allowed is a metadata cost quote (metadata.get_cost) - NO purchase is made by this spec. Default = no buy; the user decides (question logged by the lead in MORNING_FLAGS).
* Event rate: about 8 trades per quarter (95 trades / 11 quarters), so N >= 40 new trades needs about 4-5 years. Therefore an interim ENDPOINT is fixed: N >= 20 new trades OR 12 months, whichever first, using the criteria below as a KILL test only; the PASS test needs N >= 40.
## 3. Criteria (single pre-specified hypothesis, so no multiplicity beyond the one-sided test)
PASS-candidate (still not live, still needs the user) requires ALL of: (a) N >= 40 completed new trades; (b) mean net P&L per trade at equal-risk lots > 0 AND weekly-mean $/wk (carry weeks not applicable) > 0; (c) one-sided t-test of the mid-to-mid 30-minute continuation F (ticks) > 0 at p <= .05, and the forward random-side placebo (same event times, random side, 1,000 draws) p <= .10; (d) cost +1 tick still net > 0; (e) |corr| to the NQ stack (V0 and V2, daily and weekly) <= 0.3 and stack Calmar not lower (carry weeks dropped); (f) the 1-s latency check: re-run with 2 s latency is still > 0.
KILL (watch ends, result = DEAD/REGIME) if ANY: (i) after N >= 20 new trades the mean net P&L per trade <= 0 AND mean F <= 0; (ii) cumulative net P&L at equal-risk lots <= -$6,000 at any time; (iii) 12 months elapsed with N < 20 (insufficient event rate -> NOT-TESTABLE, stop spending); (iv) a data/definition break (contract specification, session hours or spread regime change > 50%).
All results are posted to DS3_FIND.md as 'WATCH read' rows with n, F, net, placebo p and the criteria checklist; nothing is promoted without the user.
