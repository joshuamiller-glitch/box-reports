## Method and caveats
- Subject: the four live sets TL3_SR_AS/NY/NP/LO (all 42 months exist), trades from runs_rf/<set>/<ym>/trades.parquet, P&L = gross - 4.84 x lots, day = exit date ET+7h (as combine.py). Judged span weeks 26-181 (2023-10-02 to 2026-09-27), Nov 2025 absent; 12 / 39 / 77 periods (one 2-week period has no trading days).
- Signal = the trade's sig_ns; confirmation = another book of the same set with a trade whose sig_ns lies within the N minutes up to and including this one, same side (simultaneous counts). Only EXECUTED trades carry sig_ns; signals the engine blocked (in position, halts, caps) are not in TRADES, so confirmations from blocked signals are missing (understates confirmation).
- POST-HOC APPROX: filtered trades are removed from the original path. Removing a trade can unblock a later entry of the same book (one position per book) and shifts stack caps, daily-loss halts and book locks; none of that is re-simulated. Exact needs engine rows (not queued; the primary lost 60% income in 3 sessions so it was not worth fleet time).
- Reference rows: N10, N60, N120 same-side, opposite-side block N30, same-side-and-no-opposite N30. Null only for the primary and two references.
- In-sample caveat: the live books were chosen on the same weeks; a confluence that keeps fewer trades inherits that selection. Plain p = one-sided sign test on periods shallower; best-of-all correction is for LEAD's scoreboard (132 lines appended for M5+M6, field step_weeks).
