# ZL1_BT_NULL2_prereg - larger grid-selection null, per book x session and structural-excess view for the BT swing flip (2026-11-02, written BEFORE these runs)
Base: V13T = fill basis N (nfix), take lines off, lock None, the 18,203 taken trades of base_rows_nfixnlnone.pkl. Rule: BT 5-min swing flip (break 10 pts, 4 h, reach 40, direction rule) = the 1,078-taken-trade reference.
(1) Grid-selection null: grid = 5-min swings, break F in {5,10,15,20}, keep in {1 h, 4 h}, reach in {20,30,40,60} (32 settings); statistic = best over the 32 settings of min(L6M,HOLD,PRE) saved $k (no count matching: selection is what is priced). Null families: 1,000 level-offset families (every event level shifted by U(-80,80) pts, independently per F) plus 200 random-time-swing families (per F: the same number of events at uniformly random times with a real 5-min swing extreme of the last 4 h that price is already >= F pts beyond). Rank = share of null families with best >= the real best (real best-of-32 computed the same way).
(2) Per book x session on V13T: saved dollars (row level, ALL and HOLD) with day-clustered 90% CI, engine maxDD cut per book (phase 0 cube, cell = extra_skip BT D40 vs base), carrying maxDD week named, ONE-WEEK label if the cut falls below 10% with the carrying week dropped. 'Structural excess' = real minus the mean of count-matched random-time-swing null families (reach re-set so exactly 1,078 taken trades are flagged; 300 families; same construction as zcm.py) for each book x session cell and for L6M / HOLD / PRE / X' / ALL.
(3) The sentence 'excess over the structural null' (real minus null mean, and the real/best-null ratio) goes into the header of BT_SHADOW_D7_V14_SPEC.md and the Monday runner output. No other test, parameter or construction is added.
