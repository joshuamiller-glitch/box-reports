# ZL-2 PREREG E4 (T-EXIT-N): RE-TARGET and TIME / SESSION EXITS on V13T_LIVE (written 2026-11-02 before any E4 statistic)
Base: d7_v13t.run_v13t_live (xcost 0.80, stopcost 2.45, lines empty, lock none, lockfix legs, grid 1sh, nfix). Injection API d7_v13t.inject (kind take/time = full market exit with the resting add cancelled; scale_out = fraction sold). Delta per lot = side*(px - exit_px_lib) - xcost + fc*(original exit not the target) (as coded in d7_v13t._build_inject; I do not alter it). Both lock frames reported (lock none headline; the 12R frame is reference only).

## Family RT (re-target to a fresh line nearer than the fixed target)
Line sets (streams, path frame, fresh = not touched since formed, valid ek <= kin < cap, direction rule dr in {0, -side}): RT_BTswing = ZL-1 BT|swing_F10|4h; RT_BTpd = BT|pd_F10|4h (broken prior-day H/L); RT_BTsess = BT|sess_F10|4h (broken Asia/London H/L); RT_POC = tape TVP_poc_day; RT_HVN = tape TCP_hvn1_60d; RT_LP = tape TLP_p25_4h (fresh >= 25-lot print, any side). Rule: at the signal second take the NEAREST fresh line on the travel side with distance da from the entry, 8 <= da <= td - 4 pts. The target becomes that line as a RESTING LIMIT at nominal price (exit cost 0): exit at the first path second k in (kin, kout) whose [SL, SH] reaches the line (long SH >= L, short SL <= L), exit price L; if the original exit comes first nothing changes. Variants: RT100 (all lots exit at the line, resting add cancelled if unfilled, kind take with xcost 0) and RT70 (70% of lots exit at the line, 30% keep the original exit, kind scale_out frac 0.7, xcost 0). Scope: all core books (KB PE SM HM MV PB); per-book scopes are run for any set that is positive in L6M and PRE.

## Family TM (time / session exits; market exits, cost 0.80 via xcost)
Session end clocks (ET, from the entry-time ranges in d_rows): asia 02:00 (next day for entries after 18:00), london 08:30, pre 09:30, nyam 12:00, nypm 15:00, close 16:00. Rules: F5/F10/F20/F30 = flatten N minutes before the end of the ENTRY session; NY1130 = NY-AM entries exit at 11:30; ASLDN = Asia entries exit at the London open 02:00 ET; MH60/MH120/MH240 = max hold time in minutes from kin. Exit at the first path second >= the exit time at path price SC, only if kin + 60 s < exit time < original exit second. Scopes: all core books, and each of the six core books separately (a rule x book cell is scored on the engine with only that book's rows injected).

## Scoring
Per cell: weekly-cumulative maxDD of the 11-book composite core, cut vs base in L6M / HOLD / MID / PRE / X' (positive = shallower), delta mean $/week with MDE (2.8 SE), worst-20 weeks, Calmar; carrying week dropped for L6M (W27-38), PRE (W434-451), X' (W321-341) per the two-episode rule; Z3 phase-averaged band as the screen (V13T band when published; V13Y band flip 2% otherwise: L6M 15.5, HOLD 13.3, MID 26.8, PRE 11.5, X' 14.1). Placebos carrying the SAME cost model (RT: cost 0, TM: cost 0.80), >= 100 draws each for any cell with a positive cut in L6M and PRE: (a) random rows, same count per day, random exit second uniform in (kin, kout); (b) same-volume: same count per book x session stratum; (c) shuffled-day counts. Success needs: cut above the band in L6M and PRE or X', no-harm in the other windows, survival of the carrying-week drop, placebo rank >= 0.95. Anything else is NOISE. Shadow/no PASS.
