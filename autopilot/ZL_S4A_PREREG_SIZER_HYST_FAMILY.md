# PRE-REGISTRATION (S4a, T-SIZER): the rank-hysteresis ER lead as ONE family with a family-wise null - written 2026-11-02 before any cell below is scored
Base = the current T-SIZER harness (code/zones3/sizer/sizer_harness.py, default mode 'ts': V13T_LIVE costs + sequential rounding + lock R scaled only when mult > 1; reference = the live binary ER ladder in the same mode; a copy is used, logic untouched). Single path (lock-reset phases are identical on this base). Cut = 1 - maxDD(cell)/maxDD(live ladder).
## (2) The family (72 cells)
Feature = ER(20|14|30) on 5-min closes (er_5m_14, er_5m_20, er_5m_30 of feat_signal) -> causal per-book rank r: (a) EXPANDING rank (ranks_book.parquet, min 100 earlier signals) or (b) ROLLING-250 rank (share of the previous 250 signals of the book strictly below; min 100) [new arrays ranks_roll250.parquet, truncation-audited]. Three tiers with rank cuts (q1, q2) in {(1/4, 3/4), (1/3, 2/3), (0.4, 0.6)}, multipliers 0.5 / 1.0 / 1.5, and hysteresis margin h in {0, 0.03, 0.05, 0.10}: per book in signal order the tier is kept unless r < q1 - h (tier 0), r >= q2 + h (tier 2) or q1 + h <= r < q2 - h (tier 1); the first signal uses plain cuts; NaN rank -> 1.0. 3 windows x 3 cut pairs x 4 margins x 2 rank types = 72 cells. The previous lead (ER20, expanding, (1/3,2/3), h .05) is cell #1 of this family.
## Selection statistic and gates
S = mean(cut_L6M, cut_PRE) of a cell; the family result is B = max S over the cells with mean change (ALL) >= 0 vs the live ladder and no window (L6M HOLD MID PRE X') with a cut below minus the PA9 flip-5 band (L6M .219 HOLD .205 MID .322 PRE .099 X' .182). B2 = max over the same cells of min(cut_L6M, cut_PRE).
## Family-wise null (>= 100 worlds)
World w: a random day-source map pi_w over label days (each label day d takes the multiplier sequence of day pi_w(d), drawn with replacement among days with taken signals; the within-day order is taken cyclically), the SAME map applied to all 72 cell multiplier vectors of the world (cross-cell correlation preserved; multiplier marginal and day-level autocorrelation structure kept; the relation to price removed). Each world re-scores the 72 cells on the engine (7,200 runs for 100 worlds); null of B and B2 = their values over worlds. P-value = (1 + #worlds with B_null >= B_real)/(1 + 100). If less than 100 worlds can be run by the report time, the number run is stated and the P-value is for that number.
## (3) Which tier carries the gain
For the lead cell and for the best-of-family cell: (i) x1.5 tier replaced by x1.0 (multipliers 0.5/1.0/1.0); (ii) x0.5 tier replaced by x1.0 (1.0/1.0/1.5); (iii) the three-tier lead vs the same rank cuts without hysteresis. Reported as cut, mean, equal-risk mean (11-point lscale scan, ZL-2 smoothed fit).
