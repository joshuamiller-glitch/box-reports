Code: outputs/code/th_zn/ (zn_bars.py, zn_levels.py LANDED; zn_core.py scorer being landed next; zn_page.py page generator). Bulk: /mnt/l2/l2vast/_th_zn/.
## 0. Data source (state exactly)
- Prices/levels: 1-min OHLC built by zn_bars.py from the 1-s STATE arrays /mnt/l2/l2vast/_th_state/days/<yyyymmdd>.npz (p_first/p_high/p_low/p_last), 931 trading-day files (18:00 ET -> 18:00 ET, Friday 17:00). NOT bars1m_NQ.npz (that one is back-adjusted and ends 2026-10-16; its levels are off by up to 3000 pts from the traded contract).
- Roll continuity: cum = cumulative roll jumps (14 quarterly rolls, jump = mean book mid over 5 s after the roll flag minus 5 s before; 182..331 pts). All levels are built on the continuous axis (cont = raw - cum) and converted back to the traded contract at the signal bar: live = (cont + cum_at_bar)/4 pts. Entry prices of the trade list are on the traded contract, so distance = |level_live - entry_px|.
- Volume: NQ chart 1-min bars carry no volume in the chart; volume here = TRADED PRINTS of the 1-s state arrays (tr_px, tr_sz; ~600k contracts/day, 1-min bar volume sum matches the arrays to the contract). Profiles are tick-resolution (0.25) profiles of those prints: session profile since 18:00 ET (developing POC/VAH/VAL each minute), RTH profile since 09:30 (developing), prior-day RTH, composite 5/20 RTH days (sum of daily histograms), VA = 70% two-bin expansion from POC, naked POC = prior RTH POC not yet traded through since its session end (8 slots, most recent first), HVN (top-3 smoothed local maxima, >= 10 pts apart and >= 10 pts from POC), LVN (top-3 deepest smoothed local minima inside the day range, <= 35% of max, edges 10% excluded). NT8-computable: from the chart's own tick/volume data (Volumetric/tick series) or 1-min bars + per-bar volume; the volume-profile levels need an NT8 volume profile indicator (state this as the NT8 requirement; prior-day/composite/naked POC could be a precomputed-at-session-end level).
- Causality: a bar with start t0 is known at second s iff t0+60 <= s; trade bar = last bar with end <= sig_ts (strict). Prior-RTH-day levels are used only after that RTH session's last bar closed (pdi). IB/OR levels only after the window closes (one bar later). Developing extremes/VWAP/profiles are values as of the last closed bar. Age >= 0 for every level used (checked).
## 1. Level-feature parquet schema
/mnt/l2/l2vast/_th_zn/lv_<F>.parquet, F in A B G (ZN-CORE); other owners write lv_C.. lv_F (ZN-STRUCT / ZN-BOOK) with the SAME columns. Rows = Z.Base('S1B-COMB').t order (21135). Aux: lv_base.parquet (atr15 [pts, mean TR of the last 14 completed 15-min bars], ti bar index, side, entry, cum, sig, atrd [daily ATR pts]). Shifted-level placebo files: lv_<F>__sh<+25|-25>.parquet (all level prices shifted by +/-25 pts; same columns).
Columns (S in a=ahead: (level-entry)*side >= 0; b=behind: (entry-level)*side > 0, i.e. between entry and stop):
- `<F>_<S>_<fresh>_<age>_dist` float32 pts (>= 0) of the NEAREST level of family F on side S with freshness fresh in {any, t1 (touches <= 1), t0 (untested since formation)} and age <= {1h, 4h, 1d, 5d, any} (NaN = none). Touch = a 1-min bar since formation (<= 5 days back) within +/-2 pts of the level. Dynamic levels (VWAP and bands, anchored VWAPs, developing POC/VAH/VAL) have touches = 0, age = 0.
- nearest (any/any) level details: `<F>_<S>_px`, `_type` (level name), `_age_s`, `_touch`, `_fresh` (touch == 0), `_atr` (dist / atr15), `_width` (0: point levels), `_strength` (touches; volume share is in the type name for profile levels), `_conf` (number of level types of the family within 5 pts of it, incl. itself).
- `<F>_npath30|60|90`: number of levels ahead within 30/60/90 pts (levels in the target path).
- Family A types: pdh pdl pdc (prior RTH), pwh pwl, pmh pml, asia/ldn(London 02:00-08:30)/pre(04:00-09:30)/on(18:00-09:30) h/l (developing, then frozen), or5/15/30 h/l, ib30/ib60 h/l + 1.5x/2x extensions (h15,h2,l15,l2), yvwap (prior RTH VWAP), settle (15:59 bar typical price), gap0..4 (unfilled open gaps >= 10 pts, up to 40 days, within 2 x daily ATR). Family B: vg/vr (session since 18:00, RTH since 09:30 VWAP) + _u1..3/_d1..3 sigma bands (1-min typical price x volume weighted), avwap_wk/mo/swH/swL (15-min fractal 2/2) /od (open-drive extreme), poc_s vah_s val_s (developing session), poc_r vah_r val_r (developing RTH), poc_pd vah_pd val_pd, poc5 vah5 val5, poc20 vah20 val20, hvn1-3, lvn1-3, npoc0-7. Family G: open0930, p1000, e1130, p1500, settle_today, fr5h/fr5l (first-5-min range). (No news-bar series is owned: omitted.)
- Warm-up: priors are NaN until the first prior session/week/month exists (week/month levels from ~May/June 2023; composite 20d from ~May 2023), so X' has fewer level-days.
## 2. Geometry grid (zn_core.GRID)
side S in {ahead, behind}; reach D in {5,10,15,20,30,40,60,90} pts and {0.25,0.5,1,1.5} x atr15; half-width hw in {0,2,5,10} pts (flag if max(dist-hw,0) <= D); freshness in {any,t1,t0}; age in {1h,4h,1d,5d,any}; npath cond in {any, 0 (none inside D... =flag only), >=1}: applied by `npath` variants in zn_core; confluence flag (>= 2 levels of the family within 5 pts of the nearest: `_conf`>=2) and cross-family confluence (>= 2 families with nearest-ahead within 5 pts of each other, zn_core.xconf). The flag vector is deduplicated per scope (identical flags = one cell).
## 3. Actions and scorer (zn_core.py, import: sys.path.insert(0,'code/th_zn'); import zn_core as N)
- N.load_lv(F) -> DataFrame (parquet + base). N.flag(lv, F, side, reach, unit, hw, fresh, age, extra=None) -> bool[21135].
- N.mult(flag, action, base_lots) -> M float32 (Z.round_mult applied): skip=0, half=.5, quarter=.25 (down-only), up=2.0 (`UP`: label 'UP (report, never promoted)', needs the up-size bar). Re-target/delay/structure-stop/split/state-cut-arm/cooldown actions are NOT in the static scorer: exact engine only (state_zone_b.py pattern) for the top-5 per family.
- N.scope_M(base, flagM, scope): M applies only inside scope (ALL, a book, a session, or (book, session)); everything else 1. Every cell is scored by book x session (7 books x 5 sessions), by book, by session and pooled (ALL) - never pooled only.
- N.score_cell(base, M, family, level_set, geom, action, scope) -> ledger row dict = Z.score_cell + columns below; placebo = Z.placebo (random same-count skip/half within book x session, forward-only, B=100) + N.placebo_shift(lv_<F>__sh*, ...) (shifted levels) + N.placebo_days (shuffled days: flags of the same book x session x side taken from a random other day, matched by order within day) ; family p = max-stat over the WHOLE zone set: N.family_p() stores null draws in /mnt/l2/l2vast/_th_zn/null_<owner>.npz and computes the same z-standardised WY max as Z.family_p over EVERY zone cell of every owner (own p shown next to it).
- Equal-lots rows: zone cell vs reference at same lots (cut_w); equal-mean rows: eq_* (global scalar so L6M mean equals the reference). Drawdown first: dd_w, w20_w, ulc_w, cut_w, eq_cut_w, calmar_L6M, usd_per_k_L6M; trades touched % = lot_change_share*100. maxDD / worst-20 / Ulcer on ALL weeks; carry week dropped from means only (Z conventions).
- Purged monthly WF: Z.wf_pick over the cells of one family x scope (first=202401, 26 trailing weeks, 7-day embargo) -> wf_ok. Held-out live week: N.live_zone(M_fn) from the frozen file only (no level history for the live week is owned beyond the state arrays through 2026-11-05: live-week zone checks use the zone flag recomputed from the trade-level features at the frozen-file entry times when covered, else 'n/a' - never the 92 live cuts).
