# PREREG ZONES-3 L2 addendum, sections B/C (ZL-3) - written 2026-11-01 ~22:50Z, BEFORE any drawdown / mean statistic of an L2 zone on D7 v1.2

Scope: score the order-book (ZL-1, `streams_book`) and tape (ZL-2, `streams_tape`) zone streams, alone and with the price lines, on the D7 v1.2 base. Post-hoc research, Shadow only, no PASS claims, append-only files. NEW WINDOWS ONLY (L1M, L2M view, L3M, L6M, HOLD, MID, PRE, X'; F9 = 2026-02-07..10-31). Old-cap numbers are never quoted as new.

## 0. Base and engine
D7 v1.2 = `code/d7base/d7_v12.py` `run_v12(ov)` (lock 12R, TH-L2 loss ON / profit OFF, U7 30 min = agent assumption, zones HALF for the 7 non-OTE lines of the 8-line set at D20, OTE-62 B73 D30, X1-X5 and signal-state in shadow, NY-AM 1 lot K7/H7/M7). Lock-off and v1.1 (no U7) are reported beside the headline for the finalists only. All additions enter through the engine hooks `extra_skip` (rows removed before the lock engine) and `extra_mult` (size multiplier on the ER row multiplier, integer half-up min 1 lot); B73 / WT rows for L2 zones through a compose hook that reuses `d7lib._ote_rows` with the zone distance instead of the OTE-62 distance (rows already owned by the OTE-62 B73 or by a lot-halved set line are excluded from re-targeting, and PE confirmation rows / PB keep their shipped entry). Zone features come from `poi_core.feat_kernel` (ahead = between entry and target, behind = between entry and stop, fresh = end > kin, age = SS[kin] - SS[ek]) on the engine's own rows (kin, side, E, td, sd), plus an own kernel for coincidence and density. Zone streams are used exactly as written by ZL-1 / ZL-2 (no re-tuning); a stream is usable for a window only where its coverage reaches the window end (coverage = last ek vs the engine SS and last stream day); an uncovered window column is printed as `n/a (stream ends YYYYMMDD)`, never as zero effect.

## 1. Zone families (fixed before scoring)
Individual streams: all 96 book + 128 tape files (224). Class unions (one family = rows of all member streams merged, dr kept): BOOK classes ABS, ICE, DEF, PUL, SWP (keep 4 h members, plus 1 h for PUL); TAPE classes TCD, TCP, TDA, TLP, TLQ, TPF, TVP; unions BOOKALL (all five book classes, 4 h), TAPEALL (all tape classes except TLQ_* and TCP long profiles), L2ALL = BOOKALL + TAPEALL. Neutral (dr 0) and side-bearing zones follow poi_core: dr = -side or 0 is ahead, dr = +side or 0 is behind.
Strength terciles are causal: tercile edges of a stream's `strength` (`str` for tape) from the expanding history of events formed before the row's formation time (min 100 events, else the row counts in the middle tercile). Age bins: <1 h / 1-4 h / >4 h (age of the nearest zone). Freshness variants: fresh / any (fresh or touched) / fresh within 1, 2, 4 h.

## 2. Frames and actions (the ZONES frames)
Distances D = 10, 15, 20, 30, 40, 60 pts and 25 / 50 / 75 % of the target distance td.
* AHEAD (zone between entry and target within D): skip, half (lots x0.5), B73 (70 % now, 30 % after price trades through the zone), WT (wait, whole lot through the zone), re-target (target = zone - 2 ticks), delay N min (N = 1, 3, 5).
* BEHIND (zone between entry and stop within D): skip, half, size-up x1.5 (zone protects the stop), stop placement (stop moved to zone - 2 ticks beyond, only where that is tighter than the shipped stop and >= 4 pts).
* AT (zone within 2 pts of the entry, either side): take-only (all other rows skipped), size-up x1.5, skip.
Stage 1 (screen): every one of the 224 streams and the 10 class / union families, AHEAD, D 20 and 40, fresh, action skip (1 run each), per book and per session through the cell-level cube (no extra runs). Stage 2: the top 12 families / streams by the RANK below (and any ZL-1 / ZL-2 leads) get the full grid: D x freshness x age bin x strength tercile x action x frame. Everything scored is listed; non-top streams are kept in the stage-1 table (no cherry-picking: the full stage-1 table is published). Cells are cached by mask hash; cells with an identical mask are scored once.

## 3. Scoring (drawdown first), columns, labels
Per cell, per window (L1M, L2M view, L3M, L6M, HOLD, MID, PRE, X', F9): weekly mean and paired weekly delta mean vs the base with MDE (2.8 x SE), weekly-cumulative maxDD, worst-20 weeks (only where >= 20 weeks; windows with fewer than 20 losing weeks are not a tail measure), weekly SD, Calmar, equal-risk mean (lot table scaled by `lscale` until the worst-20 sum of ALL equals the base's, <= 7 secant steps, gap reported). Three columns STRICT / TOLERANT / NOW-ONLY exactly as `z2lib_redo.tiers` (literal TOLERANT is the headline; TOL-B / TOL-nc post-hoc beside). RISK-KEEP = L6M maxDD cut >= 20 % with the L6M mean change inside MDE; honesty columns: beats the same-volume placebo, and PRE / X' / HOLD agree (cut >= 0 each). Labels: RISK-KEEP, (volume effect) = cut not beating the same-volume placebo, (L6M only) = HOLD and PRE both not agreeing; LEAD = cell passes TOLERANT with placebo rank <= 0.10; CONFIRMED only if STRICT-or-TOLERANT, RISK-KEEP and rank <= 0.05 after the best-of-N null (below). Per book (K7 P7 U7 H7 M7 A7) and per session (asia london pre nyam nypm close) via the engine cube; per-book / per-session cells (action on one book or one session only) are run for the finalists.
RANK = L6M-and-HOLD median maxDD cut at equal risk (placebo beaten), ties by Calmar gain; stage-1 ranking uses the plain maxDD cut (L6M, HOLD, PRE, X' average) and the same-volume placebo rank.

## 4. Placebos
(P1) same-volume placebo: for a cell that adds / removes rows relative to the base, random rows with the same planned-lot volume per book x session (`z2lib_redo.plc_mask` kind 'vol', seeds fixed); (P2) random-level same count (kind 'cnt'); (P3) shuffled-label stack placebo: the zone feature (the mask, built on the shuffled trade axis within book x session x td-bin x side strata, `get_perm`) with the same fire counts; (P4) shuffled-day: zone masks rotated by a random whole number of days (rows keep their book / session). Draws: stage 1: 40 x P1 for the top-30 by plain cut; stage 2 finalists (top 10): 100 draws each of P1, P2, P3 (P4: 50). Rank = share of draws with a cut >= observed (L6M) / maxDD-cut pooled over L6M, HOLD, PRE, X'. A null of the selection itself: stage-1 table recomputed on 15 shuffled-label replicates (label-permuted zone features, `get_perm`) giving the best-of-N distribution of the top cell cut; observed top cells are reported as multiples of it.

## 5. Combinations with the price lines
Set lines = the 8 coded lines (D20, fresh as shipped) with per-line distance a_L from `z2lib_redo.lines()` (af); the line price = E + side x a_L. A set line (fresh, within D20) is a CONFIRMED zone when at least one fresh L2 zone of the tested family (BOOKALL, TAPEALL, L2ALL, and each class) lies within 5 pts of the line price, ahead; otherwise it is a WEAK line (no L2 evidence). Also per line (the 8 lines separately) the same split. Actions (applied to the rows fired by the set at D20, relative to the v1.2 base, which has them HALF): confirmed -> skip / half (base) / size-up-keep; weak -> take full / half (base) / skip; combinations confirmed-skip + weak-full; confirmed-skip only; weak-full only; weak-skip only. Confluence of an L2 zone with a set line within 5 pts at D 10 / 20 / 30 / 40 / 60 and with the OTE-62 B73 rows likewise. Compared to: shipped group 10 (the v1.2 base), the ZONES-3 price layer (from the Z1-Z3 deliverables when published; otherwise price-layer cells re-run by me and labelled).

## 6. Density (section 3 of the order)
For each family F in {BOOKALL, TAPEALL, L2ALL, each class, SET8 price lines, SET8 + L2ALL}: count of fresh zones ahead within 20 / 40 / 60 pts, count behind within 20 / 40 / 60 pts (behind capped to the stop distance), nearest zone distance in any direction, ahead/behind ratio (n_ahead + 1)/(n_behind + 1). Rules scored on the engine: skip when n_ahead(20 or 40) >= k (k = 1, 2, 3, 5), skip when nearest-any distance <= 5 pts (congestion) / >= 40 pts (open space, size-up and skip variants), skip / half when ratio >= 2, size-up when ratio <= 0.5, plus the NTE-1 middle-third no-man's land on the same measure. Frames halves, skips as above; thresholds fixed here, no other thresholds scored.

## 7. Latency / capacity
Information delay: every zone's formation index ek is shifted by +1 s and +3 s (the zone becomes usable that many seconds later; rows whose zone is not yet known at kin lose it). Applied to the top finalists in AHEAD skip / half (non-entering) and to the entering actions (B73, WT, take-only, size-up, re-target, delay) where the decision itself waits: entry kin shifted by +1 s / +3 s for the rows the action changes, via the delay-hook rows of z3lib. Cost relative to the 0-s cell reported as the percentage of the drawdown cut kept. Capacity: zone-action contracts per day vs the 10-level book depth at the zone is described, not scored (no extra statistic).

## 8. The ONE learned rule (price + L2 together)
Per engine row at the signal: features = book, session, side, td, sd; 8 set lines (ahead distance, age, fresh flag, behind distance); price confluence counts; for each L2 class and the unions: n ahead within 20 / 40 / 60 (fresh), n behind within 20 / 40 / 60, nearest ahead / behind distance, nearest any, strength of the nearest (causal tercile), age of the nearest, confirmed-line flag count, weak-line flag count. Target y = the row's base-trade net points per lot > 0 (from the base candidate rows; all library rows with a trade). Model: sklearn HistGradientBoostingClassifier (max_depth 3, 80 iterations, learning rate 0.08, min_samples_leaf 100), walk-forward: each Monday the model is re-fit on the 3 months (13 weeks) before and predicts the week; an expanding-window variant beside. Policy by predicted P bucket: P < q20 -> skip, q20..q40 -> half, else full (bucket edges from the training window's predicted P, no look-ahead), plus the single-threshold variants {skip bottom 10 / 20 / 30 %}. Arms: (A) price features only; (B) price + L2 features; (C) L2 only; shuffled-feature placebo: features permuted across rows within book x session x month before fit and predict (30 replicates of the score metric, B arm); calibration: reliability by decile of predicted P vs observed hit rate and Brier per window. The tree: sklearn DecisionTreeClassifier, max_leaf_nodes = 6, fit on the pooled walk-forward predictions' sign (distillation, predicted P as target via regression tree on P with 6 leaves), described in words and mapped to D7 as the per-line table `line | D | freshness | action`. Scored on the engine through extra_skip / extra_mult like any other cell (drawdown first, same-volume placebo, three tiers).

## 9. Disclosures / limits

(iii) Stream parameters were chosen by ZL-1 / ZL-2 from descriptive hold-rates on old data; the descriptive result there was that no stream reacts better than a random level. (iv) The learned rule's labels are the engine's own realised base trades; counterfactual outcomes for skipped rows are the library's candidate outcomes.
